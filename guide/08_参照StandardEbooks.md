## 1. 总结论

- **软件架构、处理流程、技术选型不变。** SE 手册规定的是「成品书的样子」，影响的是我们重建的输出格式（`guide/04` 模板、`rebuild.py` 输出部分）和检查规则（`guide/07`）。
- **规范的写法向 SE 看齐**：带编号的命令式规则，每条可判定，配正例/反例；规范有版本号。
- **检查报告的格式向 `se lint` 看齐**：类别前缀编号（我们已有）、每条报错 = 编号 + 问题 + **独立的修改提示** + 位置；**按书豁免**（豁免必须写理由）。
- **不采用的四类**：英文排版规则（斜体、小型大写、缩进 1em…）；SE 自家页面（版本记录、公有领域声明、SVG 封面/书名页）；SE 私有词汇 `se:`；SE 的网址、标识符、主题词体系。

## 2. 已核实的事实（不需要决策）

实测方法：EPUBCheck 5.4.0（含 `--usage`）；Z39.98 词表以 DAISY 官方页面存档为准（官方地址 2026-10 已 404）。

| 问题 | 结论 |
|---|---|
| `epub:prefix` 写在哪 | **只能写在 `<html>` 上**；写在 `<body>` 报 RSC-005 + OPF-028 |
| 用了 `z3998:` 没声明前缀 | EPUBCheck 报 OPF-028 error；**我们现有规则不会自动补**，需新增 |
| `backlink`、`contributors`、`subtitle`、`loi`、`imprint`、`halftitlepage`、`glossterm`、`division` | 在 EPUB 结构语义词表（SSV）内 |
| `label`、`ordinal` | **不在 SSV**；序号用 `z3998:ordinal` |
| `epub:type="endnote"`、`role="doc-endnote"` | **均已弃用**（EPUBCheck 分别报 usage / warning）；注释 `li` 上不写 |
| Z39.98 诗歌 | `verse` 为总类，`poem`、`song`、`hymn`（属 song）、`lyrics` 为子类 |
| Z39.98 戏剧、书信 | `drama`、`scene`、`persona`、`stage-direction`、`letter`、`salutation`、`valediction`、`sender`、`recipient`、`signature`、`postscript` 均存在；**`dateline`、`act` 不存在**（`dateline` 是 SE 的 `se:` 私有词） |
| 无标题的 `section` | 有无 `aria-label` EPUBCheck 都不报错 |
| 无障碍符合性声明 | 采用 EPUB Accessibility **1.1** 写法 `<meta property="dcterms:conformsTo">`（1.0 的 `<link>` 写法作废） |

## 3. 直接修正（缺陷或内部矛盾，不需要决策）

规范文档：

1. `02` §5.7、§6.1：`epub:prefix`「html 或 body」→ 只写在 `<html>`。
2. `02` §6.2、§7.1：删去 `doc-endnote`、`epub:type="endnote"`；`backlink` 改为「SSV 词，与 `role="doc-backlink"` 同写」；§7.3 注释 id 约定统一为 `noteref-N` / `note-N`。
3. `01` §7：`dcterms:conformsTo` 改 1.1 写法；无障碍元数据按固定顺序输出。
4. `04` §4.3（旧 T2）：「第一章」与章名之间补一个全角空格（否则纯文本、目录粘成「第一章侯门庶子」）。
5. `07` SEM-012：删去「注号用 `sup`」，与 04 §4.12（旧 T16）一致。
6. `02`/`03`/`01` 的语言码写法统一：以原书 `dc:language` 为准；新生成时简体 `zh-Hans`、繁体 `zh-Hant`。

代码：

7. `default.css`：`i, cite` 一律斜体 → 默认正体，仅 `:lang(en)` 等西文斜体（中文没有真斜体，书名会被硬拉斜）。
8. `rebuild.py`：同一条注被多处引用时生成重复的 `noteref-N` id → 第 2 处起用 `noteref-N-2`，回链指向第一处。
9. `rebuild.py`：多段注、含引文的注被压成一个 `p` → 保留块结构；末块不是 `p` 时回链单独成段（SE 7.E）。
10. 规则引擎：新增「用了 `z3998:` 必须在 `<html>` 声明 `epub:prefix`」，自动补声明。

## 4. 决策（2026-10-29 用户确认：全部按建议执行）

| # | 问题 | 决定 |
|---|---|---|
| D1 | 「第一章 一切从这里开始」是否用 `hgroup` 拆成序号 + 章名 | **不拆**，整体留在一个 `h` 里。`hgroup` 里的 `p` 不算标题，拆开后目录和读屏只剩「第一章」。`hgroup` 只用于真正的副标题 |
| D2 | 引文/题记的出处（「——梁启超」）用什么写 | **保留现有 `p.attribution`**，放在 `blockquote` 内（与 SE 位置一致，现有模板不变）；输入书里的 `footer`、`p.source` 照样识别 |
| D3 | 书信容器 | 叙事中引用的信用 `blockquote`，书信集里的整封信用 `section`；两者都标 `z3998:letter`，称呼、落款、附言用对应 `z3998:` 词 |
| D4 | 诗歌结构 | **统一为 SE 写法**：一节诗一个 `p`，每行一个 `span`，行间 `<br/>`，缩进用 `indent-N` 类；整首 `z3998:poem`、片段 `z3998:verse`；`04` §4.7（旧 T9）重写，保留中文居中/楷体习惯 |
| D5 | 后记/跋与尾声/结语的分区 | 尾声、结语归正文（body），后记、跋归后置部分（back）；判断不了时交用户确认 |
| D6 | 无标题的献辞页、题词页 | 用 `section` + `aria-label`（替换现行的 `div`） |
| D7 | 尾注要不要按章分组 | **不分**，全书一个连续编号的列表（SE 做法） |
| D8 | 图片缺 alt 时是否用图注填 | **不再复制图注**（读屏会念两遍）：有图注时 `alt=""`，标「待补描述」，留给 M3 大模型生成 |
| D9 | 一次性的特殊样式怎么挂 | 不用 id 选择器（与 03 §10 一致）：出现 3 次及以上用 class，少于 3 次用「类 + 元素」结构选择器 |
| D10 | 全局两端对齐 | **保持** `text-align: justify`（中文惯例；用户设置可覆盖）。SE 不设全局对齐 |
| D11 | 原书没有插图目录时 | 只在报告里提示（图片 ≥ 5 张），不自动新建 |
| D12 | 出处前的破折号 | **保留在文字里**，不交给 CSS 生成（去掉 CSS 后信息不能丢） |
| D13 | 我们拆分文件时写 `data-parent`（SE 的可重组性） | 采用，只在我们自己拆文件时写（`data-*` 是标准 HTML 属性，不属于私有词汇） |
| D14 | 诗集是否每首另起一页 | 默认不分页，做成配置项 |
