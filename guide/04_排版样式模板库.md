# 04 排版样式模板库

**版本 2.0.2（2026-10-31）**　本版仿照 Standard Ebooks《Manual of Style》的写法重写：规则带编号、用命令式、每条可判定，配正例和反例。旧版的 T1–T21 模板已全部并入新的 4.1–4.19 节（对照见文末附录 A）。

## 怎么读

- 规则编号形如 `4.N.M.K`。编号发布后不复用；删除的规则保留编号并写「（已删除）」。检查报告和 `07_质检清单.md` 用这些编号指回规范。
- 规则句末的「〔人工〕」表示只能人工判断，「〔大模型〕」表示需要大模型判断；不带标记的规则都应能被程序检查。
- 句末的「（SE x.y.z）」表示规则来自 Standard Ebooks 手册对应条目（CC0），对照理由见 `08_参照StandardEbooks.md` 和 `_se_notes/`。
- 每节固定结构：规则 → 正例 / 反例 → 识别信号（软件如何认出这类内容）→ CSS（模板增量样式）→ 注意与降级。
- 中文排版数值以 `03` 为准，标点以 `06` 为准；默认样式表见 `03` §11，本文件的 CSS 只是增量。
- 只用标准词汇：EPUB 结构语义词表（SSV）、DPUB-ARIA、DAISY `z3998:`（必须在 `<html>` 上声明 `epub:prefix`）；不用 Standard Ebooks 私有的 `se:`。

## 4.1 通则

本节管全书通用的约定：类名、模板 CSS、语言、`epub:type` 与前缀、id。后面各节只写本节之外的规则。

### 4.1.1 类名

4.1.1.1　输出文档里的 `class` 值必须是下表注册的类名；原书的类名不在表内又无法映射时，去掉并计入报告。

4.1.1.2　新增类名必须登记（类名、元素、用途）后才能使用。

4.1.1.3　类名只用小写字母和连字符，不以数字开头，不带下划线，不用中文。

4.1.1.4　新增类名只表达角色，不表达外观：写 `chapter-summary`，不写 `small-italic`。

    4.1.1.4.1　下表「通用」行里的 `noindent`、`align-*`、`small`、`break-all`、`no-break`、字体角色类、`w-*` 是例外，它们是稳定的工具词汇，不改名。（SE 5.2.3）

4.1.1.5　元素前缀（`p.x`）只在需要提高选择器特异性时才写，类名本身不带元素名。

### 4.1.2 模板 CSS

4.1.2.1　模板 CSS 块的首行必须是 `/* tpl:模板名 */`。

4.1.2.2　输出时只输出被用到的模板；所有模板块排在默认表（03 §11）之后；块与块之间不得有顺序依赖。

4.1.2.3　模板只追加规则，不得修改或覆盖默认表中已有规则的声明。

4.1.2.4　模板选择器的特异性不得低于 (0,1,1)，不得用 `!important`。

4.1.2.5　模板不写 `color`、`background`；装饰灰 `rgba(127,127,127,x)` 和 `.accent` 除外（03 §9）。

4.1.2.6　不得用 id 选择器、`epub:type` 属性选择器做样式钩子。（SE 5.1.2.2、SE 5.10.2 不采用）

4.1.2.7　一次性样式的挂法：同类元素出现 3 次及以上，用 class；少于 3 次，用「类 + 元素」的结构选择器（如 `section.endnotes li`、`blockquote + p`）。

4.1.2.8　整页留白和居中用 `%` margin（相对容器宽度），不得用 `vh`、`calc()` 或 flex 做垂直居中；03 §2 已说明分页模型下 `vh` 因阅读系统而异。

4.1.2.9　不得用 `::before`、`::after` 的 `content` 生成文字或符号；出处前的破折号、序号后的空格都写在文本里。（03 §10；D12）

4.1.2.10　数值以 `guide/03` 为准，标点以 `guide/06` 为准。

### 4.1.3 语言

4.1.3.1　每个内容文档的 `<html>` 同时写 `lang` 和 `xml:lang`，两者同值。

4.1.3.2　语言码以原书 `dc:language` 为准；新生成时，简体写 `zh-Hans`，繁体写 `zh-Hant`。

4.1.3.3　一个块里所有子元素都是同一种外语时，`lang`/`xml:lang` 写在该块的容器上，不逐段、逐词重复。（SE 5.3.1.3）

4.1.3.4　整个标题是外文时，`lang`/`xml:lang` 写在 `h*` 元素上（`hgroup` 里则写在对应的 `p` 上），不另包 `span`。（SE 7.2.7）

4.1.3.5　正文中连续两个及以上西文词，或含非 ASCII 拉丁字母的串，或书名号内的外文书名，用 `<span lang="…" xml:lang="…">` 标注语言；单个缩写、常见品牌名（GDP、iPhone）不标。（SE 5.3.1.2）

4.1.3.6　语言码无法唯一判定时，不自动写入，交大模型或用户确认。〔大模型〕

4.1.3.7　不得用 `<i>` 表示外文；中文没有真斜体（03 §7.7）。

**正例**
```html
<html xmlns="http://www.w3.org/1999/xhtml" xmlns:epub="http://www.idpf.org/2007/ops" lang="zh-Hans" xml:lang="zh-Hans">
	<body>
		<section epub:type="chapter" role="doc-chapter" id="chapter-004">
			<h2 class="chapter-title" lang="en" xml:lang="en">Chapter Four</h2>
			<p>他在门口停了停，说了一句<span lang="en" xml:lang="en">never mind it</span>，转身走了。</p>
		</section>
	</body>
</html>
```

**反例**
```html
<p>他说了一句<i>never mind it</i>。</p>            <!-- 用斜体冒充语言标注 -->
<html lang="zh-CN">                                  <!-- 缺 xml:lang；新生成的简体应写 zh-Hans -->
```

### 4.1.4 `epub:type` 与前缀

4.1.4.1　软件生成的 `epub:type` 值只能来自 EPUB 结构语义词表（SSV）或 Z39.98 词表（`z3998:` 前缀）；不得用 `se:` 等其他词表。

    4.1.4.1.1　输入书中已声明前缀的其他词表值，原样保留，不报错、不改写。

4.1.4.2　SSV 与 `z3998:` 都有同义词时，用 SSV 的值。（SE 4.3.2）

4.1.4.3　使用 `z3998:` 值的文档，必须在 `<html>` 上声明 `epub:prefix="z3998: http://www.daisy.org/z3998/2012/vocab/structure/"`，并已声明 `xmlns:epub`。

    4.1.4.3.1　`epub:prefix` 只能写在 `<html>` 上；写在 `<body>` 上无效。（EPUBCheck 实测：RSC-005 + OPF-028）

    4.1.4.3.2　用了 `z3998:` 而未声明时，自动补声明；不想声明时，整个 `z3998:` 值都省略，不得半声明。

4.1.4.4　`label`、`ordinal` 不在 SSV 内，不得作为不带前缀的 `epub:type` 值；序号只能写 `z3998:ordinal`。

4.1.4.5　`epub:type` 有对应的 DPUB-ARIA `doc-*` role 时，两者同写（如 `epub:type="dedication" role="doc-dedication"`）。

4.1.4.6　不在 `h1`–`h6` 上写 `epub:type="title"`；一个元素的 `epub:type` 值不超过 3 个。

4.1.4.7　不写已弃用的 `epub:type="endnote"`、`role="doc-endnote"`。

**正例**
```html
<html xmlns="http://www.w3.org/1999/xhtml" xmlns:epub="http://www.idpf.org/2007/ops"
      epub:prefix="z3998: http://www.daisy.org/z3998/2012/vocab/structure/" lang="zh-Hans" xml:lang="zh-Hans">
	<body epub:type="bodymatter">
		<section epub:type="chapter" role="doc-chapter" id="chapter-001">
			<h2 class="chapter-title"><span epub:type="z3998:ordinal">第一章</span>　开端</h2>
```

**反例**
```html
<span epub:type="ordinal">第一章</span>     <!-- ordinal 不在 SSV，缺 z3998: 前缀 -->
<span epub:type="label">第</span>           <!-- label 不在 SSV -->
<body epub:prefix="z3998: …">                 <!-- epub:prefix 写在 body 上无效 -->
```

### 4.1.5 id

4.1.5.1　每个文件的根 `section` 必须有 `id`；缺失时取文件名主干（`chapter-003.xhtml` 取 `chapter-003`）。（SE 5.1.1.2）

4.1.5.2　已有的 id 一律保留，不为了与文件名一致而改名。

4.1.5.3　新生成的 id 只用于链接目标：nav 条目、`noteref`/`backlink`、页码标记、图表目录和正文交叉引用、术语引用。（SE 5.1.2.1）

4.1.5.4　新生成的 id 只用小写英文字母、数字和连字符，以字母开头，不含汉字；需要序号时用流水号，不用拼音转写。

4.1.5.5　没有专用约定的元素，id 写作 `<所属 section 的 id>-<元素名>-<N>`，N 是该元素在所属 section 内按文档序的序号，从 1 起。（SE 5.1.2.7）

4.1.5.6　有专用约定的 id 沿用专用写法：`noteref-N`、`note-N`、`figure-N`、`table-N`、`term-N`，N 为全书流水号。

4.1.5.7　新生成的 id 在全书范围内唯一；存量 id 只要求在本文件内唯一。（SE 5.1.2.9）

4.1.5.8　一个文件含多个并列单元（如「附录一」「附录二」合在一页）时，每个单元的 `section` 取「假如独立成文件时的文件名主干」作 id（`appendix-a`、`appendix-b`），日后拆分时 id 不变。（SE 5.1.1.3）

4.1.5.9　nav 条目的链接目标是所属 `section` 的 id，不指向 `h{n}` 一类的流水号；`section` 缺 id 时先按 4.1.5.1 补。

**正例**
```html
<section epub:type="chapter" role="doc-chapter" id="chapter-003">   <!-- 文件 chapter-003.xhtml -->
	<h2 class="chapter-title">第三章　转折</h2>
	<section id="chapter-003-section-1"><h3>一、起因</h3></section>
</section>
```

**反例**
```html
<section epub:type="chapter" id="第三章">…</section>   <!-- id 含汉字 -->
<h1 id="h27">第三章　转折</h1>                          <!-- 流水号 id 绑在标题上，插入新标题后漂移 -->
```

### 识别信号

本节是通则，不做内容识别。检查项：`class` 不在注册表内；`epub:type` 用了 `z3998:` 而 `<html>` 未声明；`epub:prefix` 写在非 `<html>` 元素上；`<html>` 缺 `xml:lang`；根 `section` 缺 id；id 含汉字。均为置信度 A（自动修复），`lang` 码不确定的归 C。

### CSS

无（模板 CSS 的通用约定见 4.1.2）。

### 注意与降级

- `epub:type`、`role` 在不支持的阅读器上被忽略，内容不受影响；`z3998:` 声明缺失会让 EPUBCheck 报错，但不影响阅读。
- 输入书里带 `se:` 或其他词表值的，保留即可，不要因为本节规则删掉。

## 4.2 文件与分节

本节适用于内容文档的根结构、`section`/`article` 的使用、无标题页和拆分文件时的父子关系。

### 4.2.1 根结构

4.2.1.1　`<body>` 的直接子元素只能是 `section`、`article`、`nav`；不得放裸 `div`、`p`、`h*`。封面页（单图）和导航文档豁免。（SE 7.1.1）

4.2.1.2　每个文件有一个根 `section`，承载 `epub:type` 和 `role`；文件含多个并列单元时，每个单元各有一个 `section`。

4.2.1.3　分区由 `<body>` 上的 `epub:type="frontmatter"`、`"bodymatter"` 或 `"backmatter"` 表示；`afterword`（后记、跋）不得出现在 `bodymatter` 内。

4.2.1.4　输入书里 `body > div` 且 `div` 含标题时，把标签改成 `section`；`body` 下有多个并列根时，外包一层 `section`。

**正例**
```html
<body epub:type="bodymatter">
	<section epub:type="chapter" role="doc-chapter" id="chapter-001">
		<h2 class="chapter-title">第一章　开端</h2>
		<p>……</p>
	</section>
</body>
```

**反例**
```html
<body>
	<div class="chapter"><h2>第一章　开端</h2><p>……</p></div>
</body>
```

### 4.2.2 `section` 与 `article`

4.2.2.1　`section` 用于作品的主要结构划分：部、卷、章、节。

4.2.2.2　「部」「卷」用 `epub:type="part"`、`role="doc-part"`；介于部与章之间的「编」「辑」「篇」「集」，或章内的大划分，用 `epub:type="division"`。（SE 7.1.2）

4.2.2.3　`article` 只用于可以独立流通的单项：杂志文章，以及诗词曲选、箴言集、短札集、短篇集里的单篇。（SE 7.1.3）

    4.2.2.3.1　长篇小说中插入的诗不用 `article`。

4.2.2.4　短单项合集（诗词曲选、箴言集）可以放在一个文件里，每项一个 `article`；是否让每项另起一页由配置决定，默认不分页。（SE 7.1.3.1；D14）

4.2.2.5　纯样式分组用 `div`，不用 `section`。

### 4.2.3 无标题页

4.2.3.1　没有标题的 `section`，必须有 `aria-label`；没有标题又没有结构语义的内容块，用 `div`，不用 `section`。（SE 7.2.8；D6）

4.2.3.2　无标题但有结构语义的页（献辞、题词、无题名的卷首语）写作 `<section epub:type="…" role="doc-…" aria-label="…" class="no-head">`，`aria-label` 写中文页名（「献词」「题词」）。

4.2.3.3　`class="no-head"` 只用于没有标题的 `section`，作用是顶部留白，避免内容贴页顶。

4.2.3.4　无标题的页不得标 `epub:type="chapter"`。

**正例**
```html
<body epub:type="frontmatter">
	<section epub:type="dedication" role="doc-dedication" aria-label="献词" class="no-head dedication">
		<p>献给母亲</p>
	</section>
</body>
```

**反例**
```html
<section epub:type="chapter" role="doc-chapter">     <!-- 无标题、无 aria-label，还标成了 chapter -->
	<p>献给母亲</p>
</section>
<div epub:type="dedication"><p>献给母亲</p></div>    <!-- 有结构语义的页用了 div -->
```

### 4.2.4 标题位置与可重组

4.2.4.1　有标题的 `section`/`article`，第一个子元素必须是标题块：`h1`–`h6`、`hgroup` 或 `header`。（SE 7.1.4）

4.2.4.2　每个内容文档首个标题的数字，必须等于它在 nav 中的深度加 1（顶层条目为 `h2`，其下一层为 `h3`），规则见 4.3.1。（SE 7.2.4、SE 7.1.5）

4.2.4.3　软件自己拆分文件时，新文件的顶层 `section` 必须写 `data-parent`，值为原父 `section` 的 id；父 `section` 没有 id 时先按 4.1.5.1 补。（SE 7.1.5.1；D13）

    4.2.4.3.1　输入书已有 `data-parent` 时保留，并校验：目标 id 存在、目标文件在 spine 中位于本文件之前、本文件的标题层级等于父层级加 1。

4.2.4.4　拆分前后，被拆出的 `section` 的 id 不变。

**正例**（部页与章页分在两个文件；章文件由拆分产生）
```html
<!-- part-01.xhtml -->
<body epub:type="bodymatter">
	<section epub:type="part" role="doc-part" id="part-01">
		<h2 class="part-title">第一部　山河</h2>
	</section>
</body>

<!-- chapter-001.xhtml -->
<body epub:type="bodymatter">
	<section epub:type="chapter" role="doc-chapter" id="chapter-001" data-parent="part-01">
		<h3 class="chapter-title">第一章　开端</h3>
		<p>……</p>
	</section>
</body>
```

### 识别信号

- 输入书 `body` 下是 `div` 或多个并列根：置信度 A，改标签或外包 `section`（单个根 `div` 含标题时 `div` 改 `section` 只改标签）。
- `section` 无 `h*` 且无 `aria-label`：置信度 B，自动补 `aria-label`（页名取自 `epub:type`）并列入报告。
- 文件内只有一两个短段、位于前页、开头为「献给」「谨以此书献给」或带出处的引语：见 4.6，按献辞、题记处理。
- `data-parent` 目标不存在或层级不符：置信度 A 报告，不自动改。

### CSS
```css
/* tpl:no-head */
section.no-head{ margin-top:25%; }          /* 与 03 §6.2 章首下沉同值，可调：20%–30% */
```

### 注意与降级

- `margin-top:25%` 相对容器宽度，在窄屏手机约 90px，不占半屏；`vh` 不采用（4.1.2.8）。
- 不支持 `aria-label` 的阅读器上，无标题 `section` 只是少了一个读屏名称，版面不受影响。
- 无标题 `section` 有无 `aria-label`，EPUBCheck 都不报错（已实测）；写 `aria-label` 是为了读屏和 HTML 规范。
- 每项另起一页的 `break-after:page` 属增强写法，各阅读系统支持不一，失效即降级为不分页。

## 4.3 标题

本节适用于全书所有标题：层级数字、章号与章名、副标题、署名、章首提要、章首与篇章页、节标题。书名页的 `h1` 见 4.14。

### 4.3.1 层级

4.3.1.1　`h1` 只用于书名页的书名；其余所有标题从 `h2` 起。（SE 7.2.3）

4.3.1.2　标题的数字表示它在全书中的层级，不是在本文件中的层级。（SE 7.2.4）

    4.3.1.2.1　没有「部」「卷」的书：章为 `h2`，节为 `h3`，小节为 `h4`。

    4.3.1.2.2　有「部」「卷」的书：部为 `h2`，章为 `h3`，节为 `h4`，小节为 `h5`。

    4.3.1.2.3　前言、序、后记、注释、附录等与章同级的文件，标题层级与章相同。

    4.3.1.2.4　书没有书名页时，章仍用 `h2`，不因此升为 `h1`。

4.3.1.3　同类标题（所有章、所有部）必须同级；不得跳级（`h2` 之后直接出现 `h4` 是错误）。

4.3.1.4　一个文件里，最高级标题只出现一次；文件含多个并列单元时，每个单元各有一个。

4.3.1.5　章首标题（章、前言、后记等每文件的首个标题）必须带 `class="chapter-title"`，才有章首的下沉样式；部标题带 `class="part-title"`。

4.3.1.6　`h*` 的直接父元素必须是 `section`、`article`、`header` 或 `hgroup`，不得放进 `div`。（SE 7.2.5）

4.3.1.7　结构划分的标题一律用 `h*`，不得用加粗的 `p` 冒充；标题进不进目录由 nav 决定，与是否用 `h*` 无关。

4.3.1.8　nav 的嵌套深度与标题数字一致：顶层条目对应 `h2`，其下一层对应 `h3`。

**正例**（无部）
```html
<section epub:type="chapter" role="doc-chapter" id="chapter-002">
	<h2 class="chapter-title">第二章　远行</h2>
	<section id="chapter-002-section-1">
		<h3>一、出发</h3>
		<p>……</p>
	</section>
</section>
```

**反例**
```html
<h1>第二章　远行</h1>                       <!-- h1 留给书名页 -->
<section><h2>第二章</h2><h4>一、出发</h4></section>   <!-- 跳级 -->
<div class="chapter-head"><h2>第二章　远行</h2></div>  <!-- 标题放进 div -->
<p><b>一、出发</b></p>                       <!-- 加粗 p 冒充标题 -->
```

### 4.3.2 章号与章名

4.3.2.1　「第一章　开端」整体放在一个 `h*` 里；不得用 `hgroup` 把章号和章名拆成两个元素。（D1）

4.3.2.2　章号与章名之间必须有一个全角空格（U+3000）；不得用半角空格、冒号、`·` 或不留空。

4.3.2.3　只有章号（「第五章」）、只有章名（「楔子」）、章号加章名，三种形式都写成一个 `h*`，文本原样保留。

4.3.2.4　标题文本是纯文字：不含句末句号，不含页码，不含 `<br/>`。

4.3.2.5　章号与章名想分两行显示时，把两部分包进 `span.title-num` 与 `span.title-name`，两个 `span` 之间仍保留一个全角空格文本节点；两行效果由 CSS `display:block` 实现。

4.3.2.6　序号可以包进 `<span epub:type="z3998:ordinal">`，是可选的；只有文档已按 4.1.4.3 声明前缀时才写。（SE 7.2.9.2）

4.3.2.7　不写 `z3998:roman`；不拆 label（`第`、`章`）。

4.3.2.8　nav 条目的文字必须等于对应标题的纯文本（折叠空白后），不得出现序号与章名粘连。

**正例**
```html
<h2 class="chapter-title">第一章　开端</h2>

<h2 class="chapter-title"><span class="title-num" epub:type="z3998:ordinal">第一章</span>　<span class="title-name">侯门庶子</span></h2>

<h2 class="chapter-title">楔子</h2>
```

**反例**
```html
<hgroup><h2>第一章</h2><p>开端</p></hgroup>        <!-- 目录和读屏只剩「第一章」 -->
<h2 class="chapter-title">第一章 开端</h2>          <!-- 半角空格 -->
<h2 class="chapter-title">第一章开端</h2>            <!-- 无空格，目录里粘成一串 -->
<h2 class="chapter-title">第一章<br/>开端</h2>       <!-- 标题内 br -->
<h2 class="chapter-title"><span epub:type="ordinal">第一章</span>　开端</h2>   <!-- ordinal 不带前缀 -->
```

### 4.3.3 副标题

4.3.3.1　标题带真正的副标题时，用 `hgroup`，内部先是一个 `h*`，后跟一个或多个 `p`；`hgroup` 只用于主标题加副标题。（SE 7.2.6；D1）

4.3.3.2　副标题 `p` 写 `class="subtitle" epub:type="subtitle" role="doc-subtitle"`。

4.3.3.3　只有一个子元素的 `hgroup` 拆包，不保留。（SE 7.2.6.2）

4.3.3.4　副标题保留原书的括号与标点，不删不加。

4.3.3.5　副标题只在原书有，且识别为副题时才拆进 `hgroup`；拿不准的，不拆，整体仍留在 `h*` 里。〔大模型〕

4.3.3.6　nav 条目和 `<title>` 只取 `h*` 的文字（主标题），不含副标题。

**正例**
```html
<hgroup>
	<h2 class="chapter-title">第三章　转折</h2>
	<p class="subtitle" epub:type="subtitle" role="doc-subtitle">（一个司机的故事）</p>
</hgroup>
```

**反例**
```html
<hgroup><h2>转折</h2></hgroup>                        <!-- 单子元素 hgroup -->
<h2>第三章　转折<br/><small>（一个司机的故事）</small></h2>   <!-- 副标题挤进标题 -->
```

### 4.3.4 集合单项的署名与标题块

4.3.4.1　集合单项（`article`）有作者署名时，标题与署名放进 `header`：`h*` 加 `p.byline`。（SE 7.2.10.11）

4.3.4.2　`header` 里至少有一个块级子元素，不得含裸文本；输入书的 `header` 含裸文本时，把文本包进 `p`。（SE 5.5.1）

4.3.4.3　`header` 只在标题之外还有署名、题记或副标题时才写；只有标题时不加。

4.3.4.4　题记可以放在 `header` 内，也可以紧跟标题块之后；识别输入书时两种位置都接受。（SE 7.4.5.2）

4.3.4.5　不用 `epub:type="contributors"`，署名行只用 `class="byline"`。

**正例**
```html
<article id="poem-017">
	<header>
		<h2>登幽州台歌</h2>
		<p class="byline">陈子昂</p>
	</header>
	<p>……</p>
</article>
```

### 4.3.5 章首提要

4.3.5.1　紧跟章标题的提要段（回前提要、本章导读、内容提要）写作 `<p class="chapter-summary">`，放在标题块之后、正文之前。（SE 7.2.11）

4.3.5.2　章首提要不加 `epub:type`；不得用 `bridgehead`，它在 SSV 里是不进层级的小标题，不表示摘要。

4.3.5.3　提要中的破折号写 `——`，句末标点遵循 `guide/06`。

**正例**
```html
<section epub:type="chapter" role="doc-chapter" id="chapter-005">
	<h2 class="chapter-title">第五回　贾夫人仙逝扬州城</h2>
	<p class="chapter-summary">本回写黛玉初到贾府——寄人篱下，步步留心。</p>
	<p>……</p>
</section>
```

### 4.3.6 章首与篇章页

4.3.6.1　篇章页（文件内只有部或卷的标题，及副标题、题记、图片，没有正文）的根是 `section epub:type="part" role="doc-part"`，标题为 `h2.part-title`。

4.3.6.2　篇章页用图片时，用 `<img>`，不得靠 `body` 背景图。

4.3.6.3　章首标题后的第一个正文段照常缩进；首段是否无缩进、是否首字下沉见 4.5。

4.3.6.4　节标题（章内的 `h3` 及以下）不得带 `chapter-title` 或 `part-title`。

4.3.6.5　`letter-spacing` 只用于章号这类短字，不用于整个标题；居中的元素用了 `letter-spacing` 时，加同值 `padding-left` 补偿末字后的留白。

4.3.6.6　章内第一级标题带 `class="section-title"`，第二级带 `class="subsection-title"`；更深的层级不带角色类，用默认的数字兜底样式。标题的样式由角色类决定，与 `h` 的数字无关（03 §6.2）。

**正例**（篇章页，副标题加题记）
```html
<section epub:type="part" role="doc-part" id="part-01">
	<hgroup>
		<h2 class="part-title">第一部　山河</h2>
		<p class="subtitle" epub:type="subtitle" role="doc-subtitle">1937–1945</p>
	</hgroup>
	<blockquote class="epigraph" epub:type="epigraph" role="doc-epigraph">
		<p>……</p>
		<p class="attribution">——某某</p>
	</blockquote>
</section>
```

### 4.3.7 节标题与同名标题

4.3.7.1　节标题用 `h3`–`h6`（层级见 4.3.1），无编号的小标题也用 `h*`，不用加粗 `p`。

4.3.7.2　同一层级的编号写法一致：`一、` 对应一级节，`（一）` 对应下一级，`1.` 对应再下一级；同一种写法不得对应不同层级。

4.3.7.3　标题全部为拉丁字母而没有 `lang` 时，报告；补 `lang` 见 4.1.3.4。

4.3.7.4　同名标题（诗集里多首《无题》、同一词牌的多首词）在全书中出现 3 次及以上时，nav 条目的文字可以写作「标题（首句）」；`h*` 本身不改。（SE 7.2.10.7）

    4.3.7.4.1　nav 文字以 `h*` 文字开头并带括注时，不算与标题不一致。

**正例**
```html
<h3>一、缘起</h3>
<h4>（一）背景</h4>
<h4 class="align-center">（二）居中小标题</h4>
```

```html
<!-- nav 中的同名条目 -->
<li><a href="poems.xhtml#poem-017">无题（相见时难别亦难）</a></li>
<li><a href="poems.xhtml#poem-018">无题（昨夜星辰昨夜风）</a></li>
```

### 识别信号

**章首标题**（置信度：文件首个标题块高；其余中）

- 文件首个标题块，是一个短段（≤30 字）、无句末标点、位于文件首。
- 匹配 `^第[0-9零〇一二三四五六七八九十百千两]+[章节回卷部篇集幕]`、`Chapter\s*\d+`、`序章|楔子|引子|前言|后记|尾声|番外|附录`。
- 三种组合：仅序号（`第五章`）、仅章名（`楔子`）、序号加章名；章号与章名分在两行、或同行以空格/冒号/`·` 分隔的，规范成「序号　章名」一个标题（中，列入报告）。

**篇章页**：文件内仅有一个标题（及副题、题记、图片）而无正文（高）。

**各级标题**

- 已有 `h2–h6`（强，但按 4.3.1 重新校正数字，不依赖原标签）。
- 独占一段、≤25 字、无句末标点、前后为长段落；以 `一、`、`（一）`、`1.`、`1.1` 开头；字号/加粗/居中与周围不同。
- 层级由编号模式聚类：同一模式为同一级，输出不跳级（`h2` 直接到 `h4` 视为错误，自动修数字）。

**副标题**：标题后紧随的短段（样式小于标题、居中或楷体），置信度低，交大模型；低置信度时不拆。

**章首提要**：紧随章标题的短段，文本含「本章」「导读」「提要」，或各分句以 `——`、`；` 分隔（中，列入确认清单）。

**数字校正**：整书标题数字众数以 4.3.1.2 为准校正：原书每章 `h1` 的，章改 `h2`；有「部」的，部 `h2`、章 `h3`，并让 nav 嵌套与之一致。统计时书名页、半书名页、封面、版权页文件排除在外。

### CSS
```css
/* tpl:chapter-head */
h2 .title-num, h3 .title-num{ margin-bottom:.3em; font-size:.75em; letter-spacing:.1em; }   /* 章号小于章名 */
h2 .title-name, h3 .title-name{ font-size:1em; }
h3.chapter-title{ margin:25% 0 1.5em; font-size:1.5em; }                 /* 有「部」时章为 h3；h2.chapter-title 默认表已有 */
.part-title + .subtitle{ margin-top:0; text-align:center; }
hgroup{ break-after:avoid; page-break-after:avoid; break-inside:avoid; page-break-inside:avoid; }
hgroup p.subtitle{ text-indent:0; }
header{ break-after:avoid; page-break-after:avoid; break-inside:avoid; page-break-inside:avoid; }
header p.byline{ margin:-.4em 0 1em; font-size:.9em; text-indent:0; text-align:left;
  font-family:"Kaiti SC","STKaiti","KaiTi",serif; }
p.chapter-summary{ margin:0 2em 1.5em; font-size:.95em; text-indent:0; text-align:left;
  font-family:"Kaiti SC","STKaiti","KaiTi",serif; }
```

### 注意与降级

- 默认表的 `.chapter-title` 为 (0,1,0)，已压过 `h2`、`h3` 元素选择器，所以章首样式靠 class 而不靠标签数字；这也使得章用 `h2` 时仍有 1.5em 与 25% 下沉。
- `hgroup` 内 `p` 不是标题：目录、读屏标题列表、阅读器大纲都只取 `h*`，所以只在真正的副标题时才用它（D1）。EPUBCheck 对 `hgroup > h* + p` 的接受度【需实测】；`p` 上 `role="doc-subtitle"` 的合法性【需实测】。
- 不支持 `hgroup` 的阅读器当它是普通块，两个子元素依次显示，内容不丢。
- 标题数字下沉一级后，节标题的默认外观随数字变弱（有部的书节标题为 `h4`，粗体 1.05em）；如需保持节标题外观一致，由 03 §6.2 另行调整。
- 章号的 `letter-spacing` 使居中时末字后留白，需要时给居中元素加同值 `padding-left`。
- 降级：丢 CSS 后标题仍是 `h*`，序号与章名之间有一个全角空格，目录文字不粘连。

## 4.4 书内目录页

本节适用于书中可见的目录页：导航文档 `nav epub:type="toc"` 兼作可见目录，或独立目录页。nav 本身的写法见 `guide/01`。

### 4.4.1 结构

4.4.1.1　目录是一个 `ol`，每个条目是 `li > a`；有下级时，`li` 内再嵌一个 `ol`。

4.4.1.2　导航文档里的可见目录写作 `<nav epub:type="toc" id="toc" role="doc-toc" class="toc">`，其中先是目录标题，再是 `ol`。

4.4.1.3　目录标题用 `h2`，带 `class="chapter-title"`，文字写「目录」；用 `align-center` 居中时保留。

4.4.1.4　独立的可见目录页（不是导航文档）用 `<section epub:type="toc" role="doc-toc" class="toc">`。【需实测：EPUBCheck 对内容文档中 `epub:type="toc"` 的态度】

4.4.1.5　目录条目不含目录页自身。

4.4.1.6　页码、点线引导符一律删除，重建成链接列表；不得在条目里写页码。

4.4.1.7　条目文字等于对应标题的纯文本，序号与章名之间保留一个全角空格（4.3.2.8）；目录里只收标题，不收副标题。

4.4.1.8　目录的嵌套深度与标题层级一致：「部」是顶层条目，其下的章嵌套在内；无「部」时章是顶层条目。（SE 7.1.5）

4.4.1.9　`nav epub:type="landmarks"`、`nav epub:type="page-list"` 加 `hidden` 属性，不在可见目录里显示。

4.4.1.10　目录页字体、字号全书统一。

**正例**
```html
<nav epub:type="toc" id="toc" role="doc-toc" class="toc toc-hang">
	<h2 class="chapter-title align-center">目录</h2>
	<ol>
		<li class="toc-part"><a href="part-01.xhtml">第一部　山河</a>
			<ol>
				<li><a href="chapter-001.xhtml">第一章　开端</a>
					<ol><li><a href="chapter-001.xhtml#chapter-001-section-1">一、缘起</a></li></ol></li>
				<li><a href="chapter-002.xhtml">第二章　远行</a></li>
			</ol></li>
	</ol>
</nav>
<nav epub:type="landmarks" hidden="hidden">
	<ol><li><a epub:type="bodymatter" href="chapter-001.xhtml">正文</a></li></ol>
</nav>
```

**反例**
```html
<p>第一章　开端……………………3</p>              <!-- 点线加页码，没有链接 -->
<li><a href="c01.xhtml">第一章开端</a></li>       <!-- 序号与章名粘连 -->
<li><a href="c01.xhtml">第一章　开端</a></li>
<li><a href="c01.xhtml#s1">一、缘起</a></li>      <!-- 小节与章并列，丢了层级 -->
```

### 4.4.2 变体

4.4.2.1　条目带序号（`第一章`、`一、`）时，在根元素上加 `toc-hang`，使回行与序号后文字对齐；条目无序号时不加。

4.4.2.2　篇名（部、卷）条目的 `li` 加 `class="toc-part"`，粗体显示。

4.4.2.3　`toc-hang` 悬挂宽度等于最长序号的字数加 1；软件按全书计算，写入 CSS 的 `em` 值。

### 识别信号

- 已有 `nav epub:type="toc"`（强）。
- 标题为「目录」「目　录」「Contents」；一列 `<a>`；或「章名……页码」行（点线、页码）；文件位于前页（版权页之后）。
- 纸书目录的页码、点线引导符必须删除，重建成链接列表（置信度 A）。
- 不能与标题配对的目录项（原目录里有、正文里没有的）：置信度 C，列入确认清单。

### CSS
```css
/* tpl:toc */
.toc ol{ list-style:none; margin:0; padding:0; }
.toc ol ol{ padding-left:1.5em; }                      /* [书] 每级退 1–2 字 */
.toc li{ margin:.4em 0; line-height:1.5; text-indent:0; }
.toc li a{ text-decoration:none; color:inherit; }       /* 目录内链接可去下划线 */
.toc.toc-hang li > a{ display:block; margin-left:2.5em; text-indent:-2.5em; }   /* 有序号：回行齐字；2.5em = 最长序号字数 + 1，软件按全书计算 */
.toc li.toc-part > a{ font-weight:bold; }              /* 篇名 */
```

### 注意与降级

- 无序号目录：回行缩格用默认即可；有序号：加 `toc-hang`。
- 若目录是导航文档本身，`h2.chapter-title` 的 25% 下沉保留，`align-center` 可选。
- `color:inherit` 是 `a` 的色值例外，不引入新的色值（03 §9）。
- 降级：丢 CSS 后仍是可点击的嵌套有序列表。

## 4.5 正文段落

本节适用于普通叙述性段落：缩进与接排、空行、场景分隔、首字下沉。

### 4.5.1 段落

4.5.1.1　每个段落是一个 `<p>`；不得用空 `<p>`、连续 `<br/>` 或 `div` 分段。

4.5.1.2　首行缩进由默认表的 `text-indent:2em` 承担；不得用全角空格、`&emsp;` 或空格手写缩进。

4.5.1.3　缩进与段距二选一（03 §5）；默认用缩进，不再给 `p` 加 `margin`。

4.5.1.4　标题后的第一个正文段同样缩进，不默认无缩进（03 §5）。

4.5.1.5　被引文、图、表、诗等块元素打断后，接着上文同一段的续句，写作 `<p class="noindent">`；打断之后另起的新段照常缩进。

4.5.1.6　原稿（PDF、纸书）明确无缩进的段落，保留 `class="noindent"`。

4.5.1.7　原文用空行或空段隔开的场景切换，转为 `<p class="gap">`（`margin-top:1.5em`），不得保留空段。

4.5.1.8　不得为排版而在 `p` 上写内联 `style`；对齐用 `align-left`/`align-center`/`align-right`。

**正例**
```html
<p>他在信中写道：</p>
<blockquote>
	<p>今日事势，譬之于病，……</p>
</blockquote>
<p class="noindent">这段话至今读来仍令人心惊。</p>
<p>第二天一早，他便动身了。</p>
<p class="gap">三年后，他再次回到这里。</p>
```

**反例**
```html
<p>　　近日，解放军报发表文章……</p>          <!-- 手写全角空格缩进 -->
<p><br/></p>                                    <!-- 空段做间隔 -->
<p style="text-indent:0">……</p>               <!-- 内联样式 -->
<p>他在信中写道：</p><blockquote>…</blockquote><p>这段话……</p>   <!-- 续句本应 noindent -->
```

### 4.5.2 场景分隔

4.5.2.1　主题或场景转换用 `<hr/>` 或 `<p class="sep" role="separator">` 二选一，全书统一；`hr` 只表示转换，不得用于装饰性边线。（SE 4.2.8）

4.5.2.2　原书用 `<hr/>`（含线条图片、`——`）的，用 `hr`；原书用文字符号（`＊　＊　＊`、`***`、`◇◇◇`）独占一段的，用 `p.sep`。

4.5.2.3　`p.sep` 的文字统一为 `＊　＊　＊`（符号间一个全角空格），符号写法以 `guide/06` 为准。

4.5.2.4　场景分隔不得出现在 `section` 的第一个或最后一个子元素位置。

4.5.2.5　分隔之后的首段照常缩进。

**正例**
```html
<p>……话音刚落，灯就灭了。</p>
<p class="sep" role="separator">＊　＊　＊</p>
<p>第二天清晨，雨停了。</p>

<p>……话音刚落，灯就灭了。</p>
<hr/>
<p>第二天清晨，雨停了。</p>
```

**反例**
```html
<p>***</p>                      <!-- 无 sep 类，符号写法与 06 不一致 -->
<p>＊ ＊ ＊</p>                  <!-- 半角空格 -->
<hr style="border:2px solid black"/>
```

### 4.5.3 首字下沉

4.5.3.1　首字下沉是可选主题，默认关闭；只有用户启用时才输出。

4.5.3.2　只对章首标题后的第一个正文段使用，且段长不少于 40 字；更短的段不下沉。

4.5.3.3　首字不得是数字或西文字母；首字符是开引号时，把「开引号加首字」整体作为下沉单位。

4.5.3.4　下沉字写作 `<span class="dropcap">`，不用 `::first-letter` 和 `initial-letter`。

4.5.3.5　带 `dropcap` 的段同时加 `class="noindent"`（浮动字已占位）。

4.5.3.6　一个 `section` 内最多一个 `dropcap`。

**正例**
```html
<p class="noindent"><span class="dropcap">那</span>天夜里，风很大，吹得窗纸一阵阵响，……</p>

<p class="noindent"><span class="dropcap">“那</span>天夜里，”他说，“风很大……</p>
```

**反例**
```html
<p><span class="dropcap">3</span>月的一天……</p>           <!-- 首字是数字；且缺 noindent -->
<p class="dropcap-para">那天夜里……</p>                     <!-- 用 ::first-letter 之类的整段类 -->
```

### 识别信号

**接排与无缩进**（置信度：中）
- 引文、图、表、诗之后接着上文同一段的续句；原稿明确无缩进的段落。
- 标题后首段**不**默认无缩进（03 §5）。

**空行**：原文用空行/空段隔开的场景切换，已转为 `margin`（置信度高）。

**场景分隔**：独段 `* * *`、`***`、`◇◇◇`、`——`、`<hr/>`（置信度高）。

**首字下沉**：用户启用该主题；章首标题后的第一个正文段（高）；首字符不是数字、西文；首字符为开引号时用「引号加首字」（中）；段长 ≥ 40 字。

### CSS
```css
/* tpl:paragraph */
p.sep{ margin:1.2em 0; text-indent:0; text-align:center; }

/* tpl:dropcap */
span.dropcap{ float:left; font-size:3.2em; line-height:1; margin:.04em .1em 0 0; text-indent:0; }
```

默认表已含 `p.noindent`、`p.gap`、`hr`，不重复。

### 注意与降级

- 缩进与段距二选一（03 §5）；无缩进主题见 03 §5。
- `3.2em` 等于两行行高（1.6 × 2）；三行下沉用 `4.8em`；字号过大会引起首行排版错位，先在窄屏实测【需实测】。
- `initial-letter` 属性新近出现，支持不一，不采用【需实测】。
- 首字符是标点或引号时，`::first-letter` 行为不稳，所以用 `span` 加 float。
- 降级：段落间由阅读系统的默认段距分隔；丢 CSS 后下沉字成为普通首字。

## 4.6 引文、题记、献辞

本节适用于块引用（他人的文字、文献、古文）、章首与整页题记、卷首语、献辞。引用的诗见 4.7，引用的书信见 4.8。

### 4.6.1 引文

4.6.1.1　块引用用 `<blockquote>`，里面至少有一个 `<p>`，不得裸写文本。（SE 5.8.1）

4.6.1.2　`blockquote` 只用于引用他人的话、叙述中嵌入的文献；仅为缩进排版的内容不用 `blockquote`。

4.6.1.3　多段引文每段一个 `<p>`。

4.6.1.4　块引用已用缩进和字体区分，不再带外层引号；原书带引号的，保留与否由 `guide/06` 的引号风格决定，不得双重标记。

4.6.1.5　紧接在引文后的续句，写作 `<p class="noindent">`，新段照常缩进。

4.6.1.6　引文整块是外语时，`lang`/`xml:lang` 写在 `blockquote` 上（4.1.3.3）。

4.6.1.7　出处写在 `blockquote` 内最后一个子元素：`<p class="attribution">`。（D2）

    4.6.1.7.1　出处文字以 `——` 开头，破折号写在文字里，不交给 CSS 生成。（D12）

    4.6.1.7.2　出处末尾不加句号。（SE 7.4.5.1）

    4.6.1.7.3　出处中的作品名可以包在 `<cite>` 里（可选），人名不得放进 `cite`。

4.6.1.8　输入书里的 `footer`、`p.source`、`p.inscription`，作为出处照样识别，输出时统一为 `p.attribution`。

**正例**
```html
<p>他在信中写道：</p>
<blockquote>
	<p>今日事势，譬之于病，……</p>
	<p class="noindent attribution">——梁启超《少年中国说》</p>
</blockquote>
<p class="noindent">这段话至今读来仍令人心惊。</p>
```

**反例**
```html
<blockquote>今日事势，譬之于病，……</blockquote>              <!-- blockquote 内裸文本 -->
<blockquote><p>“今日事势，譬之于病，……”</p></blockquote>      <!-- 缩进加外层引号，双重标记 -->
<p class="attribution">——梁启超《少年中国说》。</p>            <!-- 出处末尾加句号 -->
<blockquote><p>……</p><footer>梁启超</footer></blockquote>      <!-- 输入书写法，输出应转成 p.attribution -->
<blockquote><p>……</p><p class="attribution">梁启超</p></blockquote>   <!-- 出处缺 —— -->
```

### 4.6.2 章首题记

4.6.2.1　章首或书首的题记写作 `<blockquote class="epigraph" epub:type="epigraph" role="doc-epigraph">`。

4.6.2.2　章首题记紧跟章标题块之后、正文之前，题记不超过 80 字。

4.6.2.3　出处用 `p.attribution`，放在 `blockquote` 内，规则同 4.6.1.7。

4.6.2.4　一处有多条题记时，每条一个 `blockquote.epigraph`，各带自己的 `p.attribution`。（SE 7.4.6.2）

4.6.2.5　题记是诗时，诗的结构按 4.7，容器仍是 `blockquote.epigraph`。

4.6.2.6　题记不超过版心宽度的 2/3，靠左缩进 3em 与普通引文区分。

**正例**
```html
<section epub:type="chapter" role="doc-chapter" id="chapter-003">
	<h2 class="chapter-title">第三章　转折</h2>
	<blockquote class="epigraph" epub:type="epigraph" role="doc-epigraph">
		<p>生年不满百，常怀千岁忧。</p>
		<p class="attribution">——《古诗十九首》</p>
	</blockquote>
	<p>……</p>
</section>
```

**反例**
```html
<div class="epigraph"><p>生年不满百，常怀千岁忧。——《古诗十九首》</p></div>   <!-- div，出处挤在题记行里，无 epub:type -->
```

### 4.6.3 整页题记

4.6.3.1　整页题记（书首题词页）写作 `<section epub:type="epigraph" role="doc-epigraph" aria-label="题词" class="no-head epigraph-page">`，放在 `<body epub:type="frontmatter">` 内。（SE 7.4.6.1、7.4.6.4）

4.6.3.2　整页题记含多条引文时，每条一个 `<blockquote>`，各带 `p.attribution`。（SE 7.4.6.2）

4.6.3.3　整页题记有标题时，按普通 `section` 处理，去掉 `no-head` 和 `aria-label`，标题层级按 4.3.1。

4.6.3.4　整页居中用 `no-head` 的 `%` 上边距，不得用 `vh`。

**正例**
```html
<body epub:type="frontmatter">
	<section epub:type="epigraph" role="doc-epigraph" aria-label="题词" class="no-head epigraph-page">
		<blockquote>
			<p>天地不仁，以万物为刍狗。</p>
			<p class="attribution">——《老子》</p>
		</blockquote>
		<blockquote>
			<p>人生如逆旅，我亦是行人。</p>
			<p class="attribution">——苏轼</p>
		</blockquote>
	</section>
</body>
```

### 4.6.4 卷首语

4.6.4.1　嵌在章首、篇章页的短卷首语（数行、每行短、无出处）写作 `<div class="lead">`，不加 `epub:type`。

4.6.4.2　卷首语独立成页（有自己的文件）时，按内容用 `foreword` 或 `preface`（`guide/02` §3），不用 `div.lead`。

4.6.4.3　卷首语是整段文章而不是短句时，按正文版式（两端对齐，首行缩进 2em），不用居中。

**正例**
```html
<div class="lead">
	<p>这是一本关于……的书。</p>
	<p>献给所有……的人。</p>
</div>
```

### 4.6.5 献辞

4.6.5.1　献辞页写作 `<section epub:type="dedication" role="doc-dedication" aria-label="献词" class="no-head dedication">`，放在 `<body epub:type="frontmatter">` 内。（SE 7.3.1；D6）

4.6.5.2　短献辞（只有 1 段，且不超过 100 字）：居中，不缩进。

4.6.5.3　长献辞（2 段及以上，或总字数超过 100 字）：按正文版式（首行缩进 2em、两端对齐），保留 `epub:type`、`aria-label` 与 `no-head`，不写 `dedication` 类。（SE 7.3.2）

4.6.5.4　原书献辞右对齐、偏右下时，保留原书风格：在 `p` 上写 `align-right`，不写 `dedication` 类。

4.6.5.5　献辞页有标题时，按普通 `section` 处理，标题层级按 4.3.1，去掉 `no-head` 和 `aria-label`。

**正例**
```html
<body epub:type="frontmatter">
	<section epub:type="dedication" role="doc-dedication" aria-label="献词" class="no-head dedication">
		<p>献给我的母亲</p>
	</section>
</body>

<!-- 原书右对齐 -->
<section epub:type="dedication" role="doc-dedication" aria-label="献词" class="no-head">
	<p class="align-right">谨以此书献给所有……的人</p>
</section>
```

**反例**
```html
<div epub:type="dedication"><p>献给我的母亲</p></div>     <!-- 用 div，缺 role 与 aria-label -->
<section epub:type="dedication" class="dedication"><p>……</p></section>   <!-- 无标题也无 aria-label -->
```

### 识别信号

**引文**（置信度：已有 `blockquote` 强）
- 整段被引号包裹；左缩进明显或字体/字号与正文不同；前一段以「：」结尾后的缩进段；连续多段字号小于正文；`<div>` 带 `margin-left`。
- 「冒号结尾，下一段整体引号包围」为中。
- 出处：`blockquote` 末段为 `——…` 开头的短行（建议标 `attribution`）；`footer`、`p.source` 照样识别。

**章首题记**（置信度高）
- 紧随章标题之后、正文之前；≤ 80 字；末尾（或下一行）有 `——人名`、`《书名》`、`—— xxx` 出处；字体/字号与正文不同或居右；常在引号内。
- 位置可在 `header` 内或紧跟标题块之后。

**整页题记**：前页中的短页，仅含一条或数条带出处的引语（高）。

**卷首语**：位于篇章页或章首，数行（≤ 8 行）、每行短、无出处，或标题为「卷首语/开篇语/写在前面」（中，列入报告）。

**献辞**：「献给……」「谨以此书献给」，独占一页（高）。长短判据：段数 ≥ 2 或总字数 > 100 为长献辞。

### CSS
```css
/* tpl:quote */
blockquote + p.noindent{ margin-top:.75em; }
p.attribution{ margin:.4em 0 0; text-indent:0; text-align:right; font-size:.875em; }
blockquote p.attribution{ font-family:inherit; }

/* tpl:epigraph */
blockquote.epigraph{ margin:1em 0 2em 3em; font-size:.95em;
  font-family:"Kaiti SC","STKaiti","KaiTi",serif; }
blockquote.epigraph p{ margin:.2em 0; text-indent:0; text-align:left; }
blockquote.epigraph p.attribution{ margin-top:.4em; text-align:right; }   /* 压过上一行 p 的 text-align:left */
section.epigraph-page > blockquote{ margin:0 2em 1.5em 3em; }
div.lead{ margin:1.5em 2em; font-family:"STFangsong","FangSong",serif; }
div.lead p{ margin:.35em 0; text-indent:0; text-align:center; }

/* tpl:dedication */
section.dedication p{ margin:0 2em .5em; text-indent:0; text-align:center; font-family:inherit; }
```

默认表已含 `blockquote` 基本样式（左 2em，上下 .75em，段距 .35em，楷体，行高 1.5，首行缩进 2em）。

### 注意与降级

- 引文规则：左缩进 2em、上下 .75em、非正文字体、行高略紧（不小于 1.4）。
- `blockquote.epigraph p` 的特异性 (0,1,2) 高于 `p.attribution`，所以题记内的出处右对齐需要单独的 `blockquote.epigraph p.attribution` 规则，否则会被压成左对齐。
- 卷首语若是整段文章，改用 `div.lead p{ text-align:justify; text-indent:2em; }`。
- 整页居中不做垂直居中（4.1.2.8）；`no-head` 的上边距使内容离页顶一段距离。
- `aria-label` 在不支持的阅读器上被忽略，版面不受影响。
- 降级：题记、引文丢 CSS 后回落为普通缩进的 `blockquote`，出处是其最后一段。

## 4.7 诗歌

适用于古诗、词、曲、现代诗、歌词，以及正文、剧本里引用的诗句。结构统一为：**一节诗一个 `p`，每行一个 `span`，行间 `<br/>`**；排版型（居中、居左、词、自适应换行）只由类名和 CSS 决定，不改结构。

### 4.7.1 语义

4.7.1.1　整首诗、词、曲的容器写 `epub:type="z3998:poem"`；词、曲虽可歌，整首仍用 `poem`。（SE 7.5.6）

4.7.1.2　节选、残句、单联引用的容器写 `epub:type="z3998:verse"`。（SE 7.5.6）

4.7.1.3　歌词（流行歌曲、民歌、儿歌，全部或部分）的容器写 `z3998:song`；赞美诗、圣歌、明示为诗偈的佛偈颂写 `z3998:hymn`，拿不准时写 `z3998:song`。不用 `z3998:lyrics`。（SE 7.5.6.1）

4.7.1.4　`epub:type` 只写在诗歌容器（`div`、`blockquote`、`article`）上，一个容器只写一个值；不写在 `p.stanza` 或 `span.line` 上。

4.7.1.5　文档用了 `z3998:` 值，就必须在 `<html>` 上声明 `epub:prefix="z3998: http://www.daisy.org/z3998/2012/vocab/structure/"`；声明只能写在 `<html>`，写在 `<body>` 上无效。缺声明时补上，不得因此删去 `epub:type`。（08 §2、§3.10）

4.7.1.6　行内引一两句诗（嵌在叙述句子里）不算诗歌块，不套本节结构，不加 `epub:type`。

### 4.7.2 结构

4.7.2.1　一节诗是一个 `<p class="stanza">`；节与节之间不放空 `p`、`<br/><br/>`、`<hr/>`。（SE 7.5.1）

4.7.2.2　每个诗行是一个 `<span class="line">`；`p.stanza` 里的文字必须全部在 `span.line` 内，不得有裸文本。（SE 7.5.2）

4.7.2.3　行与行之间写一个 `<br/>`；一节的最后一行后面不加 `<br/>`。（SE 7.5.3）

4.7.2.4　诗行缩进用 `span.line` 上的 `indent-1`、`indent-2`、`indent-3`，最多 3 级；不得用空格、全角空格、`&nbsp;`、`&emsp;` 缩进或对齐。（SE 7.5.4）

4.7.2.5　保留原书的断行；不得为了凑行长重新断行或合并行。〔人工〕

4.7.2.6　不得把一首诗写成「`div.stanza` 里一行一个 `p`」「`pre`」「一个 `p` 里只用 `<br/>` 的裸文本」或「一行一个 `p`」。

4.7.2.7　诗题、作者、小序写在诗歌容器内、第一个 `p.stanza` 之前：诗题 `p.poem-title`，作者 `p.poem-author`，小序 `p.poem-preface`；它们不得带 `stanza` 类，不得用 `span.line`。

4.7.2.8　诗题的元素按位置定：正文或章内独立成篇的诗、`blockquote` 引诗，诗题用 `p.poem-title`，不用 `h1`–`h6`；诗集中作为独立单项（4.7.5）的诗，诗题用 `h`，层级按 4.3。（SE 7.1.3、7.2.1）

4.7.2.9　出处署名（「——《陈拾遗集》」）写 `p.attribution`，放在最后一个 `p.stanza` 之后、容器之内；其末尾不加句号。

4.7.2.10　诗行内的注号放在行末标点之后，仍在该 `span.line` 内。

4.7.2.11　古诗词曲每个 `span.line` 以其自身标点结尾；现代诗保留原书标点，不补标点。〔人工〕

**正例**（整首诗，居中型；完整文档开头写出前缀声明）
```html

	<body>
		<section epub:type="chapter" role="doc-chapter">
			<h2>唐诗选读</h2>

				<p class="stanza">
					<span class="line">前不见古人，后不见来者。</span><br/>

				<p class="attribution">——《陈拾遗集》</p>
			</div>
		</section>
	</body>

```

**正例**（居左型，两节，含缩进行）
```html

	<p class="poem-title">断章</p>
	<p class="poem-author">卞之琳</p>
	<p class="stanza">
		<span class="line">你站在桥上看风景，</span><br/>
		<span class="line indent-1">看风景人在楼上看你。</span>
	</p>
```

**反例**（旧写法：一行一个 `p`，缺语义，全角空格缩进，节无 `p`）

### 4.7.3 排版型

4.7.3.1　每个诗歌容器必须有且仅有一个排版型类：`poem-center`、`poem-left`、`poem-ci`。

4.7.3.2　`poem-center`（居中）用于规整的五言、七言绝句和律诗：至少 2 行，各行字数相差不超过 1。原书已居中排印的现代诗，保留居中。

4.7.3.3　`poem-left`（居左，回行低一格）用于古风、乐府、杂言、楚辞、现代诗、歌词，以及任何行长不齐或单行超过 20 字的诗。

4.7.3.4　`poem-ci`（词、曲）用于词和散曲：每阕一个 `p.stanza`；阕内以句末的 `。？！` 为界，每个整句一个 `span.line`；原书已按韵断行的，保留原书断行（4.7.2.5）。

4.7.3.5　词的诗题写作「词牌·题」（`水调歌头·明月几时有`），词序写 `p.poem-preface`；只有词牌没有题的，诗题只写词牌。

4.7.3.6　原书把两阕连排在同一行时，默认仍拆成两个 `p.stanza`；用户选择「保持原书排版」时，两阕写在同一个 `p.stanza`，阕与阕之间放 `<span class="ci-gap"></span>`，且该 `p` 内不加 `<br/>`。

4.7.3.7　`poem-adaptive`（自适应换行）只与 `poem-center` 同用；每个 `span.line` 内按分句拆成 `<span class="verse">`，每个 `span.verse` 含其末尾标点，分句之间不写空白。

4.7.3.8　`poem-center` 的诗不得使用 `indent-N`；需要缩进的诗改用 `poem-left`。

**正例**（词）
```html
<div class="poem poem-ci" epub:type="z3998:poem">
	<p class="poem-title">水调歌头·明月几时有</p>
	<p class="poem-author">苏轼</p>
	<p class="poem-preface">丙辰中秋，欢饮达旦，大醉，作此篇，兼怀子由。</p>
	<p class="stanza">
		<span class="line">明月几时有？把酒问青天。</span><br/>
		<span class="line">不知天上宫阙，今夕是何年。</span>
	</p>
	<p class="stanza">
		<span class="line">转朱阁，低绮户，照无眠。</span><br/>
		<span class="line">不应有恨，何事长向别时圆？</span>
	</p>
</div>
```

**正例**（自适应换行）
```html
<div class="poem poem-center poem-adaptive" epub:type="z3998:poem">
	<p class="poem-title">出塞</p>
	<p class="stanza">
		<span class="line"><span class="verse">秦时明月汉时关，</span><span class="verse">万里长征人未还。</span></span><br/>
		<span class="line"><span class="verse">但使龙城飞将在，</span><span class="verse">不教胡马度阴山。</span></span>
	</p>
</div>
```

### 4.7.4 正文中的引诗

4.7.4.1　在叙述、论述中整块引用的诗，用 `<blockquote class="poem-quote">`，`epub:type` 写在该 `blockquote` 上（整首 `z3998:poem`，片段 `z3998:verse`，歌词 `z3998:song`）；内部结构同 4.7.2，并带一个排版型类（4.7.3.1）。（SE 7.5.5）

4.7.4.2　引诗不再加外层引号。

4.7.4.3　引诗的出处署名写在该 `blockquote` 内，规则见 4.7.2.9 与 4.6。

4.7.4.4　引诗省略若干行时，被省略处单独写一行 `<span class="line elision">……</span>`，省略号按 06 §2.4 写；该容器的 `epub:type` 用 `z3998:verse`。（SE 7.5.7）

**正例**
```html
<p>他在信末抄了一首旧诗：</p>
<blockquote class="poem-quote poem-center" epub:type="z3998:poem">
	<p class="stanza">
		<span class="line">床前明月光，</span><br/>
		<span class="line">疑是地上霜。</span><br/>
		<span class="line">举头望明月，</span><br/>
		<span class="line">低头思故乡。</span>
	</p>
	<p class="attribution">——李白《静夜思》</p>
</blockquote>
```

**正例**（引诗有省略）
```html
<blockquote class="poem-quote poem-left" epub:type="z3998:verse">
	<p class="stanza">
		<span class="line">海客谈瀛洲，烟涛微茫信难求。</span><br/>
		<span class="line elision">……</span><br/>
		<span class="line">安能摧眉折腰事权贵，使我不得开心颜！</span>
	</p>
</blockquote>
```

### 4.7.5 诗集

4.7.5.1　诗词曲选、箴言集这类由短小单项组成的集合，可把多首放在同一文件，每首一个 `<article>`；`article` 带 `class="poem"`、排版型类、`epub:type` 和 `id="poem-N"`（N 为全书顺序号）。（SE 7.1.3；02 §2.1）

4.7.5.2　诗集中每首的诗题用 `h`（层级按 4.3），作者用 `p.poem-author`。

4.7.5.3　同名诗词在全书中出现 3 次及以上（《无题》《浣溪沙》），目录（nav）条目文字后附首句括注：`无题（相见时难别亦难）`；括注取该诗首行，生成后交用户确认。〔大模型〕

4.7.5.4　默认不让每首诗另起一页；配置项 `poem.page_break` 开启时，才输出 `article.poem` 的分页样式。（D14）

**正例**
```html
<article id="poem-3" class="poem poem-center" epub:type="z3998:poem">
	<h2>无题</h2>
	<p class="poem-author">李商隐</p>
	<p class="stanza">
		<span class="line">相见时难别亦难，东风无力百花残。</span><br/>
		<span class="line">春蚕到死丝方尽，蜡炬成灰泪始干。</span>
	</p>
</article>
```

### 识别信号

诗词误判代价高。置信度：已有 `z3998:poem/verse/song` 或旧版 `div.poem`、类名含 poem/stanza/verse（A，只做结构转换）；五七言规整、合计 ≥4 句，且有下列语境之一（B，自动并报告）：前有诗题/作者行、前一段以冒号引出（「诗曰：」「道是：」）、紧接在另一首诗之后、或原书给这几行单独的样式（类名不同于本文件正文主流，或缩进比正文深）；其余（C，只给建议，由用户确认后改写）。句中带顿号的不算诗句（多为散文）。

- 连续 ≥2 行；每行字数 ≤20（古体可含两个半句，各 ≤10 字）；各行长度相近（偏差 ≤1）；多数行以 `，。？！；` 结尾。
- 五言 `^.{5}[，。]$`、七言 `^.{7}[，。]$`，或每行含两个半句。
- 前一行是诗题 + 作者：`《X》`、`X·Y`、2–4 字且无标点的作者行、`〔朝代〕作者`。
- 词：词牌名（`《水调歌头》`、`水调歌头·题`）、行长短不一、「上阕/下阕」或分成两段。
- 现代诗：短行、无固定长度、行末无句号。
- 排版型选择：各行等长 ±1 且为偶数个半句 → `poem-center`；词、曲 → `poem-ci`；杂言、现代诗、长行 → `poem-left`；用户启用自适应 → 加 `poem-adaptive`。
- 外来或旧版形态（一行一个 `p` 的 `div.stanza`、`pre`、行首全角空格）：改写为 4.7.2 结构；行首比其余诗行多出的全角空格每 2 个折算 1 级 `indent-N`（上限 3，超出报告；与 07 SEM-034 一致）。

### 注意与降级

- 降级：丢 CSS 后，诗节仍是独立的 `p`（节界保留），行由 `<br/>` 分开，顺序不变。
- `p.stanza > br` 被设为 `display:none` 后，若某阅读器不认这条规则，每行之间会多出一个空行；该情形不改结构，只在报告中提示【需实测】。
- 选择器写 `p.stanza`，不写 `div.poem p`，否则会波及 `p.poem-title`、`p.poem-author`（SE 7.5.8）。
- 居中诗的某行末尾带注号时，该行视觉上偏左约一个上标宽（≤0.7em），接受此偏差，不用对侧行补空格；偏差不能接受时，把注号移到诗末。
- 自适应换行的分句被当作整体，窄屏上分句间换行、宽屏一行两句【需实测】；只适合每分句字数基本固定的古典诗词。不采用 `white-space:nowrap`（会禁用所有换行）。
- 仿宋、楷体在 Android 与部分阅读器上可能缺失，回落到宋体族，外观降级但可读；诗的区分靠缩进和行结构，不只靠字体。
- 竖排时结构不变；缩进与悬挂的物理属性（`padding-left`、`margin-left`）改为逻辑属性，由 4.15 的竖排增量一并给出【需实测】。
- 词的字数分类（小令 ≤58、中调 59–90、长调 ≥91）只作识别辅助，不影响结构。

## 4.8 书信

适用于书信、书信集、日记体中的信件，以及叙事中引用的整封信。

### 4.8.1 容器与语义

4.8.1.1　叙事、传记、论述中引用的信，用 `<blockquote class="letter" epub:type="z3998:letter">`。（SE 7.B.1；D3）

4.8.1.2　书信集中、整封信即一个单元的，用 `<section class="letter" epub:type="z3998:letter">`，每封信一个 `section`；`section` 带 `id`，并按 4.3 配标题。（D3）

4.8.1.3　一封信只有一个 `z3998:letter` 容器；`blockquote.letter` 内不得再嵌套 `blockquote`。

4.8.1.4　容器内至少含一个 `z3998:salutation` 才能包 `.letter`；只有署名或日期、没有称谓的片段，不包 `.letter`，只给对应段加 4.8.4 的类与语义。

4.8.1.5　书信容器内不得使用 `header`、`footer`，不得用 `<br/>` 合并祝颂语与署名；各部分各自成段。

4.8.1.6　用了 `z3998:` 值，须在 `<html>` 上声明 `epub:prefix`（见 4.7.1.5）。

### 4.8.2 信头与称谓

4.8.2.1　书信集每封信的标题写在 `section.letter` 的第一个子元素，类为 `letter-title`，元素为 `h`，层级按 4.3。

4.8.2.2　标题以「致、与、寄、复、答」开头且形态规整时，收信人名包 `<span epub:type="z3998:recipient">`。（SE 7.B.7）

4.8.2.3　标题里的日期写 `<span class="letter-date">`。

4.8.2.4　称谓之前的地点、日期行写 `<p class="dateline">`，不用 `z3998:dateline`（该词不存在）。（SE 7.B.4）

4.8.2.5　称谓独立成段，写 `<p class="salutation" epub:type="z3998:salutation">`，顶格，以全角冒号结尾；嵌在首行里的称谓写 `<span class="salutation" epub:type="z3998:salutation">`。（SE 7.B.5）

4.8.2.6　日期能确定为公历且完整时，写 `<time datetime="1898-02-17">`；无年份的公历日期写 `datetime="02-05"`；民国、干支、农历纪年的日期不加 `datetime`，保持纯文本。（SE 7.B.4）

### 4.8.3 正文

4.8.3.1　信的正文段首行缩进 2em，称谓之后的第一段也缩进；不套 `noindent`。（不采用 SE 7.B.6）

### 4.8.4 信尾

4.8.4.1　祝颂语每句一个 `p`，标 `epub:type="z3998:valediction"`：上句（「此致」）用普通 `p`，保留默认缩进；下句（「敬礼」）写 `p.closing`，顶格。

4.8.4.2　署名整行（含「启上」「顿首」）写一个 `<p class="signature" epub:type="z3998:sender z3998:signature">`，右对齐；不把署名与「启上」拆开标注。（SE 7.B.9）

4.8.4.3　落款日期写 `<p class="date">`，右对齐；署名与日期的先后保持原书顺序。

4.8.4.4　署名是图片时，图片写 `<img class="signature-img" alt="人名"/>`，放在 `p.signature` 内。

4.8.4.5　附言（「又及」「再启」「再及」「追启」「附：」）写 `<p class="postscript" epub:type="z3998:postscript">`，放在署名与日期之后；多段附言用 `<div class="postscript" epub:type="z3998:postscript">` 包住各段。（SE 7.B.11）

4.8.4.6　`signature`、`date` 也用于章末署名、序言落款；这类用法不加 `z3998:sender`、`z3998:letter`。

**正例**（叙事中引信）
```html
<html xmlns="http://www.w3.org/1999/xhtml" xmlns:epub="http://www.idpf.org/2007/ops" epub:prefix="z3998: http://www.daisy.org/z3998/2012/vocab/structure/" lang="zh-Hans" xml:lang="zh-Hans">
	<body>
		<section epub:type="chapter" role="doc-chapter">
			<h1>第七章　来信</h1>
			<p>第二天清晨，他收到了先生的回信：</p>
			<blockquote class="letter" epub:type="z3998:letter">
				<p class="salutation" epub:type="z3998:salutation">西谛先生：</p>
				<p>昨乔峰交到惠赠之……</p>
				<p epub:type="z3998:valediction">此布，并颂</p>
				<p class="closing" epub:type="z3998:valediction">曼福</p>
				<p class="signature" epub:type="z3998:sender z3998:signature">迅　启上</p>
				<p class="date">二月五日</p>
				<p class="postscript" epub:type="z3998:postscript">又及：书已收到。</p>

	</body>
</html>
```

**正例**（书信集，整封信一个 `section`）

**反例**（用 `header`/`footer`、`br` 合并、`z3998:dateline`、缺称谓语义）

### 识别信号

出现下列件数越多越可信；≥3 件且含称谓为 B（自动并报告）；缺件时只套单项（C）。叙事中的引信与书信集的区分：信上方有书信集标题或位于独立小节为 `section`，嵌在叙述段之间的为 `blockquote`。

1. 称谓：首段 `^[^，。！？\n]{1,12}[：:]$`（「西谛先生：」）。
2. 正文若干段。
3. 祝颂语：`此致|敬礼|顺颂|并颂|谨上|敬上|顿首|拜上|匆此|专此|即颂`。
4. 署名：≤10 字短行，常带「启/上/拜」。
5. 日期：`^\d{4}年\d{1,2}月\d{1,2}日$`、`^[〇一二三四五六七八九十]+年…月…日$` 或 `二月五日`。
6. 书信集标题：`致X`、`与X书`，常带日期。
7. 附言：署名之后以 `又及|再启|再及|追启|附：|P.S.` 开头的段。

## 4.9 剧本与对白

适用于戏剧、剧本、曲牌唱词，以及访谈、问答体对话。

### 4.9.1 整体与分幕

4.9.1.1　整个文件是剧本时，`<body>` 写 `epub:type="bodymatter z3998:drama"`；剧本只是一部书的一部分时，把 `z3998:drama` 写在包裹该剧的 `section` 上。（SE 7.A.12）

4.9.1.2　幕写 `<section class="act" epub:type="chapter" role="doc-chapter">`；不得使用 `z3998:act`（该词不存在）。

4.9.1.3　场写 `<section epub:type="z3998:scene">`，放在所属的幕之内；只有场、没有幕的剧，场写 `epub:type="chapter z3998:scene"`。

4.9.1.4　幕、场的标题用 `h`，层级按 4.3，「第一幕」「第二场」与幕名整体写在一个 `h` 内。（D1）

4.9.1.5　幕或场开头的场景说明（「幕启：……」）写在标题之后，用 `p.stage`。

4.9.1.6　访谈、问答体用 4.9.2 的写法 B，不给 `body` 加 `z3998:drama`。

### 4.9.2 对白

4.9.2.1　每个发言是一个 `p.dialogue`；同一人连续的多段，各自一个 `p`；不同人的发言不得用 `<br/>` 合并成一段。

4.9.2.2　角色名写 `<span class="persona" epub:type="z3998:persona">`；span 内不含冒号和结尾标点。（SE 7.A.4）

4.9.2.3　写法 A（角色名独占一行）：`p.speaker-line` 内放 `span.persona`，下一个 `p.dialogue` 是台词。

4.9.2.4　写法 B（连排）：`p.dialogue.dialogue-run` 内先放 `span.persona`，再写全角冒号「：」和台词；冒号在 `span` 外。

4.9.2.5　一部剧本只用一种写法，A、B 不得混用。

4.9.2.6　`span.persona` 内不得含空白字符（`铁　梅` 改为 `铁梅`）；需要对齐时由 CSS 完成。

4.9.2.7　同一角色在全剧中写法一致；全称与简称混用（「铁梅/梅」「李奶奶/奶奶」）列入确认清单。〔大模型〕

4.9.2.8　不用 `table` 排对白。（SE 7.A.1 不采用）

4.9.2.9　「众」「合」「同声」等多人齐说，当作普通角色名，不做特殊结构。

### 4.9.3 舞台说明

4.9.3.1　整段舞台说明写 `<p class="stage" epub:type="z3998:stage-direction">`；行内插入的写 `<span class="stage" epub:type="z3998:stage-direction">`。（SE 7.A.7）

4.9.3.2　舞台说明的括号（`（）` 或 `〔〕`）写在正文里，成对且不混用半角；不用 `::before`/`::after` 的 `content` 生成括号。

4.9.3.3　舞台说明不用斜体，字体用楷体；角色名不被楷体带走（见 CSS）。

4.9.3.4　舞台说明中提到角色名时，用 `<span class="persona" epub:type="z3998:persona">` 包住名字，「的」留在 span 外；只在能与对白说话人或人物表匹配时才加。〔大模型〕

4.9.3.5　原书用 `〔〕`、`［］` 标注的编者补入说明，加 `class="editorial"`，保留原括号字符；不自动生成。（SE 7.A.8）

4.9.3.6　曲牌与唱法（`唱【西皮散板】`）写在 `p.speaker-line` 的 `span.stage` 内，或单独一个 `p.stage`；不写进诗行。该处原文没有括号时，不补括号。

4.9.3.7　括号内的舞台说明，独立成句的以句号结尾，句中插话不加句末标点；两种写法并存时只报告少数派，不改写。（SE 7.A.11）

### 4.9.4 唱词与韵文台词

4.9.4.1　台词里每行一句的唱词、韵白，写成 4.7 的诗歌结构：`<div class="poem poem-left" epub:type="z3998:verse">`，放在对应的角色行或 `p.dialogue` 之后。（SE 7.A.5）

4.9.4.2　唱词容器内每节一个 `p.stanza`，每行一个 `span.line`，规则同 4.7.2。

### 4.9.5 人物表

4.9.5.1　人物表写 `<section class="cast" epub:type="z3998:dramatis-personae">`，内含标题 `h` 和一个 `ul`；每个 `li` 先写 `span.persona`，再写一个全角空格，再写身份说明。

4.9.5.2　人物表的 `ul` 去掉项目符号，左对齐，不居中、不斜体。

4.9.5.3　人物表中的角色名与对白中的写法一致。〔大模型〕

4.9.5.4　人物表的 `section` 写 `epub:type="z3998:dramatis-personae"`（已核实在 Z39.98 词表中，见 08 第 2 节）。

**正例**（写法 A，含舞台说明与唱词；完整文档开头写出前缀声明）
```html
<html xmlns="http://www.w3.org/1999/xhtml" xmlns:epub="http://www.idpf.org/2007/ops" epub:prefix="z3998: http://www.daisy.org/z3998/2012/vocab/structure/" lang="zh-Hans" xml:lang="zh-Hans">
	<body epub:type="bodymatter z3998:drama">
		<section class="act" epub:type="chapter" role="doc-chapter">
			<h1>第一幕</h1>
			<p class="stage" epub:type="z3998:stage-direction">（幕启：北风呼啸，四壁昏暗；<span class="persona" epub:type="z3998:persona">李奶奶</span>捻灯，屋中转明。）</p>

```

**正例**（写法 B，连排）

```html
<p class="dialogue dialogue-run"><span class="persona" epub:type="z3998:persona">铁梅</span>：奶奶，您放心。</p>
```

**正例**（人物表）

**反例**（角色名内加空格对齐、括号用 CSS 生成、表格对白、混用 A/B）

### 识别信号

整部剧本、人物表、舞台说明均为 C（只给建议，需用户开启）；已有 `z3998:drama/persona/stage-direction` 时为 A。

- 「角色名＋全角空格/冒号＋台词」行连续出现，角色名 ≤4 字（`^[^，。！？：\s]{1,6}[：:　]`），重复率高。
- 括号舞台提示 `（……）`、`〔……〕`；曲牌 `【西皮散板】`；「幕/场」标题。
- 全书 ≥70% 的段落为对白或舞台说明 → 视为整部剧本。
- 人物表：剧本开头、紧邻标题「人物表/登场人物/角色表/剧中人物」的短行列表。
- 识别时「众、合、同、齐」当作普通角色名。

### 注意与降级

- 原书把台词 `text-indent:6em`，在 360px 手机上仅剩约 10 字行宽；改为写法 A 整体缩进 2em，写法 B 悬挂不超过 5em。

- 降级：丢 CSS 后角色名、台词、舞台说明仍按段分开；`span.persona` 内的文字保持可读。

## 4.10 条款与列表

适用于法律、规章、章程、合同的条文，以及一般的有序、无序列表和定义列表。

### 4.10.1 条文

4.10.1.1　每一条是一个 `<p class="article">`，条号写 `<span class="article-no">第一条</span>`，条号之后写一个全角空格再接条文。

4.10.1.2　条的第二款起另起一个 `p.article`，不带 `span.article-no`；一条内只有第一个 `p` 带条号。

4.10.1.3　条号是文本，写入文字，不用 `ol` 自动生成，也不依赖 `cjk-ideographic`。

4.10.1.4　章、节标题（「第一章　总则」）用 `h`，层级按 4.3；不写成 `p.article`。

4.10.1.5　默认排法为首行缩进 2em、回行顶格；原书使用悬挂排法的，才给 `p` 加 `article-hang`，后续款（无条号）同时加 `article-cont`。

4.10.1.6　悬挂排法的悬挂宽度 N = 全书最长条号的字数 + 1，由软件算出后写入样式表；`span.article-no` 内的 `text-indent` 必须设为 0。

4.10.1.7　不用透明 `border`、空格补字距来对齐「条」字。

### 4.10.2 项与目

4.10.2.1　条内的「项」（`（一）`、`（二）`）每项一个 `<p class="item hang-N">`，序号是文本，紧接正文，不加空格。

4.10.2.2　序号占 3 字（`（一）`）的，N 为 3；占 4 字（`（十一）`）的，N 为 4；`一、`、`1.`、`①` 占 2 字，N 为 2。同一组项必须用同一个 N，取该组最长序号。

4.10.2.3　序号含半角字符（`1.`、`1)`）的，序号包 `<span class="item-no">`，使回行对齐。

4.10.2.4　「项」之下的「目」写 `<p class="item item-sub hang-N">`，N 的取法同 4.10.2.2。

4.10.2.5　条款范围之外的普通列表，不套 `p.item`，按 4.10.3。

### 4.10.3 列表

4.10.3.1　阿拉伯数字序号（`1.`、`2.`）的连续 ≥3 段，且不在条款内的，改写为 `ol`，删去文本中的序号，序号由 `ol` 生成。

4.10.3.2　以 `·`、`•`、`●`、`■` 手写圆点开头的连续段，改写为 `ul`，删去文本中的圆点。

4.10.3.3　中文序号（`一、`、`（一）`、`①`）保持为文本，写成 `p.item`（4.10.2），不用 `ol` 的 `cjk-ideographic`。（03 §7.7）

4.10.3.4　`ul`、`ol` 的子元素只能是 `li`；不用 `<br/>` 分条，不用 `<p>` 加手写符号冒充列表。

4.10.3.5　`li` 内文字与块级子元素（嵌套列表、多段）混排时，把文字包进 `<p>`；纯文字的短项不包。（SE 5.6.1）

4.10.3.6　`ol` 保留 `start`、`reversed`；不用 `type`；`ul` 不写 `type`。

4.10.3.7　嵌套 `ul` 的项目符号形状由 CSS 显式指定，不依赖阅读器自动轮换。

4.10.3.11　列表与序号项采用悬挂排：序号（含 `ol` 自动编号、项目符号、`p.item` 的文字序号）与正文段落首行对齐，即缩进两字；回行与序号后的文字对齐，不回到顶格。（2026-10-31 新增）

4.10.3.8　术语加释义用 `<dl>`：每个 `<dt>` 一个术语，其后一个或多个 `<dd>`；`dt` 内不放块级元素。

4.10.3.9　`dd` 内文字与块级子元素混排时，文字包进 `<p>`；纯一句的释义不包。（SE 5.9.1）

4.10.3.10　带 `glossterm`/`glossdef` 语义的术语表，规则见 4.19，本节不重复。

**正例**（条文，默认排法）
```html

<p class="article"><span class="article-no">第一条</span>　为了保护公民的合法权益，制定本法。</p>
<p class="article"><span class="article-no">第二条</span>　本法适用于下列情形：</p>

<p class="item hang-3">（二）经批准设立的。</p>
<p class="article">前款所称登记，是指……</p>
<p class="article"><span class="article-no">第十一条</span>　……</p>
```

### 识别信号

条文、序号项的识别置信度为 A（自动）。

- `^第[0-9零〇一二三四五六七八九十百千]+条`（强）。
- 连续多段以 `（一）`、`（二）`、`1.`、`①` 开头。
- 上下文出现「章/节」标题（`第一章 总则`），位于规章类文本。
- 手写圆点列表：连续 ≥2 段以 `·•●■` 开头（A）。
- 阿拉伯数字序号段：连续 ≥3 段 `^\d+[.、)]`，且不在条文之内（B，自动并报告）。
- `dl`：已有 `<dl>`（强）；「术语：释义」成对的短段（C，仅建议）。

## 4.11 插图、图注与插图目录

适用于块级插图、并列图、行内图、绕排图，图注，以及原书已有的插图目录页。图片规格、体积、格式见 `guide/05`；alt 的通用写法见 05 §1.5，本节只规定输出时的判定规则。

### 4.11.1 插图

4.11.1.1　独占一段的块级图用 `figure` 包住，`img` 是 `figure` 的子元素。（SE 7.C.8）

4.11.1.2　行内图不放进 `figure`，`img` 直接写在 `p` 里。判定为行内图的条件：位于文字中间，且渲染尺寸不大于 2em、宽高比接近 1:1；或已带 `glyph`、`formula` 类。（SE 7.C.11）

4.11.1.3　一个 `figure` 只放一张主图。并列图用外层 `figure.figure-group`，内含 `div.figure-row`，行内每张图各自一个 `figure.figure-col`；外层 `figcaption` 写总图注，放在最后。

4.11.1.4　三张及以上同尺寸图，各自成一个 `figure`，竖排依次展示；不做滑动画廊。

4.11.1.5　图宽只用宽度类 `w-100`、`w-80`、`w-60`，不写像素值，不写 `width`/`height` 属性或内联 `style`（行内图 `formula` 的 `height` 除外，见 4.11.1.6）。

4.11.1.6　公式图的高度由图片原始像素高度除以 16 得到 em 值，写入 `style="height:N.Nem"`，这是唯一允许的内联尺寸样式。

4.11.1.7　`figure` 的 id 只在该图被插图目录或正文交叉引用时才生成，写成 `figure-N`，N 是全书流水号，从 1 起，不含章号，不取自图号文字。原书已有的 id 原样保留。（SE 7.C.1）

    4.11.1.7.1　`figure` 的 id 全书唯一；重复时第 2 处起改为 `figure-N-2`，并报告。

4.11.1.8　整页插图（宽、高均不小于版心的 90%）在 `figure` 上加 `full-page` 类。该图已自成一个文件时不加，避免出现空白页。（SE 7.C.10）

4.11.1.9　绕排只用于竖长窄图：`figure` 加 `float-left` 或 `float-right`，宽度 45%，图文间距不小于 1em；紧跟的正文之后放一个 `div.clear`。窄屏（宽度不大于 30em）取消浮动。

4.11.1.10　`img` 上的 `epub:type`（`z3998:illustration`、`z3998:photograph`）只在类型已确定时才写，不自动全量添加；写了就必须在 `<html>` 上声明 `epub:prefix="z3998: http://www.daisy.org/z3998/2012/vocab/structure/#"`。（SE 7.C.5）〔大模型〕

4.11.1.11　有透明背景、主色近黑的线稿图，在 `img` 上加 `line-art` 类，或建议重新导出为不透明浅色底。

**正例**
```html
<figure id="figure-3">
	<img class="w-80" src="../images/zhiyuan.jpg" alt=""/>
	<figcaption>图 1-3　北洋海军「致远号」官兵</figcaption>
</figure>
```
（`alt=""` 的原因见 4.11.2.5。）

**正例：并列图**
```html
<figure class="figure-group">
	<div class="figure-row">
		<figure class="figure-col"><img src="../images/a.jpg" alt="正面照。"/><figcaption>（a）正面</figcaption></figure>
		<figure class="figure-col"><img src="../images/b.jpg" alt="侧面照。"/><figcaption>（b）侧面</figcaption></figure>
	</div>
	<figcaption>图 3-2　外观</figcaption>
</figure>
```

**正例：行内图**
```html
<p>此字作<img class="glyph" src="../images/rare-2ee26.png" alt="𮸦"/>，见于……</p>
<p>由公式<img class="formula" style="height:1.6em" src="../images/f1.png" alt="E=mc^2"/>可得……</p>
```

**反例**
```html
<!-- 行内小图被包进 figure，断开了句子 -->
<p>此字作</p><figure><img src="../images/rare-2ee26.png" alt="𮸦"/></figure><p>，见于……</p>
<!-- 固定像素宽度 -->
<figure><img src="../images/a.jpg" width="600" alt="…"/></figure>
```

### 4.11.2 alt 文本

4.11.2.1　每个 `img` 都有 `alt` 属性，即使值为空串。

4.11.2.2　块级内容性插图的 `alt` 描述画面本身，写成完整的句子，不写「图片」「插图」前缀，不描述图在书中的位置，不重复紧邻的图注。（SE 7.C.2）〔大模型〕

4.11.2.3　块级内容性插图的 `alt` 以句末标点（。！？）结束；行内图（`glyph`、`formula`，或 4.11.1.2 判定的行内图）不加句末标点。（SE 7.C.3）

4.11.2.4　`alt` 中不含不换行空格 U+00A0、词连接符 U+2060、零宽空格 U+200B。（SE 7.C.3）

4.11.2.5　`img` 缺 `alt` 时，一律补 `alt=""`，不得把图注复制进 `alt`（读屏会把同一句话念两遍）。该图在报告中标「待补描述」，留给大模型生成。（D8）

4.11.2.6　大模型生成的 `alt` 是草稿，标「AI 草稿」，用户确认后才写入内容性图像。〔人工〕

4.11.2.7　`alt` 是文件名、含 `.jpg`/`.png`，或只有「图」「图片」「image」「img」时，清空为 `alt=""` 并标「待补描述」。

4.11.2.8　`alt` 与同一 `figure` 内 `figcaption` 的文本逐字相同时，报告（info），建议改写 `alt`；不自动改。（SE 4.2.5）

4.11.2.9　装饰图（分隔花纹、章末花饰，渲染宽或高小于版心的 1/4）写 `alt=""`，不报「待补描述」。

**正例**
```html
<figure>
	<img src="../images/map-1.png" alt="长江中下游地图，标出了赤壁、江陵和夏口三地的相对位置。"/>
	<figcaption>图 2-1　赤壁之战形势</figcaption>
</figure>
```

**反例**
```html
<!-- 图注抄进 alt，读屏念两遍 -->
<figure>
	<img src="../images/map-1.png" alt="图 2-1　赤壁之战形势"/>
	<figcaption>图 2-1　赤壁之战形势</figcaption>
</figure>
<!-- 缺 alt 属性 -->
<img src="../images/map-1.png"/>
```

### 4.11.3 图注

4.11.3.1　图注用 `figcaption`，是 `figure` 的子元素，写在图的下方；`figcaption` 不出现在 `figure` 之外。

4.11.3.2　紧邻 `img`、居中或小字、不超过 40 字的短段，转成 `figcaption`，不保留为 `p`。

4.11.3.3　图号和表号是真实文字，写在图注里；不用 CSS 计数器生成，不用图号做 id。

4.11.3.4　图号与图题之间用一个空格（全角或半角，按原书）。全书统一为占多数的写法；多种连接符（`1-3`、`1—3`、`1.3`）并存时，列出少数派并报告，不自动改。

4.11.3.5　多行图注用 `<br/>` 分行，来源行放在 `span.small` 里。多段图注每段一个 `p`。

4.11.3.6　图注字号不大于正文，默认 .9em；图注与图的间距小于图与上下文的间距。

4.11.3.7　图注里不留颜色内联样式（如 `color:#a52a2a`）。

4.11.3.8　没有图注的图，不补造图注。

**正例**
```html
<figcaption>图 1-3　地平坐标系<br/><span class="small">来源：作者自绘</span></figcaption>
```

**反例**
```html
<p style="text-align:center;color:#a52a2a;font-size:12px">图1—3 地平坐标系</p>
```

### 4.11.4 插图目录

4.11.4.1　原书已有插图目录页（标题含「插图目录」「图目录」「图片目录」「插图索引」，正文是成行的「图X—Y　题名……页码」）时，保留这一页，转成 `nav epub:type="loi"`。（SE 7.D.1；D11）

4.11.4.2　原书没有插图目录页时，不新建；块级内容性插图不少于 5 张时，只在报告里提示。（D11）

4.11.4.3　插图目录页的结构是一个 `nav`，带 `id="loi"`、`class="loi"`、`epub:type="loi"`，内含一个标题 `h2.chapter-title` 和一个 `ol`；`ol` 不显示项目符号（`h1` 只给书名页，见 4.3.1.1）。（SE 7.D.4）

4.11.4.4　新生成或重命名的插图目录文件名用 `loi.xhtml`，位置随原书（紧跟目录页，或在书末），`body` 的 `epub:type` 随位置取 `frontmatter` 或 `backmatter`。（SE 7.D.2）

4.11.4.5　条目文字取 `figcaption` 第一行（含图号与题名，不含来源行）；该行超过 40 字或没有图注时，取 `alt`；两者都没有时，条目保留原文并报告。（SE 7.D.5）

4.11.4.6　每个条目的链接指向对应 `figure` 的 id（`chapter03.xhtml#figure-3`），不指向文件顶部。（SE 7.D.6）

4.11.4.7　原书条目里的页码、点线、制表位全部删除。

4.11.4.8　没有对应 `figure` 的条目，保留文字、不加链接，并报告。

4.11.4.9　收入插图目录的是块级、内容性的 `figure`；不收 `glyph`、`formula`、`signature-img`、`line-art` 类，不收 `alt=""` 的装饰图。（SE 7.D.3）

4.11.4.10　插图目录页要出现在 `nav epub:type="toc"` 里，条目文字用原书页标题；landmarks 里加 `epub:type="loi"` 的条目（01 §landmarks）。

**正例**
```html
<body epub:type="frontmatter">
	<nav id="loi" class="loi" epub:type="loi">
		<h2 class="chapter-title">插图目录</h2>
		<ol>
			<li><a href="chapter01.xhtml#figure-1">图 1-1　地平坐标系</a></li>
			<li><a href="chapter03.xhtml#figure-3">图 1-3　北洋海军「致远号」官兵</a></li>
		</ol>
	</nav>
</body>
```

**反例**
```html
<!-- 带页码与点线，链接指向文件顶部 -->
<p><a href="chapter01.xhtml">图 1-1　地平坐标系…………12</a></p>
```

### 识别信号

- 插图：`img`（强）；独占一段的图；图后紧跟短句（≤40 字、`^图\s*\d`、`^(Figure|Fig\.)`、居中小字）；行内图（高）：位于文字中间、尺寸 ≤2em、近 1:1；两张同尺寸图紧邻（并列）；`float`/`align` 属性（绕排）。先见文后见图，图随文走，图不越过小标题。置信度：块级图转 `figure` 为 A；图注转 `figcaption` 为 A；并列图、绕排为 B。
- 图注：紧邻 `img` 的短段；`^图\s*\d+[-—.．]?\d*`、`^(Fig(ure)?\.?)\s*\d`、`^(图|表)[：:]`；来源行 `来源：|摄于|图片来自`。置信度 A。
- 插图目录：标题含「插图目录|图目录|图片目录|插图索引」，且正文多数行匹配 `^图\s*\d+.*\d+$`，或页面主体是指向 `figure` 的链接列表。标题命中且 ≥3 个条目为 A；仅条目命中为 C（交用户确认）。
- 整页图：宽、高均 ≥ 版心 90%（05 §1.4）。
- 缺 alt 的判定见 4.11.2；「待补描述」清单汇总写入报告，供 M3 大模型处理。

### 注意与降级

- `figure img` 的 `max-height:100vh`（防竖长图超出一屏）与宽度类并用时可能使比例失真，写入 03 §5 前须实测【需实测】。
- 夜间模式下的透明线稿：由稳到不稳依次为 ① 导出时加不透明浅色底（05）；② `img.line-art` 白底板（代价是夜间出现白框）；③ `@media (prefers-color-scheme:dark){ img.line-art{ filter:invert(1) hue-rotate(180deg); background:none; padding:0; } }`，仅限单色线稿，是否生效【需实测】；④ 内联 SVG 用 `currentColor`（`<img src="*.svg">` 不继承）。
- 降级：丢 CSS 后 `figure` 是居中块，图与 `figcaption` 相邻；不支持 `break-before` 的阅读器上整页图不强制分页。
- 插图目录里的链接依赖 4.11.1.7 的 id；原书 id 被外部引用时靠 `id_map` 保持。

## 4.12 注释

全书统一做成一个书末尾注文件（Standard Ebooks 做法）：正文里只留干净的注号链接，注文集中在书末一个连续编号的有序列表里。一书一种方案，不混用。原书的脚注、章末注、随文注都并入书末尾注，原位置删除并记入删除清单。

**为什么用书末尾注**：支持弹注的阅读系统（Apple Books、KOReader 等）凭 `epub:type="noteref"` 弹出注文；不支持的点击跳到书末，读完点 ↩ 返回；章节正文不被注文打断；注文集中便于检查。

### 4.12.1 注号

4.12.1.1　注号是带 `class="noteref"`、`epub:type="noteref"`、`role="doc-noteref"` 的 `a`，不包 `sup`。（SE 7.E.3）

4.12.1.2　注号文字是阿拉伯数字，不带方括号、圈码或「注」字；原书的 `[1]`、`①`、`（注1）` 一律转成数字。

4.12.1.3　注号 `a` 的 `href` 指向书末尾注文件里对应 `li` 的 id（`endnotes.xhtml#note-N`），不指向文件顶部。

4.12.1.4　注号的 id 是 `noteref-N`，N 与注文序号相同。（SE 7.E.4）

4.12.1.5　全书连续编号，从 1 起，按注号在正文中首次出现的顺序；不按章重新编号。（D7）

4.12.1.6　同一条注被多处引用时，第一处的 id 是 `noteref-N`，之后依次是 `noteref-N-2`、`noteref-N-3`；所有注号的 `href` 都指向同一个 `note-N`；回链只指向第一处。

4.12.1.7　句末的注号放在句末标点之后。（SE 7.E.5）

4.12.1.8　注释针对整句引文或引文末词时，注号放在闭引号之外，写成「……」¹，不写成「……¹」。（SE 7.E.6）

4.12.1.9　句中的词语注（注在某个术语之后，如「牛顿¹的理论」）保持原位置，加 `noteref-term` 类，不移到标点之后。

4.12.1.10　注号前后不留空白；源码换行产生的空白要删掉。

**正例**
```html
<p>……不要这个星期是基本面分析者，下个星期又成了技术分析者。<a class="noteref" epub:type="noteref" role="doc-noteref" href="endnotes.xhtml#note-1" id="noteref-1">1</a></p>
<p>牛顿<a class="noteref noteref-term" epub:type="noteref" role="doc-noteref" href="endnotes.xhtml#note-2" id="noteref-2">2</a>的理论认为……</p>
<p>他说：「世上本无事。」<a class="noteref" epub:type="noteref" role="doc-noteref" href="endnotes.xhtml#note-3" id="noteref-3">3</a></p>
```

**反例**
```html
<p>……技术分析者。<sup><small>[1]</small></sup></p>
<p>他说：「世上本无事。<a class="noteref" epub:type="noteref" role="doc-noteref" href="endnotes.xhtml#note-3" id="noteref-3">3</a>」</p>
<!-- 同一条注的第二处引用，id 重复 -->
<a id="noteref-1" …>1</a> … <a id="noteref-1" …>1</a>
```

### 4.12.2 尾注文件

4.12.2.1　尾注文件名是 `endnotes.xhtml`，`body` 带 `epub:type="backmatter"`，在 spine 最后；目录里列为「注释」，landmarks 标 `endnotes`。（SE 7.E.7）

4.12.2.2　尾注文件只含一个 `section`，带 `id="endnotes"`、`class="endnotes"`、`epub:type="endnotes"`、`role="doc-endnotes"`；`section` 内是一个标题 `h2.chapter-title`（文字「注释」）和一个 `ol`（`h1` 只给书名页，见 4.3.1.1）。（SE 7.E.8）

4.12.2.3　全书只有一个 `ol`，不按章分组，不加章名小标题，不拆成多个 `ol`。（D7）

4.12.2.4　`ol` 的编号由列表自动生成，注文里不再写 `[1]`、`①`。

4.12.2.5　原书各章末的「注释」小标题和注释区并入此文件，原位置删除，记入删除清单。

### 4.12.3 注文

4.12.3.1　每条注是一个 `li`，id 为 `note-N`，N 与注号相同，按 N 递增。（SE 7.E.9、7.E.10）

4.12.3.2　`li` 上只写 `id`，不写 `epub:type="endnote"` 和 `role="doc-endnote"`（二者均已弃用）。

4.12.3.3　注文的每一段是一个 `p`；注文含引文、诗歌、列表时，保留 `blockquote`、诗歌的 `p`/`span` 结构、`ul`/`ol`，不压成一个 `p`。（SE 7.E.10）

4.12.3.4　注文内部的锚点 id 原样保留，并通过 `id_map` 保持外部链接有效。

4.12.3.5　注文以「同上」「同前」「同上书」「同前书」「同书」「前引书」「ibid.」开头时，不自动改；在重排注序之后，取紧邻的前一条注，若它只有一个来源，则生成展开建议（「同上，第 23 页」→「《书名》，第 23 页」）并报告；前一条有多个来源或不紧邻时，保留原文并报告。（SE 7.E.2）〔大模型〕

4.12.3.6　注文末尾是「——作者/书名」形式的出处署名，且原书已用 `cite` 时，保留 `cite`（含破折号）、其后一个空格再接回链；不主动给所有书名号加 `cite`。（SE 7.E.12）

### 4.12.4 回链

4.12.4.1　每条注有且只有一个回链：`a`，带 `class="backlink"`、`epub:type="backlink"`、`role="doc-backlink"`、`aria-label="返回正文"`，文字是 `↩`，`href` 指向对应注号的 id（`chapter01.xhtml#noteref-N`）。（SE 7.E.11）

4.12.4.2　注文最后一个块是 `p` 时，回链放在该 `p` 的末尾，前面恰好一个空格。

4.12.4.3　注文最后一个块不是 `p`（引文、诗歌、列表、表格）时，回链单独放在一个新 `p` 里，作为 `li` 的最后一个子元素。

4.12.4.4　回链的 `href` 随注号所在文件相对计算；注号被多处引用时指向第一处（4.12.1.6）。

**正例：单段注**
```html
<!-- endnotes.xhtml -->
<body epub:type="backmatter">
	<section id="endnotes" class="endnotes" epub:type="endnotes" role="doc-endnotes">
		<h2 class="chapter-title">注释</h2>
		<ol>
			<li id="note-1">
				<p>基本面分析者依据……解读市场的供求状况。 <a class="backlink" epub:type="backlink" role="doc-backlink" aria-label="返回正文" href="chapter01.xhtml#noteref-1">↩</a></p>
			</li>
```

**正例：多段注，末块是引文**
```html
			<li id="note-2">
				<p>梁启超在《少年中国说》中写道：</p>
				<blockquote>
					<p>少年智则国智，少年富则国富。</p>
				</blockquote>
				<p><a class="backlink" epub:type="backlink" role="doc-backlink" aria-label="返回正文" href="chapter01.xhtml#noteref-2">↩</a></p>
			</li>
		</ol>
	</section>
</body>
```

**反例**
```html
<!-- 带已弃用的 endnote；整条注被压成一个 p；回链放进 blockquote -->
<li id="note-2" epub:type="endnote" role="doc-endnote">
	<p>梁启超在《少年中国说》中写道：少年智则国智，少年富则国富。↩</p>
</li>
<li id="note-3"><blockquote><p>……<a class="backlink" …>↩</a></p></blockquote></li>
```

### 4.12.5 配对与重建

4.12.5.1　注号与注文数量一致、顺序对应时，自动重建；不能配对的，列入确认清单，不静默丢弃、不猜测。

4.12.5.2　重建只改标签、class 与位置，不改注文文字；保留原 id 与外部链接。

4.12.5.3　同一块只套一个角色；原书已有 `epub:type="noteref/footnote/endnote"` 时，视为强信号并改成本节写法。

4.12.5.4　正文括注（「（参见第三章）」）不是注释，不转换；双行小字夹注识别后只作建议〔人工〕。

### 识别信号

- 正文里 `<sup>\d+</sup>`、`[1]`、`（注1）`、`①–⑳`、指向文末的 `<a href="#…">`；文末或章末集中的 `[1] xxx`、`① xxx`、`注：`、`<ol>`；已有 `epub:type="noteref/footnote/endnote"`（强）。
- 配对：注号与注文数量一致且顺序对应，A；仅能部分配对，B 自动并报告；无法配对，C。
- 注文以「同上」「同前」等开头：C，仅建议。
- 注号紧贴 `。」`/`。”` 之内（后面紧跟闭引号）：B，自动移到闭引号之后；引文中原作者自带注号无法区分，只报告。

### CSS
```css
/* tpl:notes */
a.noteref{ font-size:.75em; line-height:0; vertical-align:super; font-style:normal; font-weight:normal;
	text-decoration:none; padding:0 .1em; }
section.endnotes > ol{ margin:1em 0; padding-left:2.5em; }
section.endnotes > ol > li{ margin:1em 0; font-size:.9em; line-height:1.6; }
section.endnotes li p{ margin:.3em 0; text-indent:0; text-align:justify; }
section.endnotes li blockquote{ margin:.5em 0 .5em 1em; }
a.backlink{ text-decoration:none; padding:0 .2em; }
```
（注号不用 `sup`：原书常见 `<sup><small>[1]</small></sup>`，叠加缩小后看不见。）

### 注意与降级

- 降级：丢 CSS 后注号是普通数字链接，注文是书末有序列表，回链可用。
- 不支持弹注的阅读器上，注号点击后整页跳到书末；这是预期行为。
- 竖排书里 `vertical-align:super` 的效果因阅读器而异，见 4.15【需实测】。
- 注号放入标题（`h1`–`h6`）时，不进入导航文字。

## 4.13 表格

适用于数据表、对照表、参数表。表格只用于表格数据，不用于版面。

### 4.13.1 结构

4.13.1.1　`tr` 一律放在 `thead`、`tbody` 或 `tfoot` 里，不作为 `table` 的直接子元素。（SE 5.7.1）

4.13.1.2　表头单元格用 `th`，不用 `td`；列表头 `th scope="col"`，行表头 `th scope="row"`。原书没有 `th` 时，把首行提升为 `thead` 的 `th`。（SE 5.7.2）

4.13.1.3　表中间的分组行（如「一、二、三」）放在各自 `tbody` 的第一行，写成 `<th colspan="N" scope="rowgroup">`；一张表可有多个 `tbody`。（SE 5.7.1.1）

4.13.1.4　合计、总计行用 `tfoot`，首格设 `th scope="row"`。末行首格匹配 `^(合计|总计|共计|小计|Total)$` 时只提示，用户确认后才移入 `tfoot`；中间的小计行不移出 `tbody`。（SE 5.7.3）

4.13.1.5　表题用 `caption`，写在 `table` 的第一个子元素位置；表号是真实文字，不用 CSS 计数器，不用表号做 id。

4.13.1.6　表注用紧跟在表后的 `p.table-note`，以「注：」开头，不缩进。

4.13.1.7　数字列的 `td` 加 `num` 类，右对齐；文字列需要强制左对齐时加 `text` 类。

4.13.1.8　斑马纹用显式的 `tr.odd`，不用 `:nth-child`。

4.13.1.9　`table` 的 id 只在被表格目录或正文引用时才生成，写成 `table-N`，全书流水号，从 1 起。

4.13.1.10　原书已有表格目录页（标题含「表格目录」「表目录」「表索引」）时，转成 `nav id="lot" class="lot" epub:type="lot"`，结构与 4.11.4 相同，条目链接指向 `table-N`；原书没有时不新建。

4.13.1.11　不用 `table` 排版。表格不得用于分栏、对齐正文或做对白版式；识别出此类用法时，改成对应的正文结构并报告。

### 4.13.2 线型与版式

4.13.2.1　全书线型统一，三种任选其一：默认三线表（顶线 2px、表头下线 1px、底线 2px、无竖线）、全线表（`all-line`）、省线表（`part-line`）。

4.13.2.2　表头与表身用字重和淡底（`rgba` 灰）区分，表头行的内边距大于表身。

4.13.2.3　列数大于 6，或总字符宽度超过约 36 字时，加 `compact` 类（字号 .8em，不再小）；仍放不下时只报告，建议转置或拆表。

4.13.2.4　两列小表加 `table-narrow` 类，居中。

4.13.2.5　整张表转成图片只作最后手段；转图时必须有 `alt` 和文本替代（03 §1.3）。〔人工〕

**正例**
```html
<table>
	<caption>表 2-1　各季度销量（万件）</caption>
	<thead><tr><th scope="col">季度</th><th scope="col">销量</th><th scope="col">同比</th></tr></thead>
	<tbody>
		<tr><th scope="row">一季度</th><td class="num">1,500</td><td class="num">+5%</td></tr>
		<tr class="odd"><th scope="row">二季度</th><td class="num">0.75</td><td class="num">-2%</td></tr>
	</tbody>
	<tfoot><tr><th scope="row">合计</th><td class="num">1,500.75</td><td class="num">—</td></tr></tfoot>
</table>
<p class="table-note">注：同比以上年同期为基数。</p>
```

**正例：多个 tbody 的分组行**
```html
<table>
	<caption>表 3-2　各地区人口</caption>
	<thead><tr><th scope="col">地区</th><th scope="col">人口（万）</th></tr></thead>
	<tbody>
		<tr><th colspan="2" scope="rowgroup">一、华北</th></tr>
		<tr><td>北京</td><td class="num">2,184</td></tr>
	</tbody>
	<tbody>
		<tr><th colspan="2" scope="rowgroup">二、华东</th></tr>
		<tr><td>上海</td><td class="num">2,487</td></tr>
	</tbody>
</table>
```

**反例**
```html
<table>
	<tr><td>季度</td><td>销量</td></tr>               <!-- 裸 tr；表头用 td -->
	<tr style="background:#eee"><td>一季度</td><td>1,500</td></tr>  <!-- 内联颜色 -->
</table>
<p class="table-title" style="color:red">表 2-1　各季度销量</p>    <!-- 表题用 p 加色 -->
```

### 识别信号

- `table`（强）；制表符或多空格分列的连续行（≥2 行、≥2 列、列数一致）；Markdown 风格 `|---|`；ASCII 框线；前一行是表题（`表\d+`、`^表[：:]`）；后一行是表注（`注：`）。
- 置信度：`table` 重建为 A；由文本行推断出的表格为 B（自动并报告）；ASCII 框线表为 C。
- 末行是「合计」类：C，只提示。
- 版面表（单行单列、嵌套表、含大图）：B，报告并改成正文结构。

### CSS
```css
/* tpl:table */
table.table-narrow{ width:auto; margin-left:auto; margin-right:auto; }
table.compact{ font-size:.8em; }
table.all-line{ border:2px solid; }
table.all-line th, table.all-line td{ border:1px solid rgba(127,127,127,.7); }
table.part-line{ border-top:2px solid; border-bottom:2px solid; }
table.part-line th + th, table.part-line td + td{ border-left:1px solid rgba(127,127,127,.7); }
table td.text{ text-align:left; text-indent:0; }
table th{ padding:.45em .5em; }
table th[scope="rowgroup"]{ text-align:left; background:rgba(127,127,127,.2); }
table tfoot th, table tfoot td{ border-top:1px solid; }
p.table-note{ margin:.3em 0 0; font-size:.8em; line-height:1.5; text-indent:0; text-align:left; }
div.table-wrap{ overflow-x:auto; }
nav.lot ol{ list-style:none; margin:.8em 0; padding-left:0; }
```
（默认表的 `table` 即三线表，数字列 `td.num` 与 `tr.odd` 的规则已在默认表中，此处不重复。）

### 注意与降级

- 宽度用 `%`；`div.table-wrap` 的横向滚动在分页阅读器里可能无效【需实测】。
- 数字列右对齐加 `tabular-nums`；小数位数悬殊时仍右对齐。
- 表头淡底在夜间模式下用 `rgba` 灰，不写死颜色。
- 降级：不支持 CSS 时仍是完整的 HTML 表格，`caption` 在表上方，`tfoot` 在最后显示（HTML 模型下 `tfoot` 可写在 `tbody` 后）。

## 4.14 封面、书名页、版权页

适用于封面页、书名页（扉页）、版权页。三者在前页，顺序是封面、书名页、版权页，位于目录之前。

### 4.14.1 封面

4.14.1.1　封面图在 OPF 里用 `properties="cover-image"` 声明一次；全书只有一个封面页，不重复。（01）

4.14.1.2　封面页是 spine 第一项，`body` 里只有一个 `section`，带 `epub:type="cover"` 和 `class="cover"`，`html` 或 `body` 上不加其他正文内容。

4.14.1.3　封面页用 SVG 整页图（推荐）：`svg` 的 `viewBox` 填封面图的像素宽高，`preserveAspectRatio="xMidYMid meet"`，`role="img"`，`aria-label` 写「封面：书名」。

4.14.1.4　不用 SVG 时，用 `img`，`role="doc-cover"`，`alt` 写「封面：《书名》」。

4.14.1.5　含内联 SVG 的封面文件，OPF `manifest` 里该项带 `properties="svg"`。

4.14.1.6　不用 `body` 背景图做封面。

4.14.1.7　原书封面页已存在时，重建后仍是这一页；OPF 声明了封面图而 spine 里没有封面页时，生成一个封面页放在 spine 首位。

**正例**
```html
<body class="cover-page">
	<section epub:type="cover" class="cover">
		<svg xmlns="http://www.w3.org/2000/svg" xmlns:xlink="http://www.w3.org/1999/xlink"
				version="1.1" width="100%" height="100%" viewBox="0 0 1600 2560"
				preserveAspectRatio="xMidYMid meet" role="img" aria-label="封面：书名">
			<image width="1600" height="2560" xlink:href="../images/cover.jpg"/>
		</svg>
	</section>
</body>
```

**反例**
```html
<body style="background:url(../images/cover.jpg)"><p>&#160;</p></body>
```

### 4.14.2 书名页

4.14.2.1　书名页是一个 `section`，带 `epub:type="titlepage"` 和 `class="titlepage"`，只含书名、作者、出版者三项，居中。

4.14.2.2　书名用 `h1.book-title`，作者用 `p.book-author`，出版者用 `p.book-publisher`。

4.14.2.3　书名页的 `h1` 不进导航（nav 范围见 01）。

4.14.2.4　只有书名的半书名页，`epub:type` 用 `halftitlepage`。

4.14.2.5　译者、作者的「著」「译」写在 `p.book-author` 内，与姓名之间用全角空格。

**正例**
```html
<section epub:type="titlepage" class="titlepage">
	<h1 class="book-title">书名</h1>
	<p class="book-author">作者　著</p>
	<p class="book-publisher">某某出版社</p>
</section>
```

### 4.14.3 版权页

4.14.3.1　版权页是一个 `section`，带 `epub:type="copyright-page"` 和 `class="copyright"`。

4.14.3.2　版权页每行信息一个 `p`，左对齐、不缩进；`h1`–`h6` 不用于版权信息。

4.14.3.3　版权页的书名、作者、标识符与 OPF 的 `dc:title`、`dc:creator`、`dc:identifier` 一致；不一致时只报告，不改。（01/07）

4.14.3.4　不为原书没有的版权页新建内容；版权声明、CIP、ISBN 的文字原样保留。

**正例**
```html
<section epub:type="copyright-page" class="copyright">
	<p><strong>书名</strong></p>
	<p>作者：某某</p>
	<p>出版：某某出版社</p>
	<p>ISBN：978-x-xxxx-xxxx-x</p>
	<p class="gap">本书版权归作者所有，未经许可不得转载。</p>
</section>
```

### 识别信号

- 封面：spine 第一项；仅含一个 `img` 或整页图；`epub:type="cover"`；OPF 里 `properties="cover-image"` 的图；文件名 `cover`。A。
- 书名页：仅书名、作者、出版社三要素，居中，位于前页。B。
- 版权页：关键词「版权所有|ISBN|出版社|出版|印刷|印次|定价|CIP|责任编辑」成组出现（≥3 项）；位于封面之后、目录之前；整页短行（≤30 字）居多。A。

### CSS
```css
/* tpl:cover */

.cover{ height:100%; margin:0; padding:0; text-align:center; }
.cover svg{ display:block; width:100%; height:100%; }

/* tpl:titlepage */
```

### 注意与降级

- 整页高度 `100%`/`100vh` 在分页模型下行为因阅读器而异【需实测】；软件按目标阅读器选择其一。

- 封面图尺寸、格式、体积见 05。

## 4.15 竖排

适用于整本竖排书（古籍、繁体文艺书）。局部竖排（单页标题）不在支持范围。

### 4.15.1 整本一致

4.15.1.1　竖排书的 OPF `spine` 带 `page-progression-direction="rtl"`。

4.15.1.2　`html` 的 `writing-mode`、OPF 的 `page-progression-direction`、语言（`zh-Hant` 或 `ja`）三者一致；不一致时报告，不静默改。（01、07）

4.15.1.3　竖排样式放在独立的 `vertical.css`，在 `stylesheet.css` 之后加载；`html` 上同时写 `-epub-writing-mode`、`-webkit-writing-mode`、`writing-mode`。

4.15.1.4　物理的 `margin`/`padding` 方向在竖排样式里改写成逻辑属性（`margin-block`、`margin-inline-start`、`padding-inline-start`）；不用 `text-align:left/right`，改用 `start`/`end`。

### 4.15.2 标点与数字

4.15.2.1　标点保持横排码位 `「」『』……——《》`，由字体的 `vert` 特性画成竖形；不手工替换为 `﹁﹂﹃﹄︙`。

4.15.2.2　竖排书的引号统一用 `「」『』`；简体 `“”` 在竖排下可能无竖形字形，不用。（06 引号风格）

4.15.2.3　2–4 位的阿拉伯数字用 `span.tcy` 横中横；单字母、缩写保持旋转（`text-orientation:mixed`）。

4.15.2.4　着重号 `.dot` 的 `text-emphasis-position` 取 `under right`（右侧）。

**正例**
```xml
<spine page-progression-direction="rtl"> … </spine>
```
```html
<html xmlns="http://www.w3.org/1999/xhtml" xmlns:epub="http://www.idpf.org/2007/ops" lang="zh-Hant" xml:lang="zh-Hant">
…<p>二〇二五年<span class="tcy">12</span>月<span class="tcy">3</span>日</p>
```

**反例**
```html
<p>二〇二五年12月3日，他说：“你好。”</p>      <!-- 数字未横中横；引号用了 “” -->
<p>﹁你好。﹂</p>                              <!-- 手工替换为竖排标点码位 -->
```

### 识别信号

- 原书已有 `writing-mode:vertical-*`（强）；OPF `page-progression-direction="rtl"` 且语言 `zh-Hant`/`ja`；横排码位的 `「」『』` 引号占多数；用户显式选择。
- 置信度：C，只建议；用户显式选择或原书已竖排时，保留竖排。

### CSS
```css
/* tpl:vertical */
html{ -epub-writing-mode:vertical-rl; -webkit-writing-mode:vertical-rl; writing-mode:vertical-rl; }
body{ text-orientation:mixed; }
.tcy{ -webkit-text-combine:horizontal; text-combine-upright:all; }
h1, .chapter-title, .part-title{ margin:0; margin-block-end:2em; text-align:start; }
h2{ margin:0; margin-block:1.5em .8em; }
p.gap{ margin:0; margin-block-start:1.5em; }
blockquote{ margin:0; margin-block:.75em; margin-inline-start:2em; }
blockquote p{ margin:0; margin-block:.35em; }
ul, ol{ margin:0; margin-block:.5em; padding:0; padding-inline-start:3.2em; }   /* 同 4.10.3.11 */
figure{ margin:0; margin-block:.8em; }
img{ max-width:100%; max-height:100%; }
.align-left{ text-align:start; } .align-right{ text-align:end; }
p.signature, p.date{ margin:0; margin-block:.3em; text-align:end; }
p.signature{ margin-inline-end:2em; }
.dot{ text-emphasis-position:under right; }
```

### 注意与降级

- 缩进：`text-indent:2em` 沿行方向（向下）缩进，照常使用【需实测】；原书「竖排不缩进」是私有行为，不照搬。
- 注号：`a.noteref` 在竖排里的上标位置因阅读器而异，必要时改成 `vertical-align:baseline` 并实测【需实测】。
- 竖排字体需含 `vert` 字形；默认字体缺失时才嵌入子集字体（03 §8.3）。
- 降级：不支持竖排的阅读器退回横排，内容顺序仍正确（DOM 顺序即阅读顺序）。

## 4.16 生僻字与图片字

适用于 Unicode 扩展区（A–F）及基本区之外的字，系统字体缺字时显示方块或空白。

### 4.16.1 处理顺序

4.16.1.1　对每个生僻字，按下列顺序选用第一个可行的方案，不跳级：替换为通行字、子集字体回落、图片字、IDS 描述。

4.16.1.2　替换为基本区的通行字、异体字或繁体字，只在语义确定不变时才做，记入报告；该操作在文本层（06）进行。〔人工〕

4.16.1.3　子集字体回落：嵌入只含这些字的子集字体（授权与 `fsType` 检查、子集化见 05 §3），字体栈末尾追加「Book Rare」，不改 HTML；回落字体的风格与正文不协调时，只作回落，并报告。

4.16.1.4　图片字：字库里都没有该字时，才用 `img.glyph`，高度 1em，`alt` 是该字本身（可复制、可搜索）；确无 Unicode 码位时，`alt` 写 IDS 描述，如「（⿱族鸟）」。（05 §3.2）

4.16.1.5　图片字文件名含码点（十六进制小写，如 `rare-2ee26.png`）；没有码点时用 `rare-<内容哈希前 8 位>`。

4.16.1.6　图片字优先用 `fill="currentColor"` 的 SVG；用透明 PNG 时按 4.11.1.11 处理夜间模式。

4.16.1.7　私用区字符（U+E000–F8FF、U+F0000 起）、`□`、`〓` 占位，不用图片或字体猜测替换，只报告并列出上下文，等人工补字。

4.16.1.8　需要给个别字单独指定字体时，用 `span.rare`；已靠字体栈回落的字，不包 `span`。

**正例**
```html
<p>此字作𬸦，见于……</p>
<p>此字作<span class="rare">𬸦</span>，见于……</p>
<p>此字作<img class="glyph" src="../images/rare-2ee26.png" alt="𮸦"/>，见于……</p>
<p>此字作（⿱族鸟），见于……</p>
```

**反例**
```html
<p>此字作<img src="../images/RareFont943B.png" alt="字"/>，见于……</p>   <!-- 无 glyph 类；alt 不是该字 -->
<p>此字作<span style="font-family:'Some Font'">&#xE123;</span>，见于……</p>  <!-- 私用区猜测 -->
```

### 识别信号

- 码位 `U+3400–4DBF`、`U+20000–2FA1F`、基本区上沿（≥U+9FA6）、私用区；`img` 小方图（≤2em、近 1:1）夹在文字中；方框 `□`、`▯`。
- 置信度：扩展区码位统计 A；替换为通行字 C（需用户确认）；子集字体回落 B；私用区 C，只报告。
- 全部码位统计写入报告。

### CSS
```css
/* tpl:rare */
@font-face{ font-family:"Book Rare"; src:url("../fonts/rare-subset.woff2") format("woff2"),
	url("../fonts/rare-subset.ttf") format("truetype"); }
body{ font-family:"Source Han Serif SC","Noto Serif CJK SC","Songti SC","SimSun","Book Rare",serif; }
span.rare{ font-family:"Book Rare","Source Han Serif SC","Songti SC",serif; }
```

### 注意与降级

- 字体风格协调与授权由用户确认。
- 图片字夜间模式不适配（透明黑字在深底消失），按 4.11.1.11 处理。
- 降级：字体不可用时，扩展区字显示方块；图片字不受影响。

## 4.17 注音

适用于拼音、注音符号、生僻字读音、日语振假名。

### 4.17.1 结构

4.17.1.1　注音用 `ruby`，每个 `ruby` 含被注文字、`rp`、`rt`、`rp`，写成 `<ruby>床<rp>（</rp><rt>chuáng</rt><rp>）</rp></ruby>`。

4.17.1.2　不写 `rb`；不对 `rp` 设 `display:none`。

4.17.1.3　注音单元要么逐字（每字一个 `ruby`），要么逐词（一个 `ruby` 含多字，`rt` 里的音节用空格分隔）；同一书内统一。

4.17.1.4　逐词注音时，`rt` 的音节数与被注汉字数一致；不一致时报告，不自动改。

4.17.1.5　含 `ruby` 的段落加 `has-ruby` 类；要使全文行高统一时，对整章的 `p` 或容器加 `has-ruby`。

4.17.1.6　`rt` 使用的字体需含带声调字母（ā á ǎ à ǖ ǘ ǚ ǜ）；缺字时嵌入子集字体（05、03 §8.3）。

4.17.1.7　括号形式的拼音（`汉字（pīnyīn）`），在拼音是带声调字母、且音节数与汉字数一致时才转成 `ruby`，其余保留原样。

**正例**
```html
<p class="has-ruby"><ruby>床<rp>（</rp><rt>chuáng</rt><rp>）</rp></ruby><ruby>前<rp>（</rp><rt>qián</rt><rp>）</rp></ruby>明月光</p>
<p class="has-ruby"><ruby>中国<rp>（</rp><rt>zhōng guó</rt><rp>）</rp></ruby></p>
```

**反例**
```html
<ruby><rb>床</rb><rt>chuang</rt></ruby>        <!-- 写了 rb；缺 rp；无声调 -->
<ruby>中国<rp>（</rp><rt>zhōng</rt><rp>）</rp></ruby>   <!-- 音节数与汉字数不一致 -->
```

### 识别信号

- 已有 `ruby`（强）；括号内拼音 `汉字（pīnyīn）` 且为带声调字母；`rb`（旧写法）；以注音为主的少儿读物、古诗拼音版。
- 置信度：已有 `ruby` 规范化为 A；括号拼音转 `ruby` 为 B（自动并报告）；无声调或逐字对不上为 C。

### CSS

默认表已含 `ruby`、`rt`（.55em、居中）和 `p.has-ruby`（行高 2.2）。增量：
```css
/* tpl:ruby */
p.has-ruby, div.has-ruby p{ line-height:2.2; }
```

### 注意与降级

- 行高不小于 2；含 `ruby` 的段与不含的段行高不同时会产生行距波动。
- 降级：不支持 `ruby` 的阅读器显示「床（chuáng）」。
- 竖排时注音出现在字的右侧；注音符号（ㄅㄆㄇ）的排位因阅读器而异【需实测】。

## 4.18 音视频

适用于书内嵌入的音频（朗读、示范发音）和视频。

### 4.18.1 结构

4.18.1.1　音频用 `audio`，视频用 `video`，都带 `controls="controls"`，不用 `autoplay`，`preload="none"`。

4.18.1.2　音频放在 `figure.media` 里，`figcaption` 写说明；视频带 `poster`、`width`、`height`。

4.18.1.3　`audio`/`video` 的子元素里放回退内容 `p.media-fallback`：说明当前阅读系统不支持播放，并给出指向文件的链接。

4.18.1.4　音视频文件必须是本书内的资源，在 OPF `manifest` 里用正确的 `media-type` 声明；核心媒体类型之外的格式须提供回退（01/05）。

4.18.1.5　不使用厂商私有类名与属性（占位图、激活图等）。

4.18.1.6　`embed`、`object` 指向 `.mp3/.m4a/.mp4/.webm` 的，转成 `audio`/`video`。

4.18.1.7　音频提供文字稿或文字说明（`figcaption` 或回退内容）。〔人工〕

4.18.1.8　「扫码收听」类文字与二维码图原样保留，并在报告中标出，由用户决定去留。

**正例**
```html
<figure class="media">
	<audio controls="controls" preload="none" src="../audio/tiger.mp3">
		<p class="media-fallback">当前阅读系统不支持音频播放。<a href="../audio/tiger.mp3">打开音频</a></p>
	</audio>
	<figcaption>虎吼</figcaption>
</figure>
<video controls="controls" preload="none" poster="../images/sunup.jpg" width="640" height="360">
	<source src="../video/sunup.mp4" type="video/mp4"/>
	<p class="media-fallback">当前阅读系统不支持视频播放。</p>
</video>
```

**反例**
```html
<audio src="../audio/tiger.mp3" autoplay="autoplay"></audio>     <!-- 自动播放、无 controls、无回退 -->
<embed src="../audio/tiger.mp3"/>
```

### 识别信号

- `audio`/`video`、指向 `.mp3/.m4a/.mp4/.webm` 的链接或 `embed`/`object`；「扫码收听」类文字。
- 置信度：已有 `audio`/`video` 规范化为 A；`embed`/`object` 转换为 B；文字提示为 C。

### CSS
```css
/* tpl:media */
figure.media audio{ width:100%; max-width:20em; }
figure.media video, video{ width:100%; height:auto; }
p.media-fallback{ margin:.5em 0; font-size:.875em; text-indent:0; text-align:left; }
```

### 注意与降级

- EPUB 3.3 对视频未规定核心格式，须按规范提供回退内容【以规范原文为准】。
- 降级：`media-fallback` 段落与链接（可下载或外部打开）。

## 4.19 术语表（新增）

只对原书已有的术语表（标题含「术语表」「名词解释」「词汇表」「译名对照表」「人名对照表」）做结构规范化；原书没有术语表时不新建。不生成 `glossary-search-key-map.xml`，不要求 OPF 里的词典声明。（SE 7.F.1、7.F.2）

### 4.19.1 结构

4.19.1.1　术语表是一个 `section`，带 `id="glossary"`、`epub:type="glossary"`、`role="doc-glossary"`，内含标题和一个 `dl.glossary`；`epub:type` 写在 `section` 上，不写在 `dl` 上。（SE 7.F.3）

4.19.1.2　新生成或重命名的术语表文件名用 `glossary.xhtml`，位置随原书（书末或附录内），`body` 的 `epub:type` 随位置取 `backmatter` 或 `bodymatter`。

4.19.1.3　词条是 `<dt epub:type="glossterm"><dfn>词</dfn></dt>`，`dt` 里必含 `dfn`。（SE 7.F.5）

4.19.1.4　释义是 `<dd epub:type="glossdef">`，至少含一个块级子元素（`p`）。

4.19.1.5　同一释义对应多个称呼（异名、译名）时，多个 `dt` 接一个 `dd`；`dt` 与 `dd` 不孤立。

4.19.1.6　词条带外文原名时，写成 `<dfn>词</dfn>（<span lang="en">Original</span>）`。

4.19.1.7　术语的 id 只在被正文链接引用时才生成，写成 `term-N`，全书流水号；正文里已有的指向术语表的链接，原样保留。

4.19.1.8　从「词：释义」成行文本或两列表格转换时，只作建议，用户确认后才转；三列及以上的对照表（如「原文／译名／说明」）保留为 `table`，按 4.13 处理。

**正例**
```html
<section id="glossary" epub:type="glossary" role="doc-glossary">
	<h1>术语表</h1>
	<dl class="glossary">
		<dt epub:type="glossterm"><dfn>夔</dfn></dt>
		<dd epub:type="glossdef"><p>传说中的一足神兽，状如牛，苍身而无角。</p></dd>
		<dt epub:type="glossterm"><dfn>庶人</dfn></dt>
		<dt epub:type="glossterm"><dfn>黔首</dfn></dt>
		<dd epub:type="glossdef"><p>平民百姓的泛称。</p></dd>
	</dl>
</section>
```

**反例**
```html
<dl>
	<dt>夔</dt>                                  <!-- 无 dfn、无 glossterm -->
	<dd>传说中的一足神兽。</dd>                    <!-- 无 glossdef、无块级子元素 -->
</dl>
<p><b>夔</b>：传说中的一足神兽。</p>              <!-- 成行文本未转 dl -->
```

### 识别信号

- 标题含上述词，正文是「词条＋全角冒号/破折号/空格＋释义」的成行文本，或两列表格。
- 置信度：标题命中且 ≥5 条为高（A）；结构转换总是 C，用户确认后才执行。

### CSS
```css
/* tpl:glossary */
dl.glossary{ margin:1em 0; }
dl.glossary dt{ margin-top:1em; font-weight:bold; text-indent:0; }
dl.glossary dd{ margin:.2em 0 0 2em; text-indent:0; }
dl.glossary dd p{ text-indent:0; }
```
（`dd` 的外边距用 em，不用 SE 的 40px。）

### 注意与降级

- 降级：不支持 CSS 时，`dl` 仍是词条加释义的列表。
- 术语表位置不强搬；保持在原书位置。
