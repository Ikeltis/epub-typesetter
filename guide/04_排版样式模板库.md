> 基准：EPUB 3.3；中文重排版。标记：【补】= 书外补充；【需实测】= 支持情况无把握。
> 基础样式表见 `03_CSS与中文排版规范.md` §11（下称「默认表」）。本文每个模板只写**增量**，不改默认表规则。

## 0. 总则

### 0.1 模板格式

每个模板含五项：**适用场景 / 识别信号 / HTML 结构 / CSS / 注意事项与降级**。

- **识别信号**写给启发式规则或 LLM 用：按「强信号 → 弱信号」排列，并给出建议的置信度处理（高：自动套用；中：自动套用但在报告中列出；低：只给建议，由用户开启）。输入已先经 06 的文本规范化与 02 的结构清洗（去手工缩进、合并硬回车、去内联样式）。
- **CSS** 块首行写 `/* tpl:名 */`，输出时**只输出被使用的模板**；块与块之间没有顺序依赖，但所有块排在默认表之后。
- 所有模板选择器的特异性 ≥ (0,1,1)，保证压过默认表中的元素选择器（如 `blockquote p`）而不用 `!important`。
- 模板不设 `color`/`background`（装饰灰 `rgba(127,127,127,x)` 除外），夜间模式安全（03 §9）。

## T1 目录页

**适用场景**：书中可见的目录页（导航文档 `nav epub:type="toc"` 兼作可见目录，或独立目录页）。

**识别信号**：已有 `nav epub:type="toc"`（强）；标题为「目录/目　录/Contents」；一列 `<a>`；或「章名……页码」行（点线、页码）；文件位于前页（版权页之后）。纸书目录的页码、点线引导符必须删除，重建成链接列表（置信度高）。

**HTML**
```html
<nav epub:type="toc" id="toc" role="doc-toc">
  <h1 class="chapter-title align-center">目录</h1>
  <ol>
    <li><a href="c01.xhtml">第一章　开端</a>
      <ol><li><a href="c01.xhtml#s1">一、缘起</a></li></ol></li>
    <li><a href="c02.xhtml">第二章　远行</a></li>
  </ol>
</nav>
```
**CSS**
```css
/* tpl:toc */
nav ol{ list-style:none; margin:0; padding:0; }
nav ol ol{ padding-left:1.5em; }                 /* [书] 每级退 1–2 字 */
nav li{ margin:.4em 0; line-height:1.5; text-indent:0; }
nav li a{ text-decoration:none; color:inherit; } /* 目录内链接可去下划线 */
nav.toc-hang li > a{ display:block; margin-left:2.5em; text-indent:-2.5em; }   /* 有序号：回行齐字；N 取序号宽 + 1 */
nav li.toc-part > a{ font-weight:bold; }         /* 篇名 */
```
**注意与降级**
- 无序号目录：回行缩格（默认即可）；有序号：加 `toc-hang` 悬挂缩进。
- `nav epub:type="landmarks"`、`page-list` 加 `hidden` 属性，不在可见目录中显示（01）。
- 目录页字体/字号全书统一；若目录是导航文档本身，注意 `h1.chapter-title` 的 25% 下沉可用 `align-center` 并保留。
- 降级：丢 CSS 后仍是可点击的嵌套有序列表。

## T2 章首与篇章页

**适用场景**：每章开头的标题区；多篇（部、卷）书的篇章页。

**识别信号**：文件首个标题块；匹配 `^第[0-9零〇一二三四五六七八九十百千两]+[章节回卷部篇集幕]`、`Chapter\s*\d+`、`序章|楔子|引子|前言|后记|尾声|番外|附录`；一个短段（≤30 字）、无句末标点、位于文件首（高）；篇章页：文件内仅有一个标题（及副题、题记、图片）而无正文（高）。章号+章名分在两行或同行用空格/冒号/`·` 分隔的，拆成两段式（中）。

**HTML（单行）**
```html
<section epub:type="chapter" role="doc-chapter">
  <h1>第一章　开端</h1>
  <p>……</p>
</section>
```
**HTML（章号 + 章名两行）**
```html
<h1><span class="title-num">第一章</span><span class="title-name">侯门庶子</span></h1>
```
**HTML（篇章页，含题记）**
```html
<section epub:type="part" role="doc-part">
  <h1 class="part-title">第一部　山河</h1>
  <p class="subtitle">1937–1945</p>
  <blockquote class="epigraph">……</blockquote>   <!-- T6 -->
</section>
```
**CSS**（默认表已含章首下沉；此处只加两行标题与篇章页修饰）
```css
/* tpl:chapter-head */
h1 .title-num{ margin-bottom:.3em; font-size:.75em; letter-spacing:.1em; }   /* 章号小于章名 */
h1 .title-name{ font-size:1em; }
.part-title + .subtitle{ margin-top:0; text-align:center; }
h1.chapter-title{ padding-bottom:.25em; border-bottom:1px solid rgba(127,127,127,.6); }  /* 可选：下划线式 [书] */
```
**注意与降级**
- 章首 `h1`（或 `.chapter-title`）每文件一个；节标题（h2+）出现在页中不要带下沉 margin（见 03 §6）。
- 篇章页用图片时，用 `<img>`，**不要靠 `body` 背景图**（部分 RS 不渲染 body 背景；夜间模式冲突）；见 T14 的整页图写法。
- `letter-spacing` 只用于章号这类短字；居中时末字后的空白会使视觉偏左，需要时给居中元素加同值 `padding-left`（【补】）。

## T3 各级标题

**适用场景**：节、小节、小小节标题。

**识别信号**：已有 `h2–h6`（强，但需校正层级，不依赖原标签）；独占一段、≤25 字、无句末标点、前后为长段落；以 `一、`、`（一）`、`1.`、`1.1` 开头；字号/加粗/居中与周围不同。层级由编号模式聚类：同一模式 = 同一级；`一、` → h2，`（一）` → h3，`1.` → h3/h4 视上下文；输出不跳级（h1→h3 视为错误）。

**HTML**
```html
<h2>一、缘起</h2>
<h3>（一）背景</h3>
<h3 class="align-center">（二）居中小标题</h3>
```
**CSS**：默认表已含 h2–h6，无增量。
**注意与降级**
- 数值见 03 §6：h2 1.3em / h3 1.15em / h4 1.05em 粗体 / h5–h6 1em 粗体；节内标题 `margin-top ≥ 1.5 × margin-bottom`。
- 无编号小标题不要用加粗 `<p>`，用 `h3/h4`。若原稿的小标题只作视觉分段不进目录，仍用标题标签（目录收录范围由 nav 决定，见 01）。
- 层级不一致（同级标题样式不同）→ 报告。

## T4 正文

**适用场景**：普通叙述性段落。

**识别信号**：其余 `<p>`。子类：
- `noindent`：引文/图/表打断后**接着上文同一段**的续句；原稿（PDF/纸书）明确无缩进的段落（中）。标题后首段**不**默认无缩进（03 §5）。
- `gap`（空一行）：原文中用空行/空段隔开的场景切换（已转为 margin）。
- 场景分隔：独段 `* * *`、`***`、`◇◇◇`、`——`、`<hr/>`（高）。

**HTML**
```html
<p>近日，解放军报发表文章……</p>
<p class="noindent">（接着引文的续句）……</p>
<p class="gap">（空一行后的段落）……</p>
<p class="sep" role="separator">＊　＊　＊</p>
<hr/>                              <!-- 或：线条式分隔 -->
```
**CSS**：默认表已覆盖，无增量。无缩进主题见 03 §5。
**注意与降级**
- 缩进与段距二选一（03 §5）。
- 分隔符 `＊　＊　＊` 属文本，由 06 统一为单一写法；分隔后首段是否缩进：中文惯例缩进，保持默认。
- 降级：段间由 RS 默认段距分隔。

## T5 首字下沉

**适用场景**：文艺书章首段（可选主题，默认关闭）。

**识别信号**：用户启用该主题；章首标题后的第一个正文段（高）；该段首字符不是数字、西文；首字符为开引号时，把「引号+首字」作为下沉单位（中）；段长 ≥ 两行以上（≥ 40 字）。短于两行的段不下沉。

**HTML**
```html
<p class="noindent"><span class="dropcap">那</span>天夜里，风很大……</p>
```
**CSS**
```css
/* tpl:dropcap */
.dropcap{ float:left; font-size:3.2em; line-height:1; margin:.04em .1em 0 0; text-indent:0; }
```
**注意与降级**
- 3.2em = 两行行高（1.6 × 2），三行下沉用 4.8em；字号过大会引起首行排版错位，先在窄屏实测【需实测】。
- 用 `<span>` + float，不依赖 `::first-letter`（首字是标点或引号时 `::first-letter` 行为不稳）；`initial-letter` 属性新近出现，支持不一【需实测】，不采用。
- 首段需 `noindent`（浮动字已占位）。

## T6 引文

**适用场景**：块引用（引用他人文字、文献、古文）。

**识别信号**：已有 `blockquote`（强）；整段被引号包裹；左缩进明显或字体/字号与正文不同；前一段以「：」结尾后的缩进段；连续多段字号小于正文；`<div>` 带 `margin-left`。「冒号结尾 + 下一段整体引号包围」→ 中。

**HTML**
```html
<p>他在信中写道：</p>
<blockquote>
  <p>今日事势，譬之于病，……</p>
  <p class="noindent attribution">——梁启超《少年中国说》</p>
</blockquote>
<p class="noindent">这段话至今读来仍……</p>      <!-- 续句接排时才用 noindent -->
```
**CSS**（默认表已含 `blockquote` 基本样式：左 2em，上下 .75em，段距 .35em，楷体，行高 1.5，首行缩进 2em）；增量：
```css
/* tpl:quote */
blockquote + p.noindent{ margin-top:.75em; }
p.attribution{ margin:.4em 0 0; text-indent:0; text-align:right; font-size:.875em; }
blockquote p.attribution{ font-family:inherit; }
div.poem-quote{ margin:.75em 0 .75em 2em; }     /* 文中引诗：见 T9 */
```
**注意与降级**
- 规则：左缩进 2em、上下 .75em、非正文字体、行高略紧（不小于 1.4）、紧接引文的**续句**不缩进，新段仍缩进。
- 引号：块引用已用缩进与字体区分，**不再带外层引号**（若原稿带，保留与否由 06 引号风格决定，不要双重标记）。
- 出处写在 `p.attribution`，右对齐；其前的破折号属文本，写 `——`（偶数）。

## T7 题记与卷首语

**适用场景**：章/书首的题词（epigraph）、卷首语（编者或作者的开卷短文）。

**识别信号**：
- 题记：紧随章标题之后、正文之前；≤ 80 字；末尾（或下一行）有 `——人名`、`《书名》`、`—— xxx` 出处；字体/字号与正文不同或居右；常在引号内（高）。
- 卷首语：位于篇章页或章首，数行（≤ 8 行）、每行短、无出处，或标题为「卷首语/开篇语/写在前面」（中）。
- 献辞：「献给……」「谨以此书献给」，独占一页（高）：用 `epub:type="dedication"`，样式同卷首语居中。

**HTML**
```html
<blockquote class="epigraph" epub:type="epigraph" role="doc-epigraph">
  <p>生年不满百，常怀千岁忧。</p>
  <p class="attribution">——《古诗十九首》</p>
</blockquote>

<div class="lead" epub:type="foreword">
  <p>这是一本关于……</p>
</div>
```
**CSS**
```css
/* tpl:epigraph */
blockquote.epigraph{ margin:1em 0 2em 3em; font-size:.95em; }
blockquote.epigraph p{ margin:.2em 0; text-indent:0; text-align:left; }
div.lead{ margin:1.5em 2em; font-family:"STFangsong","FangSong",serif; }
div.lead p{ margin:.35em 0; text-indent:0; text-align:center; }
```
**注意与降级**
- 题记左缩进 3em 使其区别于普通引文；不超过版心 2/3。
- 卷首语若是整段文章而非短句，改用 `.lead p{text-align:justify; text-indent:2em}`。
- 降级：回落为普通 `blockquote`。

## T8 书信

**适用场景**：书信、日记体、通信集。

**识别信号**（出现下列件数越多越可信；≥3 件且含称谓则高）：
1. 称谓：首段 `^[^，。！？\n]{1,12}[：:]$`（「西谛先生：」）；
2. 正文若干段；
3. 祝颂语：`此致|敬礼|顺颂|并颂|谨上|敬上|顿首|拜上|匆此|专此|即颂`；
4. 署名：≤10 字短行，常带「启/上/拜」；
5. 日期：`^\d{4}年\d{1,2}月\d{1,2}日$`、`^[〇一二三四五六七八九十]+年…月…日$` 或 `二月五日`；
6. 书信集标题：`致X`、`与X书`，常带日期。

**HTML**
```html
<div class="letter">
  <h3 class="letter-title">致许家惺<span class="letter-date">一八九八年二月十七日</span></h3>
  <p class="salutation">西谛先生：</p>
  <p>昨乔峰交到惠赠之……</p>
  <p>此布，并颂</p>
  <p class="closing">曼福</p>
  <p class="signature">迅　启上</p>
  <p class="date">二月五日</p>
</div>
```
**CSS**
```css
/* tpl:letter */
div.letter{ margin:1.2em 0; }
h3.letter-title{ margin:1em 0 .8em; font-size:1.15em; text-align:center; }
.letter-date{ margin-left:.5em; font-size:.75em; font-family:"Kaiti SC","STKaiti","KaiTi",serif; }
p.salutation{ margin:.5em 0; text-indent:0; text-align:left; }              /* 称谓顶格 */
p.closing{ margin:.2em 0 .5em; text-indent:0; text-align:left; }           /* 祝颂语第二行顶格 */
p.signature{ margin:.5em 2em .2em 0; text-indent:0; text-align:right; }    /* 署名右齐，右缩 2em [书] */
p.date{ margin:.2em 0 .5em; text-indent:0; text-align:right; }             /* 日期右齐 */
.letter + p{ margin-top:.8em; }
```
**注意与降级**
- 书信行高沿用默认 1.6（原书 1.35 偏紧，改）；正文仍缩进 2em。
- 「此致/敬礼」两行：上句缩进或不缩进随原稿，下句顶格（`closing`）。
- 署名/日期类 `signature`、`date` 同样用于章末署名、序言落款，不限书信。
- 整封信放进 `div.letter`，与外部正文留间距；没有完整五件套时只套称谓、署名、日期，不强行包 `.letter`。

## T9 诗词曲

**适用场景**：古诗、词、曲、现代诗、歌词。

**识别信号**（综合打分，诗词误判代价高，默认「中」，列入确认清单）：
- 连续 ≥2 行；每行字数 ≤20（古体 ≤ 10 字/半句）；各行长度相近或相等（偏差 ≤1）；多数行以 `，。？！；` 结尾；
- 五言 `^.{5}[，。]$`、七言 `^.{7}[，。]$` 句式，或每行含两个半句（`秦时明月汉时关，万里长征人未还。`）；
- 前一行是诗题 + 作者：`《X》`、`X·Y`、作者 2–4 字后无标点、`〔朝代〕作者`；
- 原稿字体为仿宋/楷体，每行一个 `<p>`/`<br/>`；
- 词：出现词牌名（`《水调歌头》`、`水调歌头·题`）、行长短不一、「上阕/下阕」或分成两段；
- 现代诗：短行、无固定长度、行末无句号。

排版分型：规整诗（所有行等长 ±1 且含偶数个半句）→ 居中；杂言、词、现代诗 → 居左；诗行过长或要跨屏适配 → 自适应换行。

**HTML：居中（规整）**
```html
<div class="poem poem-center">
  <p class="poem-title">登幽州台歌</p>
  <p class="poem-author">陈子昂</p>
  <div class="stanza">
    <p>前不见古人，后不见来者。</p>
    <p>念天地之悠悠，独怆然而涕下。</p>
  </div>
  <p class="attribution">——《陈拾遗集》</p>
</div>
```

## T10 条款版式

**适用场景**：法律、规章、章程、合同的条文；带「（一）（二）」序号的项目。

**识别信号**：`^第[0-9零〇一二三四五六七八九十百千]+条`（强）；连续多段以 `（一）`、`（二）`、`1.`、`①` 开头；上下文出现「章/节」标题（`第一章 总则`）；位于规章类文本。置信度高。

**HTML**
```html

<p class="article"><span class="article-no">第十一条</span>　……</p>
<p class="item hang-3">（一）……；</p>
<p class="item hang-3">（二）……。</p>
```
**CSS**
```css
/* tpl:article */
p.article{ margin:.5em 0; }                                   /* 默认：首行缩进 2em，回行顶格——中文条文的通行排法 */
p.article-hang{ margin:.5em 0 .5em 5em; text-indent:-5em; }   /* 变体：悬挂；5em = 最长条号字数 + 1，软件按全书计算 */

```
**注意与降级**
- 默认排法不需要对齐技巧；原书用透明 `border` 补字距使「条」后对齐，仅在老 RS 上才有意义，**不采用**。
- 悬挂变体的 `span` 内 `text-indent:0` 必须写（否则继承负缩进）；条号后用一个全角空格（文本）。
- 编号 `（一）` 用手写文本；确需自动编号时用 `ol`，但不依赖 `cjk-ideographic`（03 §7.7）。
- 降级：丢 CSS 后每条一段，条号仍在文字里。

## T12 插图

**适用场景**：单图、并列图、行内图、绕排图；含夜间模式下透明图处理。图注见 T13，图片规格见 `05_图片与字体资源.md`。

**识别信号**：`<img>`（强）；独占一段的图；图后紧跟短句图注（≤40 字、`^图\s*\d`、`^(Figure|Fig\.)`、居中小字）；行内图：位于文字中间、尺寸 ≤ 2em（约 ≤64px）、近 1:1（高）；两张同尺寸图紧邻（并列）；`float`/`align` 属性（绕排）。原则：先见文后见图，图随文走，图不越过小标题。

**HTML：单图**
```html

  <figcaption>北洋海军「致远号」官兵</figcaption>
</figure>
```
**HTML：并列（2 张）**
```html
<figure class="figure-group">
  <div class="figure-row">
    <figure class="figure-col"><img src="../images/a.jpg" alt="…"/><figcaption>（a）正面</figcaption></figure>
    <figure class="figure-col"><img src="../images/b.jpg" alt="…"/><figcaption>（b）侧面</figcaption></figure>
  </div>
  <figcaption>图 3-2　外观</figcaption>
</figure>
```

三张以上同尺寸：各自成 `figure` 竖排依次展示（不做滑动画廊）。

**HTML：行内图**

**HTML：绕排**
```html

<div class="clear"></div>
```
**CSS**
```css
/* tpl:figure */
figure{ margin:.8em 0; }                                          /* 默认表已含；此处只列增量 */
```

**夜间模式下的透明图**
- 问题：黑线透明 PNG/SVG 在深色背景上不可见。RS 的夜间模式不会替书修改图片。
- 方案（由稳到不稳）：① 导出时给图加**不透明浅色底**（05）；② 加 `.line-art`（白底板，任何 RS 都可见，代价是夜间出现白框）；③ 可选增强：`@media (prefers-color-scheme:dark){ img.line-art{ filter:invert(1) hue-rotate(180deg); background:none; padding:0; } }`，仅限单色线稿，是否被评估【需实测】；④ 矢量 SVG 用 `currentColor` 作描边/填充，随主题变色（内联 SVG 才行，`<img src=*.svg>` 不继承）。

**注意与降级**
- 图宽用 `%`（100/80/60），不用固定 px；高度 `auto`。
- 并列图：每张宽度之和 + 间隙 <100%，用 `inline-block` 而非 `flex/table`；不支持时自然上下堆叠。
- 绕排只用于竖长窄图；图文间距 ≥1em；浮动元素前一段不要依赖外边距合并（浮动不合并）；手机宽度不绕排；每个浮动图后在合适位置 `clear`。
- 所有图 `alt` 非空（装饰图 `alt=""`）；信息图 alt 写出结论。
- 降级：`figure` 丢 CSS 后为居中块，图与 `figcaption` 相邻。

## T14 封面页

**适用场景**：书的封面；篇章整页图。

**识别信号**：spine 第一项；仅含一个 `img` 或一个整页图；`epub:type="cover"`；OPF 中 `properties="cover-image"` 的图（01）；文件名 `cover`。高置信度。**封面图在 OPF 声明一次即可，不要在正文里再加一页造成封面重复出现**（01）。

## T16 注释（EPUB 3 标准弹注）

**适用场景**：脚注/尾注/随文注。使用 EPUB 3 标准语义，由 RS 自行决定弹出窗口或跳转。**一书一种方案，不混用**。

**识别信号**：正文里 `<sup>\d+</sup>`、`[1]`、`（注1）`、`①–⑳`、`<a href="#…">` 指向文末；文末/章末集中的 `[1] xxx`、`① xxx`、`注：`、`<ol>`；已有 `epub:type="noteref/footnote"`（强）。需配对：锚点与注文数量一致且顺序对应（高）；不能配对的列入确认清单。

**HTML：同文件脚注（推荐）**
```html
<p>小说总集。<a class="noteref" epub:type="noteref" role="doc-noteref" href="#fn1" id="fnref1"><sup>1</sup></a>李昉等编辑。</p>

<section class="footnotes" epub:type="footnotes">
  <aside id="fn1" epub:type="footnote" role="doc-footnote">
    <p><a class="backlink" role="doc-backlink" href="#fnref1">1</a>　朝代名。宋太祖赵匡胤……</p>
  </aside>
</section>
```
**HTML：章末尾注（跨文件）**
```html
<!-- 正文 c01.xhtml -->
<a class="noteref" epub:type="noteref" role="doc-noteref" href="notes.xhtml#en1" id="enref1"><sup>1</sup></a>
<!-- notes.xhtml -->
<section class="endnotes" epub:type="endnotes" role="doc-endnotes">
  <h2>注释</h2>
  <ol>
    <li id="en1" epub:type="endnote" role="doc-endnote"><p>……<a class="backlink" role="doc-backlink" href="c01.xhtml#enref1">↩</a></p></li>
  </ol>
</section>
```
**CSS**
```css
/* tpl:notes */
a.noteref{ padding:.2em .15em; text-decoration:none; }          /* 扩大点击区，不依赖 sup 的 smaller */
a.noteref sup{ font-size:.7em; line-height:0; }                 /* 与默认表 sup 一致，勿再给 a 加字号造成双重缩小 */
section.footnotes{ margin-top:2em; }
section.footnotes::before{ content:""; display:block; width:30%; margin-bottom:.6em; border-top:1px solid; }  /* 注线：版心宽 1/4–1/3 [书] */
section.footnotes aside, section.endnotes li{ margin:.4em 0; font-size:.875em; line-height:1.5;
  font-family:"Kaiti SC","STKaiti","KaiTi",serif; }              /* [书] 小两号：.85–.875em */
section.footnotes aside p, section.endnotes li p{ margin:.2em 0; text-indent:0; text-align:justify; }
a.backlink{ text-decoration:none; }
```
**注意与降级**
- 弹注依赖 `epub:type="noteref"` + `aside epub:type="footnote"`；`role="doc-*"`（DPUB-ARIA）提供无障碍语义。EPUB 3.3 把这类弹出行为交给 RS，具体表现因 RS 而异【需实测】。
- **不要 `display:none` 隐藏 `aside`**（原书笔记中「aside 必须 display 不显示」的说法不采用）：不支持弹注的 RS 要能在文末读到注文；支持的 RS 会自行处理。
- 注文**必须带回链**（`backlink`），便于不支持弹注时返回。
- 注文区分手段：小两号（.875em）+ 楷体/仿宋 + 注线 + 编号；译者注：句号后加破折号 +「译者注」，文本层。
- 注释图标图片（锚点是小图）不采用；alt 属性塞注文的做法不采用。
- 降级：丢 CSS 后注文在文末成块，回链可用。

## T17 注音 ruby

**适用场景**：拼音、注音符号、生僻字读音、日语振假名。

**识别信号**：已有 `ruby`（强）；括号内拼音 `汉字（pīnyīn）` 且拼音为带声调字母；`<rb>`（旧写法）；以注音为主的少儿读物、古诗拼音版。逐字拼音须与汉字数一致。

**HTML**
```html
<p class="has-ruby"><ruby>床<rp>（</rp><rt>chuáng</rt><rp>）</rp></ruby><ruby>前<rp>（</rp><rt>qián</rt><rp>）</rp></ruby>明月光</p>
<!-- 多字词：-->
<ruby>中国<rp>（</rp><rt>zhōng guó</rt><rp>）</rp></ruby>
```
**CSS**：默认表已含 `ruby`、`rt`（.55em、居中）、`p.has-ruby`（行高 2.2）。增量：
```css
/* tpl:ruby */
p.has-ruby, div.has-ruby p{ line-height:2.2; }
```
**注意与降级**
- 不写 `<rb>`；不对 `rp` 设 `display:none`。
- `rt` 字体需含带声调字母（ā á ǎ à ǖ ǘ ǚ ǜ），否则回落字体不一致；必要时嵌入子集（05、03 §8.3）。
- 行高 ≥2；含 ruby 的段与不含的段行高不同时，会产生行距波动，要让全文统一时对整章加 `has-ruby`。
- 降级：不支持 ruby 的 RS 显示「床（chuáng）」。

## T18 表格

**适用场景**：数据表、对照表、参数表。

**识别信号**：`<table>`（强）；制表符/多空格分列的连续行（≥2 行 ≥2 列，列数一致）；Markdown 风格 `|---|`；ASCII 框线；前一行是表题（`表\d+`、`^表[：:]`）；后一行是表注（`注：`）。

**HTML**
```html
<table>
  <caption>表 2-1　各季度销量（万件）</caption>
  <thead><tr><th>季度</th><th>销量</th><th>同比</th></tr></thead>
  <tbody>
    <tr><td>一季度</td><td class="num">1,500</td><td class="num">+5%</td></tr>
    <tr class="odd"><td>二季度</td><td class="num">0.75</td><td class="num">-2%</td></tr>
  </tbody>
</table>
<p class="table-note">注：同比以上年同期为基数。</p>
```
**CSS**：默认表的 `table` 即**三线表**（顶线 2px、表头下线 1px、底线 2px、无墙线）。变体增量：
```css
/* tpl:table */
table.table-narrow{ width:auto; margin-left:auto; margin-right:auto; }      /* 两列小表 */
table.compact{ font-size:.8em; }                                             /* 列多时缩小，不小于 .8em */
table.all-line{ border:2px solid; }                                          /* 全线表 [书] */
table.all-line th, table.all-line td{ border:1px solid rgba(127,127,127,.7); }
table.part-line{ border-top:2px solid; border-bottom:2px solid; }            /* 省线表：只留栏线 */
table.part-line th + th, table.part-line td + td{ border-left:1px solid rgba(127,127,127,.7); }
table td.text{ text-align:left; text-indent:0; }
table th{ padding:.45em .5em; }                                              /* [书] th .45em > td .35–.4em：表头高于表身 */
p.table-note{ margin:.3em 0 0; font-size:.8em; line-height:1.5; text-indent:0; text-align:left; }  /* 表注：「注：」前不缩进，回行齐 */
div.table-wrap{ overflow-x:auto; }                                           /* 宽表横向滚动：分页 RS 里可能无效【需实测】 */
```
**注意与降级**
- 线型全书一致（全线/省线/三线任选其一，默认三线）；表头与表身区分：加粗 + 淡底（`rgba` 灰）+ 表头行高大于表身。
- 数字列 `td.num` 右对齐 + `tabular-nums`；小数点位数相近 → 右对齐即对位；位数悬殊 → 右齐。
- 斑马纹用显式 `tr.odd`，不用 `:nth-child`。
- 宽度用 `%`；列数 >6 或总字符宽 > 屏幕约 36 字 → 加 `.compact`；仍放不下 → 报告，考虑转置/拆表；整表转图片仅作最后手段（须有 alt 与文本替代，03 §1.3）。
- 表题用 `<caption>`（默认表有样式），不再用 `p.table-title` 加色；表注 `p.table-note` 紧跟表后。

## T19 竖排

**适用场景**：整本竖排书（古籍、繁体文艺书）。局部竖排（单页标题）不在支持范围。

**识别信号**：原书已有 `writing-mode:vertical-*`（强）；OPF `page-progression-direction="rtl"` 且语言 `zh-Hant`/`ja`；横排码位的 `「」『』` 引号占多数；用户显式选择。

**HTML（OPF 与根元素）**
```xml
<spine page-progression-direction="rtl"> … </spine>   <!-- 01 -->
```

```html
<html xmlns="http://www.w3.org/1999/xhtml" xmlns:epub="http://www.idpf.org/2007/ops" lang="zh-Hant" xml:lang="zh-Hant">
…<p>二〇二五年<span class="tcy">12</span>月<span class="tcy">3</span>日</p>
```
**CSS（`vertical.css`，在 `stylesheet.css` 之后加载）**
```css
/* tpl:vertical */
html{ -epub-writing-mode:vertical-rl; -webkit-writing-mode:vertical-rl; writing-mode:vertical-rl; }
body{ text-orientation:mixed; }
.tcy{ -webkit-text-combine:horizontal; text-combine-upright:all; }       /* 横中横：2–4 位数字 */
/* 物理 margin/padding 改逻辑属性：块方向=水平（右→左），行方向=垂直（上→下） */
h1, .chapter-title, .part-title{ margin:0; margin-block-end:2em; text-align:start; }
h2{ margin:0; margin-block:1.5em .8em; }
p.gap{ margin:0; margin-block-start:1.5em; }
blockquote{ margin:0; margin-block:.75em; margin-inline-start:2em; }
blockquote p{ margin:0; margin-block:.35em; }
ul, ol{ margin:0; margin-block:.5em; padding:0; padding-inline-start:2em; }
figure{ margin:0; margin-block:.8em; }
img{ max-width:100%; max-height:100%; }
.align-left{ text-align:start; } .align-right{ text-align:end; }
p.signature, p.date{ margin:0; margin-block:.3em; text-align:end; }
p.signature{ margin-inline-end:2em; }
.dot{ text-emphasis-position:under right; }                            /* 竖排取右侧 */
```
**注意与降级**
- 整本一致：`page-progression-direction`、`html` 的 `writing-mode`、`lang` 三者一致（01、07）。
- **标点**：输入保持横排码位 `「」『』……——《》`，由字体 `vert` 特性画成竖形；**不要手工替换为 `﹁﹂﹃﹄︙`**；简体 `“”` 在竖排下可能无竖形字形，竖排书统一用 `「」『』`（06 引号风格）。
- 缩进：`text-indent:2em` 沿行方向缩进（向下），照常使用【需实测】；原书「竖排不缩进」是私有行为。
- 西文长串旋转后难读；2–4 位数字用 `.tcy`；单字母/缩写可保持旋转（`mixed`）。
- 竖排字体：需含竖排字形（`vert`）；RS 默认字体缺失时才嵌入子集字体（03 §8.3）。
- 降级：不支持竖排的 RS 退回横排，内容顺序仍正确（因 DOM 顺序即阅读顺序）。

## T20 生僻字

**适用场景**：Unicode 扩展区（A–F）及基本区外的字，系统字体缺字出现方块或空白。

**识别信号**：字符码位 `U+3400–4DBF`、`U+20000–2FA1F`、基本区上沿（≥U+9FA6）、私用区（`U+E000–F8FF`、`U+F0000+`）；`<img>` 小方图（≤2em、近 1:1）夹在文字中；方框 `□`、`▯`。

**HTML**
```html
<p>此字作𬸦，见于……</p>                                   <!-- 方案 B：不改文本，靠回落字体 -->
<p>此字作<span class="rare">𬸦</span>，见于……</p>        <!-- 方案 B'：需要单独指定时 -->
<p>此字作（⿱族鸟），……</p>                              <!-- 方案 D：IDS 描述 -->
```
**CSS**
```css
/* tpl:rare */
@font-face{ font-family:"Book Rare"; src:url("../fonts/rare-subset.woff2") format("woff2"),
  url("../fonts/rare-subset.ttf") format("truetype"); }
body{ font-family:"Source Han Serif SC","Noto Serif CJK SC","Songti SC","SimSun","Book Rare",serif; }  /* 回落字体放栈末，免包 span */
span.rare{ font-family:"Book Rare","Source Han Serif SC","Songti SC",serif; }
```
**处理顺序（由稳到烦）**
1. **替换**为基本区的通行字/异体/繁体（须确认语义不变；文本层，06）。
2. **子集字体回落**：嵌入只含这些字的子集字体（05：授权、`fsType`、子集化），`font-family` 末尾追加，不需改 HTML。字体风格与正文可能不协调，只作回落。
3. **图片**（T12 `img.glyph`，夜间不适配，须写 alt）。
4. **IDS 描述** `（⿱族鸟）`（U+2FF0–2FFB，括号括起）。
5. 私用区自造字：不推荐（无语义、不可交换）。
**注意**：软件流程 = 检测扩展区 → 尝试替换 → 否则子集字体回落；全部码位统计写入报告。字体风格协调与授权由用户确认。

## T21 音视频

**适用场景**：书内嵌音频（朗读、示范发音）、视频。

**识别信号**：`<audio>`/`<video>`、指向 `.mp3/.m4a/.mp4/.webm` 的链接或 `<embed>`、`<object>`；「扫码收听」类文字。

**HTML**
```html
<figure class="media">
  <audio controls="controls" preload="none" src="../audio/tiger.mp3">
    <p class="media-fallback">当前阅读系统不支持音频播放。<a href="../audio/tiger.mp3">打开音频</a></p>
  </audio>
  <figcaption>虎吼</figcaption>
</figure>
<video controls="controls" preload="none" poster="../images/sunup.jpg" width="640" height="360">
  <source src="../video/sunup.mp4" type="video/mp4"/><p class="media-fallback">当前阅读系统不支持视频播放。</p>
</video>
```
**CSS**
```css
/* tpl:media */
figure.media audio{ width:100%; max-width:20em; }
figure.media video, video{ width:100%; height:auto; }
p.media-fallback{ margin:.5em 0; font-size:.875em; text-indent:0; text-align:left; }
```
**注意与降级**
- 音视频格式、核心媒体类型与 manifest `media-type`、回退（fallback）要求见 01/05；EPUB 3.3 对视频未规定核心格式，须按规范提供回退内容【补，以规范原文为准】。
- `controls` 必须；`autoplay` 不用；`preload="none"` 省流量。
- 不使用厂商私有类名/属性（占位图、激活图等）。
- 降级：`media-fallback` 段落与链接（可下载或外部打开）。

## 对优化软件的含义

1. 规则以 YAML/JSON 声明：`id`、`role`、`signals[]`（权重、正则/DOM 谓词）、`threshold_auto/suggest`、`template`、`tests[]`（输入→期望输出，幂等）。CSS 块以 `/* tpl:名 */` 为边界，只输出用到的模板。
2. 置信度分层：A（自动）—— 标题、图片/图注、表格、条款、目录、版权/书名/封面、注释配对；B（自动并列入报告）—— 引文、书信、题记；C（只建议）—— 诗词曲、剧本、首字下沉、竖排。
3. 套模板只改标签与 class，不改文字；保留原 `id`、锚点、链接；同一块只套一个角色，冲突取高分并记录。
4. 先清洗后识别：手工缩进、空段、`<br/>` 分段、内联 `style`、`<center>/<font>` 转 class/CSS。
5. 图：独占段 `<img>` → `figure`；紧邻短句 → `figcaption`；行内小图 → `glyph/formula`（尺寸 em 化）；透明 PNG（含 alpha 且主色近黑）→ 加 `line-art` 或建议重导出（05）。
6. 注释：锚点与注文配对重建为 `noteref`/`footnote` + 回链，统一方案；不能配对的列入待确认。
7. 表：无 `th` 则提升首行；统一线型；加 `.odd`；列数/宽度超阈值提示。
8. 目录：从 nav 重建，删页码/点线，检测层级跳级。标题：层级聚类、章首与节内区分、两行标题拆 `title-num/title-name`。
9. 诗词：行数、行长、末标点、五七言、词牌/作者行；自动选居中/居左/词/自适应，原稿分段保持为 `stanza`。书信：成组识别，缺件时只套单项。
10. 生僻字：扩展区码位统计 → 替换建议/子集字体回落清单；私用区码位报告。竖排：检测 `writing-mode`、`page-progression-direction`、`lang` 不一致；物理 margin → 逻辑属性。
11. 质检联动：3 档屏宽（约 360/768/1024）与夜间模式截图，检查硬编码颜色与透明黑线图；`epubcheck`（07）。只报告：同角色多种样式、字体种类 >4、图注大于正文、依赖 L2 属性且无降级的书（须在目标 RS 上实测）。
