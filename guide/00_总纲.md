# 00 总纲：一本好的 EPUB 应该是什么样

本目录是《EPUB 制作规范》：以 **EPUB 3.3** 为准、与工具和阅读器厂商无关、按主题组织。知识来源是《EPub指南——从入门到放弃》（赤霓，2017）的精读，并按现行规范做了更新和更正。书外补充标【补】，阅读器支持没有把握的标【需实测】。

它同时是「EPUB 排版优化软件」的需求依据：每个文档末尾的「对优化软件的含义」汇总到 `07_质检清单.md` 的规则里。

## 目标读者与目标阅读器

- 目标阅读系统：**任意符合 EPUB 3 规范的阅读系统**（Apple Books、Thorium/Readium 系、KOReader 等），不针对某一家做私有适配。
- 内容：以**可重排（reflowable）的中文书**为主；固定版式（fixed-layout）只简述。

## 版本选择：为什么输出 EPUB 3（与原书建议不同）

原书附录六「成品要求·技术标准」的原话是：「一般情况下使用 2.0 标准，其他就用 3.0 标准。当你想要用 EPub 来制作带有数学公式、音频、视频时就要使用 3.0 标准。」——即**普通文字书用 EPUB 2，只有富内容才上 EPUB 3**。

这是 2017 年的合理判断：当时 Sigil 0.9 以 EPUB 2 为主、对 3 只是部分支持；多看、掌阅等主流国产阅读器也不完全支持 EPUB 3。

本规范不沿用这条建议，理由：

1. **前提已变**：EPUB 3.3 已是 W3C 正式推荐标准（2023），EPUB 2 早已被取代；Sigil 1.0（2019）起完整支持 EPUB 3；主流阅读系统都能打开可重排的 EPUB 3。
2. **普通文字书也受益**：语义标注（`epub:type`/DPUB-ARIA，见 `02`）、标准弹注、`nav` 的 landmarks、无障碍元数据、`lang` 标注都只在 EPUB 3 里有规范地位。
3. **降级成本很低**：EPUB 3 包里可以同时放 NCX（见 `01`），只认 EPUB 2 的老阅读器通常仍能读目录和正文；只用稳妥的 CSS 基线（见 `03` 渐进增强），老阅读器上也不会乱。
4. 本软件的目标本来就是「符合 EPUB 3 的阅读系统」。

所以：**一律输出 EPUB 3（`version="3.0"`）**，原书已有的 NCX 保留并与 nav 同步，没有时可选生成（见 `01` §8）；富媒体只是 EPUB 3 的可选能力，不是使用它的门槛。

## 一本好 EPUB 的七个标准

1. **合规**：通过 epubcheck，无 error。→ `01`
2. **结构清晰**：一个章节一个（或几个）文件，标题层级与目录一致，导航（toc + landmarks）完整，辅文顺序合理。→ `01` `02`
3. **语义正确**：内容是什么就用什么元素——标题用 h、引文用 blockquote、图用 figure、注释用 aside；不用空格、空段、`<br>`、行内样式去「画」出排版。→ `02`
4. **样式克制**：相对单位、少而稳的 CSS；尊重读者的字号和主题设置；夜间模式下不出问题。→ `03`
5. **中文排版讲究**：行高、缩进、段距、标题节奏合理；标点规范；引文、诗词、书信、注释各有合适的版式。→ `03` `04` `06`
6. **资源得体**：图片清晰而不臃肿，封面规范，字体只嵌必要的子集且有授权。→ `05`
7. **可访问**：有语言标注、alt 文本、无障碍元数据。→ `01` `02` `07`

## 核心理念（贯穿全部文档）

- **渐进增强**：先保证在最弱的阅读器上「能读、不乱」，再用新特性让好阅读器「更好看」。
- **读者优先于作者**：阅读器的用户设置会覆盖作者样式，这是正确的；样式要设计成「被覆盖了也不坏」。
- **语义先于样式**：先确定内容是什么，样式是语义的后果。
- **少即是多**：一份精简的样式表 + 少量模板，胜过每段一个 class。
