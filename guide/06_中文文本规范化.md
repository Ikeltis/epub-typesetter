# 06 中文文本规范化

> 范围：对**已有 EPUB**中 XHTML 内容文档的**文本节点**做规范化（标点、空白、断行、垃圾行、字符）。不涉及 TXT 分章、格式转换、标题识别（见 02_内容文档与语义结构.md）、样式（见 03_CSS与中文排版规范.md）。
> 标记：【书】来自原书；【补】书外补充；【需实测】规范/阅读器行为不确定。
> 基准：中文标点以 GB/T 15834-2011《标点符号用法》、GB/T 15835-2011《出版物上数字用法》为参照；排版要求以 W3C《中文排版需求》(clreq) 为参照【补】。台港风格（「」『』）作为可选 profile。

---

## 1 处理原则

### 1.1 作用域：只改文本节点

1. 用 XML/HTML 解析器（lxml 等）遍历文本节点，**不对序列化后的 XHTML 字符串做正则**。书中（Sigil 时代）正则直接作用于源码，会误改 `class="a.b"`、`href="http://…"`；本文所有规则都作用于"文本节点内容"。
2. 一个**块**（`p`、`h1–h6`、`li`、`td`、`blockquote`、`figcaption` 等）内的多个文本节点被行内标签（`em`、`a`、`span`、`ruby`）隔开。跨节点的规则（引号配对、括号配对、断行合并）须先把块展平为"字符流 + 字符到节点的偏移映射"，处理后按映射写回；规则不得删除或移动行内标签。
3. 属性值（`alt`、`title`、`aria-label`）按独立文本字段处理，只启用 A 级规则中的"空白"和"全角英数→半角"；`href`/`id`/`class`/`src` 永远不碰。
4. 同步修改：标题文本改动后，nav 文档与 NCX 的对应 label、`<title>` 必须同步（见 01_容器包文档与导航.md）；字符集变化后须重新做字体子集（见 05_图片与字体资源.md 第 4 节）。

### 1.2 保护区

两层保护：

**元素级（整段跳过）**：`pre`、`code`、`kbd`、`samp`、`var`、`script`、`style`、`math`、`svg`、`textarea`、`rt`/`rp`（注音）、带 `translate="no"` 的元素、`white-space` 计算值为 `pre`/`pre-wrap`/`break-spaces` 的元素（诗歌、对齐排版）；`lang`/`xml:lang` 不属于 `zh*` 的元素（英、日、韩等）整体跳过；`epub:type` 含 `pagebreak`、`noteref`、`footnote`、`index` 的元素只允许 A 级空白规则。

**文本级（分段，不占位）**：把文本节点切成 `[(kind, text)]` 序列，kind ∈ {`protect`, `zh`, `latin`}，规则只作用于 `zh` 段及其与相邻段的边界。不使用"替换成占位符再还原"的做法：占位符字符可能已存在于正文（如私用区字符）。保护模式（Python `re`）：

```python
PROTECT = [
 ("url",     r'(?i)(?<![A-Za-z0-9])(?:https?://|ftp://|www\.)[\x21-\x7e]+'),   # 仅 ASCII 可见字符，遇中文即止；末尾 .,;:!?)'" 要回吐
 ("email",   r'[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}'),               # 修正书中漏 * 与 \. 的写法
 ("cn_id",   r'(?<!\d)\d{17}[\dXx](?!\d)'),                                    # 书中 ^\d{15}|\d{18}$ 的 ^$ 只作用于一侧，且 15 位已作废
 ("mobile",  r'(?<!\d)1[3-9]\d{9}(?!\d)'),
 ("tel",     r'(?<!\d)0\d{2,3}-\d{7,8}(?!\d)'),
 ("time",    r'(?<!\d)\d{1,2}:\d{2}(?::\d{2})?(?!\d)'),
 ("thousand",r'(?<![\w.])\d{1,3}(?:,\d{3})+(?:\.\d+)?(?!\w)'),                 # 1,234,567.89
 ("decimal", r'(?<![\w.])\d+\.\d+(?:\.\d+)*(?![\w])'),                          # 3.14 / 版本号 1.2.3
 ("isbn",    r'(?i)ISBN[\s:：]*[\d\-Xx]{10,17}'),
 ("abbr",    r'(?:(?<![A-Za-z])[A-Za-z]\.){2,}|\b(?:Mr|Mrs|Ms|Dr|St|No|vs|etc)\.'),
 ("file",    r'\b[\w-]+\.(?:jpe?g|png|gif|svg|webp|css|x?html?|epub|pdf|txt|docx?)\b'),
 ("noteref", r'\[\d{1,3}\]|［\d{1,3}］'),                                       # 注释标记，由 02 处理
]
```
注意：`\b` 在 Python 中把汉字当作 `\w`，因此"见http://…"里 URL 前不能用 `\b`，须用 `(?<![A-Za-z0-9])`。URL 匹配到的尾部 `.,;:!?)"'` 要回吐给后续规则。

### 1.3 幂等

- 规则集执行两遍，结果必须与一遍相同（用测试验证：`f(f(x)) == f(x)`）。
- 因此"输出不可再被同一规则匹配"：例如省略号规则输出 `……`，该规则的匹配式不得匹配 `……`。
- 引号规则输出方向明确的引号（`“”`），再次运行走"方向明确"分支，配对结果不变。

### 1.4 分级

| 级别 | 含义 | 默认行为 |
|---|---|---|
| A 自动 | 几乎无误伤，机械性错误 | 默认开启，直接改，记入报告 |
| B 建议 | 有合理的例外，需要上下文判断或风格选择 | 生成 diff 清单，用户批量接受/逐条拒绝；可对整书设置"接受全部 B" |
| C 仅告警 | 自动修复不可靠或属内容问题 | 只输出位置、片段和原因 |

每条规则声明：`id`、描述、作用域（`text`/`block`/`doc`）、级别、正则或算法、保护、测试样例（`tests: [{in, out}]`）。每次运行输出 dry-run 报告：每条规则命中数、前后 20 字上下文。

### 1.5 执行顺序

保护分段 → 控制字符/零宽/乱码（CHR） → 兼容区与全角英数（CHR） → 空白（SPC） → 断行合并（PAR，B） → 标点全角化（PUN） → 引号与括号配对（QUO） → 省略号/破折号/间隔号（PUN） → 数字单位（NUM） → 垃圾行检测（PAR，C） → 汇总告警。先清空白再做标点，因为标点两侧的空格会影响上下文判断。

### 1.6 宏（下文正则中的 `{…}`，用 `str.replace` 或 f-string 展开）

```python
HAN   = r'㐀-䶿一-鿿豈-﫿〇\U00020000-\U0002fa1f\U00030000-\U0003347f'  # 字符类内部；含 〇，不含标点
OPEN  = '（【〔［｛「『《〈“‘'          # 开括号/开引号
CLOSE = '）】〕］｝」』》〉”’'          # 闭括号/闭引号
STOP  = '，。、；：？！…'               # 句内外点号与省略号
SP    = r'\u0020\u00a0\u3000\t'                # 空白集合：空格、nbsp、全角空格、制表符（不含换行）
```
- 书中"汉字"写法 `[\x{4e00}-\x{9fa5}]` 只覆盖 21000 余字，且遗漏扩 A 及之后；书中 `[\x{2e80}-\x{fe4f}]` 作"任意 CJK"会把标点、假名、兼容区全算进去。判断汉字用上面的 `HAN`，判断标点用 `STOP/OPEN/CLOSE`。码位表见 05_图片与字体资源.md 第 3.1 节。
- Python `re` 的 lookbehind 须定宽，下文均满足；若需 `\p{Han}`、`\p{Extended_Pictographic}`，用第三方 `regex` 库。

## 2 标点

### 2.1 全角/半角判据

对 `zh` 段中的 ASCII 标点 `, . ; : ! ? ( ) " ' < > ~ -`，按"邻字符"判定：

- **左邻**取紧邻的前一个非空白字符 `L`；**右邻**取紧邻的后一个非空白字符 `R`。
- **中文上下文**：`L ∈ HAN ∪ CLOSE ∪ STOP`，或（`L` 为空/开括号/开引号 且 `R ∈ HAN`）。
- **保护条件**（优先于转换）：落在保护分段内；`L` 与 `R` 同为 ASCII 字母数字（`3.14`、`a.b`、`12:30`、`a,b`）；位于 `lang` 非中文元素内；整句拉丁文本（连续 ≥ 5 个拉丁词）内部。
- **歧义**（`L` 为拉丁/数字，`R` 为汉字，如 `Apple,苹果`）：转 B 级建议，不自动改。
- 数字相邻：`L`、`R` 其中一侧为数字时，仅 `L∈HAN` 且 `R` 不为数字才转换（`第3章,` ok，`3,5` 不动）。

### 2.2 点号

**PUN-01 逗号**　级别 A
- 正则：`(?<=[{HAN}{CLOSE}]),(?!\d{3}(?!\d))` → `，`
- 反例：`你好,世界` 转；`共1,234人`（`L` 为数字）不动；`中文,123,456`（后面是千分位）不动。
- 歧义：`(?<=[A-Za-z0-9]),(?=[{HAN}])` 为 B，转 `，`。

**PUN-02 句号**　级别 A
- 正则：`(?<=[{HAN}{CLOSE}])\.(?=$|\s|[{HAN}{OPEN}])` → `。`
- 反例：`中文.com`、`Windows.exe`（右邻为字母，不动）；`版本2.0`（左邻数字）；`3.14`。
- 说明：书中 `([^A-Za-z<"0-9.])\.([^A-Za-z"0-9.])` 以"否定"字符集判断，会把空格、`>`、`/` 邻近的点也转掉，改为只在汉字或闭引号之后转。

**PUN-03 分号、冒号、问号、叹号**　级别 A（冒号 B）
- 正则：`(?<=[{HAN}{CLOSE}])([;?!])` → 全角 `；？！`（`str.translate`）；冒号 `(?<=[{HAN}{CLOSE}]):(?!//|\d{2}(?!\d))` → `：`
- 反例：`原因:http://…` 不动；`比例3:2`（左邻数字，不动）；`11时30分:` 转；`Q:答` 左邻为拉丁，不动。
- 冒号与时间 `12:30` 冲突，故 B：仅 `L∈HAN` 时 A，其他走建议。

**PUN-04 重复标点**　级别 B
- 正则：`([，、；：])\1+` → `\1`；`。。(?!。)` → `。`（三个及以上是省略号，见 PUN-06）。
- 保留：`！！`、`？？`、`！？`、`？！` 属表达性用法，不改；`[！？]{4,}` → C 告警。

**PUN-05 孤立/位置异常标点**　级别 C
- 段首出现 `[，。、；：？！）】」』》”’…—]`；段尾为 `[，、；：]`；`[（【「『《“‘]` 后紧跟 `[，。、；：？！]`。多由断行合并错误或 OCR 造成。

### 2.3 括号与书名号

**PUN-06 括号配对全角化**　级别 A/B
- 算法：用栈扫描块字符流，匹配 `(…)`、`[…]`，对每个**配对**整体决定，不做单字符替换（否则产生半个全角括号）：
  - 左括号左邻 `L∈HAN∪CLOSE∪STOP`，且括号内含至少一个汉字 → 转 `（）`，A。
  - 括号内为纯拉丁/数字、左邻为汉字（`世界卫生组织(WHO)`、`如下(1)`）→ 转 `（）`，B（国内出版惯例）；profile `paren_latin=keep` 可保持不变。
  - 左邻为拉丁字母/数字（`f(x)`、`Chapter(3)`）→ 不动。
  - `[数字]`（`[1]`）视为注释标记，不动（见保护 `noteref`）。
- 未配对括号 → C 告警，不修改。
- 书名号、方头括号 `【】` 本身已是全角，不动。

**PUN-07 书名号**　级别 A/B
- ASCII 双尖括号：`<<([^<>\n]{1,40})>>` → `《\1》`（A，文本节点中已是解析后的字符，不含标签）。
- 单个 `<` `>` 包裹中文：`<([{HAN}][^<>\n]{0,30})>` → `《\1》`（B，可能是比较符号）。
- 内嵌：书名号内再出现书名号，内层用 `〈 〉`（B）：栈扫描 `《` 的深度，深度 ≥ 2 的改 `〈〉`。
- 配对检查：`《` 与 `》` 数量不等 → C。
- 书名后括号内的英文原名（`《书名》(English Title)`）：可选斜体（`<i>`）属于结构修改，不在文本规则范围，作 B 建议；【书】做法，中文书不强制。
- 补充：`〈〉` 在《GB/T 15834》用于篇名与嵌套书名，U+2329/U+232A（`〈〉` 旧码位）→ U+3008/U+3009 A。

### 2.4 破折号、省略号

**PUN-08 破折号 `——`**　级别 A
- 标准：U+2014 两个。
- 正则：`(?<!\d)(?:(?<=[{HAN}{CLOSE}{STOP}])(?:-{2,}|－{2,}|─{2,})|(?:-{2,}|－{2,}|─{2,})(?=[{HAN}{OPEN}])|―{1,2}|(?<=[{HAN}{CLOSE}])—(?!—)(?=[{HAN}{OPEN}]))` → `——`
  测试：`甲--乙`→`甲——乙`；`a--b`（两侧均为拉丁）不动；`丙―丁`（U+2015）→`丙——丁`；`庚—辛`→`庚——辛`；`壬——癸` 不动；`1900—1950`（两侧数字）不动。
- 三个及以上 `———` → `——`（B）。
- 反例：英文句子内的 `--`（lang=en）不动；表格内的 `—` 单独成格（"无"的占位）不动；数字范围见 PUN-11。
- 破折号前后不得留空格：用 SPC-05 处理。

**PUN-09 省略号 `……`**　级别 A
- 标准：U+2026 两个（占两个字位置，六点）。
- 规则（顺序执行）：
  1. `…{3,}` → `……`（A）。
  2. `(?:(?<=[{HAN}{CLOSE}{STOP}])\.{3,}(?!\.))|(?:(?<![.\w])\.{3,}(?=\s?[{HAN}]))` → `……`（中文上下文的 `...`）。
  3. `。{3,}`、`·{3,}`、`・{3,}`、`⋯` → `……`。
  4. 单个 `…`：`(?<=[{HAN}{CLOSE}])…(?!…)|(?<!…)…(?=[{HAN}])` → `……`（B；英文句子里的单个 `…` 不动）。
- 反例：`wait...`（英文句末）、`a...b`、`3...5`；`……。`、`……！` 允许；`…………`（4 个）→ `……` 可能改变语气，列为 B。
- 幂等：规则 1、4 的匹配式均不匹配 `……`（`(?<!…)…(?!…)` 对连续两个不命中）。
- 省略号前后的空格：SPC-05 处理。

### 2.5 间隔号、连接号、波浪线

**PUN-10 间隔号**　级别 A（`.` 变体 B）
- 标准：U+00B7（`·`）。
- 正则：`(?<=[{HAN}])[•‧∙⋅・．](?=[{HAN}])` → `·`；仅在两侧均为汉字时，`.`（半角）转换列 B：`(?<=[{HAN}])\.(?=[{HAN}])`。
- 反例：日文片假名中点 `・`（U+30FB）在 `lang=ja` 或片假名之间不动；`‧`（U+2027）为台湾习惯，profile `tw` 时保持。
- 字体渲染：U+00B7 在部分字体中为窄宽度，需 `lang="zh-Hans"` 等让 CJK 字体选全宽字形【需实测】。

**PUN-11 连接号与波浪线**　级别 B
- 范围表示：`(?<=\d)~(?=\d)` → `～`（U+FF5E），`〜`（U+301C）→ `～`。
- 数字范围中的 `-`、`–`、`—`：中文书可用 `～` 或 `—`（一字线），profile 选 `range=tilde|dash|keep`；默认只规范 ASCII `~`。
- 半字线 `-` 用于型号、代码（`WTO-1`、`ISO-8859`），不改。
- 反例：`2020-10-22`（日期）、`3-5年` 视为日期/范围需 B 确认。

**PUN-12 重复/混用符号检测**　级别 C
- 同一本书中对同一用途出现多种写法的统计与告警：`""` 混 `「」`，`--` 混 `——`，`...` 混 `……`；输出占比，少数派逐条列出。

### 2.6 数字与单位

**NUM-01 数字用半角**　级别 A
- 全角数字转半角（见 CHR-01）；汉字数字不转。年份、页码、金额等阿拉伯数字用半角。
- 汉字数字中的"零"：`二〇二四` 用 U+3007（`〇`）而非 `○`（U+25CB）、`◯`（U+25EF）、`О`（U+041E 西里尔）。
  正则（函数替换，长度保持）：`[○◯О]+(?=[一二三四五六七八九〇])|(?<=[一二三四五六七八九〇])[○◯О]+` → 同长度 `〇`。测试：`二○○四年`→`二〇〇四年`，孤立的 `○` 不动。

**NUM-02 千分位与小数点保护**　级别 A（保护）
- 保护：`1,234,567.89`、`3.14`、`1.2.3`、`12:30`；绝不把其中 `,`、`.` 转全角。
- 全角数字整体转换：令牌 `[０-９]+(?:[，．][０-９]+)*` 整体转半角（`１２，３４５`→`12,345`，`３．１４`→`3.14`）：令牌内一致用全角，说明作者原意是数字。
- OCR 误识别：`(?<=\d)[。，](?=\d)` 在数字之间的 `。` 或 `，`（如 `3。14`）→ B 建议改 `.` 或 `,`。
- 千分位格式（GB/T 15835）：四位以内不分节；五位以上整数可用空格或千分撇分节，**统一，不强制**：检测同一书内混用 `1,234`/`1 234`/`1234` → C。

**NUM-03 数字与单位**　级别 C（风格）
- 单位在中文（`5公斤`、`3个`）：不加空格。
- 拉丁单位（`5 kg`、`10MB`、`25°C`）：规范（SI）是数字与单位间加空格，`%` 与 `°` 紧贴；国内出版物两种都有。
- 策略：整书统一，检测有空格/无空格占比，多数派为准，少数派列 B；`%`：全角 `％` → `%`（`(?<=\d)％` → `%`，A）。
- 不要拆分 `3m`/`5pt` 之类可能是代码或变量的片段（保护 `abbr`）。

### 2.7 引号

**QUO-01 引号配对（栈式）**　级别 A（方向明确）/ B（ASCII 引号）/ C（失配）

正则无法处理：书中修错转的 `(「)+([^」「]*)「` → `\1\2」` 只对"同一层、同一错误形态"有效；书中嵌套替换式 `「([^「」]*?)「([^「」]+)」([^「」]*?)」` 只处理一层，且要循环。统一用栈。

目标风格 `style`：
- `cn`（大陆）：外层 `“ ”`，内层 `‘ ’`，再内层又用 `“ ”`，交替。
- `tw`（台港）：外层 `「 」`，内层 `『 』`，再内层又用 `「 」`。
- 默认取全书使用最多的风格；混用时 B 建议统一。

输入引号归类：`"`、`“”`、`＂`、`„‟`、`〝〞`、`「」` 为"双层类"（kind=d）；`'`、`‘’`、`＇`、`『』` 为"单层类"（kind=s）。方向明确的字符（`“`、`”`、`「`、`」` 等）直接用方向；ASCII `"`、`'` 须判定方向：

1. 左邻为空/空白/开括号/`—`/`：`/`，` 等 → 开；右邻为空白/结尾/闭标点 → 闭。
2. 以上都不决定时，看栈顶：栈顶同类 → 闭，否则 → 开。
3. 撇号保护：`'`、`’` 两侧均为 ASCII 字母数字（`don't`、`rock'n'roll`）→ 不是引号，不处理；`5'10"` 英尺英寸 → 保护。

输出符号由"当前深度"决定（深度 = 栈高），而不是输入符号：

```python
PAIRS = {'cn': [('“','”'),('‘','’')], 'tw': [('「','」'),('『','』')]}
OPEN_CTX = set(' \t\n（([【〔［「『《〈“‘—：，、；')

def fix_quotes(text, style='cn', stack=None):
    stack = [] if stack is None else stack          # 栈跨段落/跨节点共享
    out, warn = [], []
    for i, ch in enumerate(text):
        if ch in '"“”「」＂„‟〝〞':   kind = 'd'
        elif ch in "'‘’『』＇":       kind = 's'
        else: out.append(ch); continue
        prev = text[i-1] if i else ''
        nxt  = text[i+1] if i+1 < len(text) else ''
        if ch in "'’" and prev.isascii() and nxt.isascii() and prev.isalnum() and nxt.isalnum():
            out.append(ch); continue                   # 撇号
        is_open, is_close = ch in '“‘「『〝', ch in '”’」』〞'
        if not (is_open or is_close):                  # ASCII，方向待定
            if prev == '' or prev in OPEN_CTX: is_open = True
            elif nxt == '' or nxt in ' \t\n，。、；：？！）】」』》”’…—': is_open = False
            else: is_open = not (stack and stack[-1] == kind)
            is_close = not is_open
        if is_open: stack.append(kind)
        elif stack and stack[-1] == kind: stack.pop()
        else: warn.append((i, ch, 'unmatched close')); out.append(ch); continue
        depth = len(stack) - 1 if is_open else len(stack)
        o, c = PAIRS[style][depth % 2]
        out.append(o if is_open else c)
    return ''.join(out), stack, warn
```
测试（已验证）：`他说:"你好,他说'走吧'。"然后` → `他说:“你好,他说‘走吧’。”然后`（标点另由 PUN 规则处理）；`“甲说「乙说『丙』」”` → `“甲说‘乙说“丙”’”`（统一为 cn 风格）；`他说"开始` → 栈剩 `['d']`，由调用者判断是否跨段。

处理细则：
- **跨段**：同一节（section）内按顺序共享栈。中文多段引文惯例：每段开头重复开引号、只在末段闭合，故段末栈非空且下一段以开引号开头时不告警；其它情况栈非空 → C 告警；遇标题（`h1–h6`）、`<section>` 起始则清栈。
- **失配**：只告警不改（`warn` 列表带位置）；同一块内 `「…「` 连续两个开引号的"同形错转"在栈算法中表现为深度错误，由 C 级告警列出，用户确认后 B 级修复为闭引号。
- **英文引号**：`lang=en` 元素或整句拉丁文本内的引号不动。
- 句末标点与引号位置（`。”` 与 `”。`）：GB/T 15834 规定引文为整句时点号在引号内，否则在外。无法自动判断，整书统计两种比例，少数派列 C。
- 字形：`“”` 在部分字体中为半角窄字形；`lang="zh-Hans"` 配合 CJK 字体通常为全宽【需实测】。

## 3 空白

**SPC-01 控制字符与不可见字符**　级别 A
- 正则：`[\x00-\x08\x0b\x0c\x0e-\x1f\x7f-\x9f\ufffe\uffff]` → ``（XML 1.0 不允许前几类；`\x80-\x9f` 为 C1 控制字符，几乎必为乱码）。
- 孤立代理项（`[\ud800-\udfff]`）为解码错误，C。

**SPC-02 零宽与格式字符**　级别 A/B
| 字符 | 处理 |
|---|---|
| U+200B ZWSP、U+FEFF BOM/ZWNBSP、U+180E | 删除（A） |
| U+00AD SHY | 中文段内删除（A）；拉丁词内保留（拉丁文本中用于断词，除非无 `lang=en`） |
| U+200C ZWNJ、U+200D ZWJ | 在中文、拉丁文本内删除（A）；相邻字符属于 emoji（U+1F300–1FAFF、U+2600–27BF）、波斯/印度系文字时保留 |
| U+2060 WJ | B（可能是有意的禁止断行，如 `……`）；删除前先看相邻字符 |
| U+200E/200F LRM/RLM，U+202A–202E，U+2066–2069 | 中文正文删除（B）；`lang` 为阿拉伯/希伯来语时保留 |
| U+FE00–FE0F、U+E0100–U+E01EF（变体选择符） | **保留**，IVS 为字形选择（05 中 3.1） |
- 正则：`[\u200b\ufeff\u180e]` → ``；`(?<![\U0001F300-\U0001FAFF\u2600-\u27bf])[\u200c\u200d]` → ``。

**SPC-03 不间断空格与特殊空白**　级别 A/B
- U+00A0 在段首或汉字之间 → 删（A）；在拉丁词之间 → 普通空格（A，除非整句属于 `5 kg` 一类刻意的不换行，保留为 B）；`&#160;` 仅组成的段落 `<p>&#160;</p>` 为空行占位，属结构问题（02/03：删除并折算为 margin）。
- `[\u2000-\u200a\u202f\u205f]` → `' '`（A），含 en/em/thin 等空格；U+3000 见 SPC-04。
- 例外：保护区、`pre`、`white-space:pre`。

**SPC-04 全角空格与段首缩进**　级别 A/B
- 段首 `^[{SP}]+` 去除；记录原缩进习惯：整书超过 60% 的段落以 2 个全角空格开头 → 视为"用空格缩进"，A 级删除并提示交由 CSS `text-indent:2em`（03_CSS与中文排版规范.md）。
- 不规则缩进（有的 1 个，有的 2 个，有的 4 个）→ B 统一。
- 行中的 U+3000：汉字之间（姓名对齐 `张　三`、诗歌空格）→ C 告警，不改；拉丁词之间 → `' '`（A）。
- 保护：诗歌块、`white-space:pre` 元素、带 `class` 含 `poem|verse|indent` 的元素（仅 C）。

**SPC-05 汉字与标点之间的空格**　级别 A
- 正则（依次）：
  - `[{SP}]+(?=[，。、；：？！）】」』》”’…—])` → ``　（标点前）
  - `(?<=[（【「『《“‘])[{SP}]+` → ``　（开括号/开引号后）
  - `(?<=[，。、；：？！])[{SP}]+(?=[{HAN}{OPEN}])` → ``　（点号后与汉字/开括号之间）
  - `[{SP}]*(——|……)[{SP}]*` 中，与汉字相邻一侧的空格删除。
- 测试：`你好 ，世界　。 “a ”` → `你好，世界。 “a”`（`。` 后接拉丁词时保留一个空格，不删）。
- 反例：`Hello, 世界`（拉丁标点 + 空格，属英文片段）；数字与单位之间；`pre`。

**SPC-06 汉字之间的空格**　级别 B（OCR 书 A）
- 正则：`(?<=[{HAN}])[{SP}]+(?=[{HAN}])` → ``。
- 判据：整书统计 `汉字-空格-汉字` 每千汉字出现次数；> 3‰ 视为 OCR/PDF 痕迹，A；否则 B，逐条确认。
- 反例：人名对齐、署名、目录点线、诗歌、表格对齐用空格；`pre`。

**SPC-07 多余空格与行首行尾**　级别 A
- `[ \t]{2,}` → `' '`（仅拉丁段；汉字段内的多空格先被 SPC-05/06 吃掉）；`\t` → `' '`。
- 块首尾：删除首尾空白（含 U+3000、U+00A0），保留语义空格（如 `<em>a</em> <em>b</em>` 之间的）：只处理块的第一个和最后一个文本节点的外侧。
- **源码换行**：XHTML 源码中的 `\n` 加缩进（pretty-print）在汉字与汉字之间，部分引擎会渲染成一个空格（CSS Text 3 规定东亚字符间的段落换行应折叠，但引擎实现不一）【需实测】。因此 `(?<=[{HAN}])\s*\n\s*(?=[{HAN}])` → ``（A，仅作用于同一块内的文本）；块级边界的换行不动。
- 拉丁词之间的换行折成一个空格。

**SPC-08 中西文间空格（策略）**　级别 B，整书统一
- 三种做法对比：
| 做法 | 优点 | 缺点 |
|---|---|---|
| (a) CSS `text-autospace: normal`（CSS Text 4，`ideograph-alpha`/`ideograph-numeric`） | 内容里无多余字符；搜索、复制、朗读不受影响；字距由引擎控制 | 属 EPUB 3.3 CSS 基准之外的属性，支持度随 RS 引擎而异【需实测】；无支持的 RS 上中西文紧贴 |
| (b) 文本里插入 U+0020 | 所有 RS 一致 | 污染内容，搜索/朗读/复制带空格；两端对齐时空格被拉伸；若 RS 也支持 autospace 则间距重复 |
| (c) 包裹拉丁片段并用 `margin` | 视觉一致，文本无空格 | 结构被修改，DOM 变大，复制时丢失；仅作可选 |
- **建议**：
  1. 默认策略 `follow`：跟随书里已有的风格。统计中西文边界处有空格的占比 `r`：`r ≥ 0.8` 视为"加空格"风格，补齐缺漏（B）；`r ≤ 0.2` 视为"不加空格"风格，删掉零散的多余空格（B）；中间值提示用户选择。
  2. 无论哪种，输出 CSS 时给正文加 `text-autospace: normal`（03 中记录），让支持的 RS 自行处理；因它与 (b) 叠加可能重复间距，所以"加空格"风格下不输出此属性。
  3. 纯数字与汉字之间的空格不自动插入：`第3章`、`3个`、`2024年`、`50%`。
- 插入式规则（仅在 profile=`insert`）：`(?<=[{HAN}])(?=[A-Za-z0-9])|(?<=[A-Za-z0-9])(?=[{HAN}])` → `' '`，加例外：数字前为 `第`；数字后为 `[年月日号时点分秒个条次章节回卷页岁倍度元块只件名位种]`；`%`、`°` 紧贴；保护分段。
- 删除式规则（profile=`remove`）：`(?<=[{HAN}]) (?=[A-Za-z0-9])|(?<=[A-Za-z0-9]) (?=[{HAN}])` → ``。

## 4 段落

### 4.1 断行合并（硬换行）

已有 EPUB 中常见：OCR 或 PDF 转出的书，每个 `<p>` 是版面中的一行。**只能启发式 + 确认，级别 B，绝不自动合并**。

**PAR-01 硬换行检测**

1. **文档级判定**：对一个内容文档的 `p` 序列（不少于 30 段）计算各段字数；若 `≥ 40%` 的段字数落入 `[W-2, W+2]`（`W` 为众数，且 `W ≥ 15`），且其中 `≥ 30%` 的段不以句末标点结尾 → 判为"疑似硬换行文档"。
2. **相邻段合并候选**：`p_i` 与 `p_{i+1}` 同时满足：
   - 条件 a：`p_i` 不以 `[。！？…”’」』）】]`、`——` 结尾，或虽以句末标点结尾但字数 `≥ 0.95W`（OCR 恰好在行尾）；
   - 条件 b：`p_i` 字数 `≥ 0.8W`（是满行）；
   - 条件 c：`p_{i+1}` 不匹配标题模式（短行 + 无句末标点 + `第…章`、序号等，见 02）、不以全角空格/缩进开头、不是空段；
   - 条件 d：`p_{i+1}` 不以开引号开头（可能是对话新段），除非 `p_i` 以 `，`、`、`、`；` 结尾；
   - 条件 e：二者同 `class`/同父元素，不在 `blockquote`、诗歌、列表、表格、`figure` 内；
3. **置信度**：`score = 0.3·a + 0.3·b + 0.2·c + 0.1·d + 0.1·e`（满足记 1），`≥ 0.85` 为"高置信"批量确认；`0.5–0.85` 逐条确认；`< 0.5` 不提示。
4. **合并方式**：把 `p_{i+1}` 的子节点接到 `p_i` 末尾并删除 `p_{i+1}`；汉字与汉字之间无分隔；拉丁词之间补一个空格；行末连字符 `(?<=[A-Za-z])-$` 且下一行以小写字母开头 → 去连字符（B，复合词如 `well-known` 误伤风险，列 B）。
5. **反例与保护**：标题、诗歌、对白（每行都短）、目录页、署名、列表；OCR 误将段落标点行尾当作段尾（陷阱：恰在行尾的句号）；合并后须保留原文位置，便于校对。

书中正则（Sigil 版 `([\x{4e00}-\x{9fa5}])</p>\s+<p>` → `\1`）会把所有以汉字结尾的段合并，且只看前一段末尾；EmEditor 版 `([一-龥])\n` 同理；另一条 `([^。>?？."」！……：!])</p>…` 字符集重复且混入 `>`、`"`。这些只能作为"候选扫描"，不可直接替换。

行级文本（TXT 型内容，例如 `<pre>` 之外的 `\n`）的对应正则：`(?<=[^。！？…”’」』）】\n])\n(?!\s*$)(?!第[0-9零一二三四五六七八九十百千两]+[章节回卷部篇集])` → ``（仍属 B）。

**PAR-02 应拆未拆**　级别 C
- 段内出现 `\n`（文本节点内的换行，非源码缩进）且前一行以句末标点结尾、后一行以缩进开头 → 提示拆分为两段。

### 4.2 垃圾行检测

对每个块的纯文本（去标签后）：

**PAR-03 页码行**　级别 B
- 正则：`\s*(?:[-—－–]\s*)?\d{1,4}\s*(?:[-—－–]\s*)?|\s*第\s*\d{1,4}\s*页\s*|\s*\d{1,4}\s*/\s*\d{1,4}\s*`（用 `re.fullmatch`），以及仅含罗马数字 `[ivxlcdmIVXLCDM]{1,7}` 的短行。
- 保护：`epub:type="pagebreak"`、`role="doc-pagebreak"` 的元素是合法的纸书页码锚点，不得删除；位于列表/表格中的数字；章节内编号。

**PAR-04 重复页眉页脚**　级别 B
- 算法：对全书字数 ≤ 30 的块，把数字替换成 `#` 后统计频次；频次 `≥ 5` 且 `≥ 0.5%` 的块数，或交替出现（书名/章名奇偶页）→ 页眉页脚候选；列表展示各次出现位置，用户确认后批量删。
- 保护：标题（`h1–h6`）、`figcaption`、章名恰好重复（如多章同名"附录"）。

**PAR-05 水印与广告**　级别 B（仅命中整行或整段时）
```python
WATERMARK = [
 r'(?i)(?:www\.|https?://)\S+\s*$',                       # 孤立网址行
 r'(?i)\bQQ\s*(?:群|号)?[:：]?\s*\d{5,}',
 r'(?:微信|公众号|微博|关注|扫码|扫描二维码)[^\n]{0,20}(?:公众号|二维码|获取|领取)',
 r'(?:仅供|本书仅供)[^\n]{0,15}(?:学习|交流)[^\n]{0,15}(?:删除|下载后)',
 r'(?i)(?:下载|更多|最新)[^\n]{0,10}(?:txt|epub|mobi|pdf|电子书)',
 r'(?i)\b(?:z-?library|zlibrary|libgen)\b',
]
```
- 仅当整段文本被命中、或命中占该段 ≥ 50% 时标为候选；正文中的"微信"字样不动。
- 同类：`^[-=_*·.\u3000\s]{3,}$` 分隔线 → B 建议改为 `<hr/>`（结构修改）。

**PAR-06 乱码**　级别 C/B
- `锟斤拷`、`烫{3,}`、`屯{3,}`、`ï»¿`、`[ÃÂ][\x80-\xbf]`、U+FFFD `�`：C。
- 尝试修复（B）：`s.encode('latin-1').decode('utf-8')` 或 `s.encode('gbk', 'ignore')` 回转，往返后汉字占比显著提高时才提示。

## 5 字符层面

**CHR-01 全角英数转半角**　级别 A
- 正则：`[Ａ-Ｚａ-ｚ０-９]+`，按偏移 `ord(c) - 0xFEE0` 转换（函数替换）。例：`ＡＢＣ１２３` → `ABC123`。
- 数字令牌见 NUM-02。`％＄＋－＝＆＠＃` 在数字/拉丁上下文转半角（B）：`(?<=\d)％`→`%` A。
- 反例：竖排书（`writing-mode: vertical-*`）的 2 位全角数字作为竖排的"纵中横"原文，按 B 处理；`lang=ja` 内的全角字母不动。
- **禁止全局 NFKC**：NFKC 会把 `…` 变 `...`、`①` 变 `1`、`㎏` 变 `kg`、`℃` 变 `°C`、`︵` 变 `(`，规则只用上述白名单映射。
- 半角片假名（U+FF61–FF9F）→ 全角：仅 `lang=ja`/中文书少见，B。

**CHR-02 NFC（非 CJK）**　级别 A
- 仅对拉丁、希腊、西里尔段应用 `unicodedata.normalize('NFC', seg)`（如 `e` + U+0301 → `é`）；拼音声调字母不受影响（已组合）。CJK 兼容区由 CHR-03 处理，不要对整段做 NFC。

**CHR-03 CJK 兼容表意文字**　级别 B
- 范围：U+F900–U+FAFF、U+2F800–U+2FA1F（兼容区）。
- 其中大多数是与统一表意文字有"正则等价"的重复编码，NFC 会把它们映射到统一码位（如 U+F900 `豈` 的 NFC 结果是 U+8C48 `豈`，字义相同、仅码位不同）；约 12 个（U+FA0E、FA0F、FA11、FA13、FA14、FA1F、FA21、FA23、FA24、FA27–FA29）实际是统一表意文字，没有分解。
- 规则：`unicodedata.decomposition(c)` 非空的字符用 `normalize('NFC', c)` 映射（B，因为字形可能随来源字体不同而变，如日本 JIS 字形）；没有分解的保留。
- 保留：IVS（基字 + `U+E0100–E01EF`）。

**CHR-04 部首与笔画误用**　级别 A（康熙部首）/ C
- 康熙部首 U+2F00–U+2FD5：全部带兼容分解，`normalize('NFKC', c)` 仅对此区间字符使用 → 统一表意文字（`⽇`→`日`，`⼈`→`人`），常由 PDF 复制产生，A。
- CJK 部首补充 U+2E80–U+2EF3：无分解，作为正文（如 `⺟`、`⻓`）出现时告警 C，建议换为 `母`、`长`；换成什么需要字形判断。
- 表意文字描述符 U+2FF0–U+2FFF（`⿰`…）拼字：缺字占位，C。

**CHR-05 私用区与占位符**　级别 C
- 私用区：`[\ue000-\uf8ff\U000f0000-\U0010ffff]` 含义取决于字体；GB18030 映射私用区的转换表按版本不同【需核实】；记录字体与码位，转 05 的生僻字流程。
- 占位符 `□ ■ 〓 ▯ �`：孤立使用且前后为汉字 → 缺字占位，C。

**CHR-06 繁简混用与异体字**　级别 C/B
- 检测：用 OpenCC 词表生成两个集合：`S`（简体专有字：`t2s(c)==c` 且 `s2t(c)!=c`）、`T`（繁体专有字：`s2t(c)==c` 且 `t2s(c)!=c`）。对块统计 `|S|`、`|T|`，计算混用度 `m = min(|S|,|T|)/(|S|+|T|)`。整书 `m > 3%` 且块内同时出现 `S`、`T` 字 → C 告警，并列出块。
- 与 `lang` 一致性：`lang="zh-Hans"` 的块含大量 `T`，或 `zh-Hant` 的块含大量 `S` → C 告警，建议改 `lang` 或转换。
- 转换（B）：只做用户显式选择的方向（`t2s`/`s2t`/`s2twp`，词级而非字级，避免 `发→發/髮`、`后→后/後` 之类的一简多繁错误）；引文中的文言、人名、书名、专名要跳过（可选保护：`《》` 内文字、`lang` 不同的元素）。
- 异体字：仅在用户提供一一对应表时 B 处理（如《第一批异体字整理表》中的 `羣→群`、`峯→峰`）；默认只告警，不改。

**CHR-07 日期数字格式**　级别 B（可选）
- `(\d{4})[./\-](\d{1,2})[./\-](\d{1,2})` → `\1年\2月\3日`；仅在正文行文中，保护：版权页 ISO 日期、`<time>`、文件名、`dc:date`。

## 7 对优化软件的含义

- **流水线**：解析 DOM → 文本节点分段（protect/zh/latin）→ 按 1.5 顺序执行规则 → 写回 → 同步 nav/NCX/`<title>` → 重算字体子集（05）。
- **默认 A 级**：SPC-01..05、SPC-07、PUN-01..03、PUN-08/09、NUM-01、CHR-01/02/04（康熙部首）。幂等与测试样例作为发布门禁（每条规则 ≥ 3 条正例 + 3 条反例）。
- **引号、括号**：必须是栈算法，不能用单条正则；方向明确的输入 A，ASCII 引号 B，失配只告警。
- **断行合并**：B 级，需要段长度分布和置信度，界面应展示合并前后对照；不对没有硬换行特征的书触发。
- **垃圾行**：先检测再删；`epub:type="pagebreak"` 不是垃圾；删除操作可撤销并保留日志。
- **中西文空格**：默认跟随全书已有风格，CSS 优先（`text-autospace`），不批量插空格。
- **字符层面**：不做全局 NFKC；兼容区映射为 B；繁简转换只在用户指定方向时执行。
- **报告**：按规则 ID 汇总命中、改动示例（前后 20 字）与告警清单；告警包含"文档:块序号:字符偏移"以便定位。
- **配置**：profile 包含 `style=cn|tw`、`paren_latin`、`range`、`autospace=follow|insert|remove|css`、`hard_wrap_threshold`、保护区追加列表；规则库使用声明式 YAML（id、scope、level、pattern、replace、protect、tests）。
